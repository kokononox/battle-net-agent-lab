# اصلاح آزمایشی نمایش IPv6 — انتشار نهایی مسدود است

این پوشه کاندید آزمایشگاهیِ تبدیل full IPv6 از ::/0 به ::/1 و8000::/1 است. پوشش دقیقاً برابر و بدون بازترشدن سیاست است. موتور بازیابی، فقط آماده‌سازی غیرفعال را تکمیل می‌کند. روی دستگاه کاربر هنوز اجرا و تأیید نشده است؛ هیچ بستهٔ قابل‌توزیع نهایی از این مرحله معرفی نشده است.

COMPATIBILITY.fa.md فهرست وابستگی‌ها و شرط‌های تحویل را ثبت می‌کند. hosts تغییرکرده با BAT06، کیل‌سوییچ مستقل، baseline هر میزبان و journalهای نسخه‌های قبل باید در ممیزی واقعی لحاظ شوند. صرف اصلاح IPv6، آن ممیزی یا مهاجرت را انجام نمی‌دهد. فعلاً صرف کپی پوشه روی دستگاه دیگر توصیه نمی‌شود. journal/backup فایروال از میزبان قبلی به میزبان جدید کپی نشود.

Windows CI روی windows-2022 وwindows-2025 موفق شد: در هر محیط pure257، CIDR30، recovery56 در۶ مجموعه و native40؛ UI construct/dispose موفق. دو محیط Server جای Windows10/11 کلاینت واقعی نیستند. IPv6 packet، SSTP واقعی، reboot، UAC تعاملی و نبود نشتی هنوز تأیید نشده‌اند.

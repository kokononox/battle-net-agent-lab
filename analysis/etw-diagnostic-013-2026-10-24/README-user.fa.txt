WLab ETW Diagnostic 0.1.3 — اصلاح تشخیص وضعیت WPR

نسخهٔ قبلی اشتباه از exit code صفر نتیجه می‌گرفت ضبط فعال است، در حالی که خروجی شما WPR is not recording بود. این نسخه متن وضعیت را نیز بررسی می‌کند؛ unknown را فعال یا غیرفعال فرض نمی‌کند.

۱. بازی بسته باشد؛ پنجرهٔ آزمایش قبلی را پس از پایان ببند.
۲. ZIP جدید را در پوشهٔ جدا و درایو دارای فضای کافی استخراج کن.
۳. WLab-ETW-Diagnostic.exe را دوبارکلیک کن؛ در صورت موافقت درخواست Administrator و توضیح تست را تأیید کن.
۴. پس از پایان، READY-TO-SEND.zip از WLab-Control-*\RESULT-* کنار EXE را بفرست. خطاها را حذف نکن.
۵. برای بستن پنجره پس از پایان Enter بزن؛ در حین تست پنجره را به اجبار نبند.

همان شش profile جدا با Strict=true حفظ شده‌اند؛ هر start موفق فقط کنترل ۴۴۸‌بایتی به 127.0.0.1 اجرا می‌کند. این نسخه رفع خطای فعال‌سازی provider یا ثبت stack مفید را از پیش ادعا نمی‌کند.

تست واقعی تابع تشخیص وضعیت با خروجی ارسال‌شدهٔ شما و شش حالت دیگر روی PowerShell 7.6.8 لینوکس پاس شده؛ کل اسکریپت parse و کد C# کنترل compile شده است. این‌ها تأیید اجرای WPR/UAC/Windows PowerShell 5.1 یا stack بازی نیستند.

هیچ نصب یا دانلود روی دستگاه شما، اتصال اینترنت، دسترسی حافظهٔ بازی، تغییر policy/رجیستری یا آپلود خودکار وجود ندارد. ETW ممکن است متادیتای شبکهٔ پس‌زمینه را ثبت کند. memory mode و سقف ۶۴ MiB مجموع ETLهای داخل ZIP برقرارند، ولی سقف کل فضای merge/temp یا زمان اتمام تضمین نمی‌شود؛ حداقل ۲۵۶ MiB فضای آزاد بررسی می‌شود.

stop/cancel فقط instance اختصاصی همان تست را هدف می‌گیرد. اگر وضعیت نامفهوم یا cleanup تأییدنشده باشد، ادامه متوقف و لاگ نگه داشته می‌شود. recovery هر تست داخل RESULT نام دقیق instance را دارد؛ دستور عمومی cancel اجرا نکن.

EXE unsigned است؛ اگر حفاظت ویندوز اجرای آن را مسدود کرد پیام را بفرست، نه اینکه حفاظت را غیرفعال کنی.

WLab ETW Control 0.1 — فقط آزمایش کنترل شبکهٔ محلی

۱) بازی را خودت ببند. بسته را از ZIP کامل استخراج کن؛ ترجیحاً روی درایوی که فضای آزاد کافی دارد.
۲) Windows PowerShell نسخهٔ ۶۴بیتی را با Run as administrator باز کن.
۳) وارد پوشهٔ استخراج‌شده شو و اجرا کن:
   .\Run-Control.ps1
۴) READY-TO-SEND.zip را از پوشهٔ RESULT ساخته‌شده بفرست. پیام خطا هم ارزش بررسی دارد.

اگر سیاست ویندوز اجرای اسکریپت را مسدود کرد، همان خطا را بفرست؛ این بسته policy را تغییر نمی‌دهد.

این تست:
- به بازی attach نمی‌کند، حافظهٔ بازی را نمی‌خواند و فایل‌های بازی را تغییر نمی‌دهد.
- سه بلوک آزمایشی ۶۴،۱۲۸،۲۵۶‌بایتی، جمع ۴۴۸ بایت، فقط به 127.0.0.1 و پورت موقت ارسال و دریافت را بررسی می‌کند. تعداد واقعی فراخوان‌های Send و بازهٔ QPC در control.json ثبت می‌شوند؛ send ممکن است جزئی باشد و چندبار فراخوانی شود.
- اینترنت، نصب، دانلود و آپلود خودکار ندارد. WPR داخلی و .NET موجود استفاده می‌شوند.
- درخواست Stack برای AFD با keyword 0x4 و Sockets با keyword 0x1 دارد. ثبت stack مفید هنوز ثابت نشده است.
- اسم تصادفی اختصاصی WPR دارد و stop/cancel فقط همان instance را هدف می‌گیرد. هیچ wpr -cancel عمومی اجرا نمی‌شود.
- از Memory mode با ۶۴ بافر ۶۴ KiB (حدود ۴ MiB دادهٔ بافر، نه کل مصرف حافظهٔ ابزار) استفاده می‌کند؛ filemode نامحدود فعال نمی‌شود. سقف قطعی ۶۴ MiB برای ETL نهایی/فضای temp وعده داده نمی‌شود؛ فقط ETL حداکثر ۶۴ MiB وارد ZIP می‌شود. حداقل فضای بررسی‌شده ۲۵۶ MiB است. مسیر temp این فرایند و WPR به پوشهٔ RESULT هدایت می‌شود؛ فضای cache سایر اجزای ویندوز تضمیناً در این پوشه نیست.
- رویدادهای پس‌زمینهٔ سایر برنامه‌ها ممکن است داخل ETL باشند؛ trace به یک PID محدود نشده است. متادیتای شبکه و مسیر ماژول‌ها ممکن است ثبت شود. فقط raw ETL محلی برای بررسی نگه داشته می‌شود و خودکار به مخزن نمی‌رود.
- در صورت خطای start، هیچ ضبط دیگری را متوقف نمی‌کند. اگر stop شکست بخورد فقط cancel همان instance امتحان می‌شود.

عادی باید کوتاه باشد، اما زمان قطعی اتمام WPR/کامپایل .NET تضمین نشده است. پنجره را در میانه به اجبار نبند؛ در صورت قطع ناگهانی، WPR ممکن است باقی بماند. دستور recovery با نام دقیق instance داخل RESULT\SESSION-RECOVERY.txt ثبت می‌شود. فقط همان نام را متوقف کن، نه sessionهای دیگر.

محدودیت مهم: بسته روی لینوکس آماده و از نظر ساختار XML/ارجاع‌ها بررسی شده، اما روی Windows اجرا و تأیید نشده است. خود WPR پیش از start فایل profile را با -profiles بررسی می‌کند. موفقیت برنامهٔ کنترل یا وجود control.etl به معنی وجود stack مفید، موفقیت روی بازی، رمزگشایی یا ارسال CPU/BIOS نیست.

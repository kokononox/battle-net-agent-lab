# پاسخ‌دهندهٔ موقت PHP برای هاست سی‌پنل

فقط فایل `ufw-probe-0ad0686e27256f475d32.php` را از File Manager داخل document root سایت خودتان (اغلب public_html) آپلود کنید. هیچ فایل موجود، index.php، .htaccess، تنظیم SSL، ModSecurity یا وردپرس را تغییر ندهید. هیچ رمز یا SSH لازم نیست.

PHP نسخهٔ 7.4 یا جدیدتر و JSON لازم است. هیچ Composer/نصب افزونه/سرویس پس‌زمینه‌ای وجود ندارد. فقط روی سایت خودتان یا با مجوز مالک و مطابق سیاست میزبان استفاده شود.

زمان انقضای مطلق UTC: **2026-10-26T05:47:49Z**. این زمان از نخستین بازدید محاسبه نمی‌شود و فایل بعد از انقضا خودکار پاک نمی‌شود. پس از آزمون فایل را حذف کنید. اگر دیر اقدام کردید و پیام temporary_probe_expired گرفتید، فایل تازه درخواست کنید.

قالب آدرس: `https://YOUR-DOMAIN/ufw-probe-0ad0686e27256f475d32.php`. در مرورگر باید JSON شامل ready:true دیده شود. اگر کد PHP به‌صورت متن/دانلود دیده شد، فایل را حذف و ادامه را متوقف کنید. خطای SSL را نادیده نگیرید. اگر سایت به www هدایت می‌شود، آدرس نهایی صحیح را برای ابزار استفاده کنید.

فایل احراز هویت ندارد و نام تصادفی جای آن نیست؛ هیچ دادهٔ حساس نفرستید. POST فقط JSON کوتاهِ challenge را می‌پذیرد و همان را همراه REMOTE_ADDR برمی‌گرداند. نه فایل می‌نویسد، نه shell/فرمان اجرا می‌کند، نه فایل دیگر یا وردپرس را بارگذاری می‌کند و نه درخواست خروجی شبکه می‌زند. GET فقط وضعیت و زمان انقضاست. هاست ممکن است طبق تنظیمات خودش لاگ مسیر/IP نگه دارد. IP برگشتی ممکن است متعلق به پراکسی باشد و اثبات VPN نیست.

این فایل در محیط توسعه فقط بررسی استاتیک شده و PHP روی هاست هنوز آزمایش نشده است. بعد از آپلود، از بستهٔ ویندوز ۰٫۸٫۰ فقط HTTPS-Endpoint-Check.cmd را معمولی اجرا کنید؛ URL کامل و IP سایت را بدهید و I CONTROL THIS TEST ENDPOINT را تأیید کنید. این مرحله یک درخواست HTTPS می‌زند و فایروال/VPN را تغییر نمی‌دهد. سپس Export-Lab-Results.cmd → EXPORT و گزارش UnifiedFW-080-LabResults را ارسال کنید. فعلاً آزمون تغییر فایروال را اجرا نکنید.

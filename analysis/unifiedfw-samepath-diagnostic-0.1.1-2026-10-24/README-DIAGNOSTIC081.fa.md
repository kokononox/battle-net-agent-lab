# افزونهٔ تشخیصی همان‌مسیر ۰.۱.۱ برای Unified Firewall ۰.۸.۱

**افزونه است، نه برنامهٔ مستقل و نه نسخهٔ جدید فایروال.** برای حذف تفاوت مسیر EXE در آزمون تشخیصی قبلی، دقیقاً از `runtime/python.exe` و `runtime/pythonw.exe` داخل پوشهٔ ۰.۸.۱ که آزمون آخر در آن اجرا شد استفاده می‌کند. هیچ runtime تازه، مهاجرت ژورنال یا فایل جایگزین برای برنامهٔ اصلی ندارد.

## محل استخراج — این بار داخل همان پوشه، نه یک پوشهٔ جدید

محتویات ZIP را در **همان پوشهٔ آزمایش‌شدهٔ ۰.۸.۱** استخراج کنید؛ جایی که `HTTPS-Coexistence-Test.cmd` و پوشه‌های `runtime`، `lab` و `private-state` وجود دارند. ساختار نهایی باید چنین باشد:

```text
Unified-Firewall-0.8.1/
  HTTPS-Coexistence-Test.cmd        (قبلی؛ تغییر نکند)
  runtime/                          (قبلی؛ تغییر نکند)
  lab/                              (قبلی؛ تغییر نکند)
  private-state/                    (قبلی؛ پاک نشود)
  Start-Connectivity-SamePath.cmd   (جدید)
  diagnostic081/                    (جدید)
  DIAGNOSTIC081-SHA256.json         (جدید)
  DIAGNOSTIC081-BUILD-INFO.json      (جدید)
  README-DIAGNOSTIC081.fa.md         (جدید)
```

ZIP در ریشهٔ خود همین موارد جدید را دارد؛ یک پوشهٔ بیرونی اضافه لازم نیست. برای اولین نصب نباید هیچ فایل اصلی ۰.۸.۱ جایگزین شود. اگر دربارهٔ جایگزینی فایل اصلی سؤال شد، استخراج را متوقف و محل را بررسی کنید. **پوشهٔ ۰.۸.۱ را جابه‌جا یا از نو استخراج نکنید و گزارش/ژورنال قبلی را حذف نکنید.**

## اجرا

۱. VPN همان وضعیت متصل قبلی را داشته باشد. آزمون کامل، ابزارهای فایروال قبلی یا برنامهٔ دیگری با runtimeهای همین بسته هم‌زمان اجرا نشوند. چیزی روی هاست تغییر ندهید.
۲. `Start-Connectivity-SamePath.cmd` را با دوبار کلیک معمولی اجرا کنید؛ Administrator لازم نیست و UAC درخواست نمی‌شود.
۳. همان URL کامل HTTPS فایل PHP و همان IPv4 منتخبِ آزمون آخر ۰.۸.۱ را وارد کنید؛ سپس وضعیت VPN را `ON` بنویسید.
۴. تأیید مالکیت/مجوز مقصد: `I CONTROL THIS TEST ENDPOINT`.
۵. تا پایان ۱۸ تلاش صبر کنید؛ معمولاً ۱ تا ۳ دقیقه، در خطا/کندی بیشتر. برای توقف از Ctrl+C استفاده کنید؛ ذخیرهٔ گزارش ناقص تلاش می‌شود. بستن اجباری ممکن است ساخت ZIP را قطع کند؛ این ابزار قاعده‌ای ندارد که نیاز به Restore داشته باشد.
۶. خروجی **خودکار کنار همان CMD** ساخته می‌شود: `UnifiedFW-SamePath-Results-....zip`. آن را بررسی و ارسال کنید. Export-Lab-Results.cmd قبلی لازم نیست.

## کنترل‌های پیش از شبکه

- manifest دقیق بستهٔ تحویلی ۰.۸.۱ pin شده و همهٔ اعضای آن، سپس فایل‌های افزونه، با SHA256 کنترل می‌شوند. فایل اشتباه، تغییرکرده، symlink/reparse یا محل اشتباه رد می‌شود. manifest امضای ناشر نیست.
- آخرین گزارش غیر read-only هم‌زیستی از همین پوشه خوانده می‌شود. باید از آزمون paced باشد و بازیابی/برابری سیاست تمام phaseهای ثبت‌شده و top-level Restore تأیید شده باشند. به‌جای گزارش جدید ناقص/drifted، گزارش قدیمی خوب انتخاب نمی‌شود.
- مسیر و hash دو runtime با request ثبت‌شدهٔ همان آزمون، و مقصد با نتیجهٔ قبلی، باید یکسان باشند. این کنترل **وابستگی به مسیر ثابتِ داخل کد ندارد**؛ مسیر از پوشهٔ فعلی و request قبلی مقایسه می‌شود.
- اگر آخرین گزارش بازیابی‌نشده، مقصد/مسیر متفاوت یا پوشهٔ تازه باشد، قبل از درخواست مقصد متوقف می‌شود. خطا را بفرستید؛ برای عبور از کنترل، گزارش/ژورنال را پاک یا فایل‌ها را دستکاری نکنید.
- گزارش Restore قبلی، مشاهدهٔ تاریخی است؛ این ابزار NetSecurity را query نمی‌کند، نشست محافظت‌شدهٔ ProgramData را باز نمی‌کند و وضعیت زندهٔ فعلی تمام قواعد را اثبات نمی‌کند. به همین دلیل هم‌زمان آزمایش دیگری نباید اجرا شود.

## دامنهٔ دقیق

هیچ قاعدهٔ فایروال، route، VPN، DNS، hosts، trust store، profile، سرویس یا ExecutionPolicy تغییر نمی‌کند. فقط فایل‌های محلی گزارش/قفل و درخواست‌های HTTPS مجاز ایجاد می‌شوند. شش اتصال برای هر A/B/REF، جمعاً ۱۸ تلاشِ ترتیبی، فاصلهٔ چهار ثانیه پس از هر تلاش، مهلت TCP سه ثانیه و **retry صفر** حفظ شده است. مرجع PowerShell فرایندی جدا با .NET SslStream است. timeout اجرای child خطای اجراست، نه موفقیت بلاک.

DNS اولیه باید IPv4 منتخب را در پاسخ همان hostname داشته باشد. فقط همان IPv4:443 استفاده می‌شود؛ hostname برای SNI/Host/گواهی است. هیچ fallback IP، proxy HTTP، redirect یا HTTP بدون TLS وجود ندارد. نام/زنجیرهٔ TLS با روش پیش‌فرض Python/.NET تأیید می‌شود؛ اعتبارسنجی خاموش نمی‌شود. سرویس‌های سیستم بررسی زنجیره ممکن است ترافیک مستقل داشته باشند؛ ادعای «هیچ ترافیک سیستمی دیگر» نداریم.

این آزمون یکسان‌بودن همهٔ شرایط دو اجرای جدا در زمان‌های متفاوت را تضمین نمی‌کند؛ فقط تفاوت مسیر EXE قبلی را کنترل می‌کند. ۱۸ تلاش هم‌ارز بار/۱۲۶ تلاش آزمون کامل نیست. حتی موفقیت همهٔ آن‌ها علت timeout، نبود rule خارجی، هم‌زیستی WL/BL، مسیر قطعی VPN یا نبود نشت را ثابت نمی‌کند. هیچ تست بدون VPN، endpoint دوم، packet capture یا دسترسی SSH خودکار اضافه نشده است. **فعلاً آزمون کامل ۰.۸.۱ تکرار نشود.**

PHP قبلی انقضای مطلق `2026-10-26T05:47:49Z` دارد؛ دانلود این افزونه زمان را تمدید نمی‌کند. پاسخ 410 پس از انقضا اختلال شبکه نیست و باید فایل تازه تهیه شود. پس از پایان بررسی، فایل PHP از هاست حذف شود. تنظیمات امنیتی هاست/ModSecurity/SSL خاموش نشوند.

ZIP خروجی فقط result، دو Build Info و هش‌هاست؛ request خام، nonce، گزارش قبلی کامل، ژورنال، کلید و stderr کامل محلی را صادر نمی‌کند. URL، IP، مسیر EXE، زمان‌ها و بخشی از خطای اجرا ممکن است داخل result باشد؛ پیش از ارسال بررسی شود. هیچ فایل خودکار آپلود نمی‌شود.

تست‌های ساخت روی Linux شامل واحدهای کنترلر/مسیر، overlay روی یک کپی واقعی بستهٔ ۰.۸.۱ بدون جایگزینی فایل اصلی، و TLS واقعی محلی مثبت/منفی Python/.NET بوده‌اند. **خود افزونهٔ ۰.۱.۱ هنوز روی Windows کاربر اجرا نشده است.** تست‌ها باید روی کپی توسعه و با fixture انجام شوند، نه پوشهٔ آزمایش کاربر. رابط گرافیکی یا نسخهٔ نهایی امنیتی در این افزونه ساخته نشده است.

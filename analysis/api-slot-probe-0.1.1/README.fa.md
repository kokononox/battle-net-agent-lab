# WLab APIProbe 0.1.1

نسخهٔ اصلاح‌شدهٔ آزمون محدود اسلات `wow_loader.dll + 0x20A0750` است؛ مسئلهٔ اصلیِ CPU/BIOS → serialization → TCP/3724 هنوز حل نشده است.

## اصلاح مشخص
در اجرای نسخهٔ 0.1.0، ابزار به‌علت فرض برابری AllocationBase و ModuleBase پیش از هر RPM متوقف شد. گزارش کاربر نشان داد AllocationBase دقیقاً برابر ابتدای بخش `.rdata` فایل پین‌شده است. نسخهٔ جدید آن حالت هندسی را تنها همراه با **بررسی مستقل مسیر فایلِ پشت نگاشت و هش فایل بازشده** می‌پذیرد؛ شرط قبلی کورکورانه حذف نشده است.

- با `K32GetMappedFileNameW` نام NT فایل پشت آدرس اسلات و ابتدای allocation گرفته می‌شود؛ این پرسش metadata است و فراخوانی RPM دیگری نیست.
- با `GetFinalPathNameByHandleW(VOLUME_NAME_NT)` مسیر نهایی یک handle فقط‌خواندنی از DLL گرفته می‌شود و SHA-256 از **همان handle** محاسبه می‌شود.
- هر دو نام نگاشت باید با مسیر نهایی فایل پین‌شده منطبق باشند. خطا، مسیر ناشناخته/متفاوت، hash نادرست یا نگاشت نامعتبر، پیش از RPM باعث توقف می‌شود. fallback یا تلاش خودکار دیگری وجود ندارد.
- همین بررسی بعد از نمونه نیز تکرار می‌شود. تغییر یا شکست بررسیِ پس از خواندن، pointer را از نتیجهٔ معتبر حذف می‌کند.
- عنوان پنجرهٔ monitor داخلی نیز با عنوان واقعی APIProbe هماهنگ شد. تست قرارداد عنوان اضافه شده است.

## اجرا و خروجی
`START-HERE.txt` را دنبال کنید. خروجی کوچک روی **درایو خود بازی** در WLabAPIProbe ذخیره می‌شود؛ لاگ‌های کوچک launcher و lock مشترک در LocalAppData هستند. فقط READY-TO-SEND.zip را ارسال کنید. نیازی به نصب Python، Go، debugger یا ProcDump نیست.

## حدود ثابت
- فقط Windows AMD64، Windows PowerShell و دو فایل دقیق قبلی:
  - Wow.exe SHA-256: `1c51e68c00e7183c2c187606d2c443c27252a629406454de4afec336e8c5753a`
  - wow_loader.dll SHA-256: `c0a3c393db5cee834387e4f151fb97b109370330a0ed02310f597cad999b6b0c`
- دسترسی فرایند فقط query/read است؛ debugger، driver، injection، تغییر حفاظت، نوشتن در بازی یا فعال‌سازی SeDebugPrivilege ندارد.
- حداکثر **یک درخواست مستقیم ReadProcessMemory برای دقیقاً ۸ بایت** در آدرس ثابت. هیچ header یا صفحهٔ کد خوانده نمی‌شود. metadata و فایل‌های دیسک از این سقف مجزا هستند؛ این سقف ادعایی دربارهٔ جزئیات داخلی APIهای ویندوز نیست.
- PAGE_GUARD، PAGE_NOACCESS، MEM_PRIVATE، identity/hash/bounds نامعتبر یا منشأ نامشخص → توقف بدون RPM. برای allocation جدا فقط هندسهٔ دقیق بخش `.rdata` همین فایل پین‌شده مجاز است.
- `read_helper_requested` در run.json صرفاً درخواست اجرای helper است. تعداد واقعی درخواست/بایت در `analysis.json` ثبت می‌شود.
- pointer فقط با exportهای دقیق فایل دیسکی kernel32.dll، KernelBase.dll و ntdll.dll در SystemDirectory و assertion امضای Valid/Microsoft/hash-matched تطبیق داده می‌شود. aliases حفظ می‌شوند؛ forwarder، offset تقریبی و trampoline تعقیب نمی‌شوند.
- Cancel فقط helper خود ابزار را متوقف می‌کند؛ بازی terminate نمی‌شود. timeout helper برابر ۴۵ ثانیه است؛ بازگشت فوری همهٔ عملیات OS تضمین نمی‌شود.
- ZIP گزارش فقط JSON و stdout/stderr/resultهای کوچکِ allowlist را دارد؛ فایل بازی، DLL، دامپ یا باینری حافظه در آن نیست. مسیرهای محلی و PID ممکن است در گزارش باشند.

## تفسیر و محدودیت
`api_slot_sample_complete` فقط معتبرشدن نمونه در کنترل‌های ابزار است؛ `signed_disk_export_address_match` فقط برابری آدرس با export دیسکیِ بررسی‌شده است. `unresolved` یعنی نام API مشخص نشده؛ `read_stopped` یعنی باید همان علت گزارش شود و تست تکرار نشود.

بررسی نام NT و هش، اثبات یکسان‌بودن file-object، offset نگاشت، دست‌نخورده‌بودن کد زنده یا نبود race نیست؛ مدل همچنان متناظربودن layout زنده با تصویر را فرض می‌کند. هیچ EAT یا کد زنده‌ای برای بررسی این فرض خوانده نمی‌شود. assertion امضا از GUI مرز امنیتی مستقل در برابر دستکاری محلی نیست.

ابزار upload یا download خودکار ندارد؛ اعتبارسنجی امضای Windows ممکن است مطابق تنظیمات OS از cache یا سرویس شبکهٔ اعتماد استفاده کند. صفر بودن کل ترافیک سیستم ادعا نمی‌شود.

**اجرای واقعی نسخهٔ جدید روی Windows در محیط سازنده آزمایش نشده است.** تست‌های fake target، نمونهٔ هندسی گزارش قبلی، childهای خود ابزار، cross-compile و AST روی Linux معادل تست بازی نیستند؛ عادی‌ماندن بازی تضمین نمی‌شود. EXE unsigned است. برای اجرای آن تنظیم امنیتی را غیرفعال نکنید.

فرضیهٔ SetUnhandledExceptionFilter هنوز نتیجهٔ زنده نیست. اگر API مدیریت خطای استاندارد مشخص شد، این شاخه به‌عنوان سرنخ مستقیم رمزگشا کنار گذاشته می‌شود؛ اگر نگاشت یا API نامشخص ماند و اتصال مستقلی به صفحات هدف نبود، شاخه پارک می‌شود. این یک تلاش اصلاح‌شدهٔ محدود است، نه مجوز دنبال‌کردن آدرس‌های بیشتر.

منبع و QA همراه بسته‌اند؛ main و BIOS Path GUI 0.2 تغییر نکرده‌اند.

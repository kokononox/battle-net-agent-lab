WLab APIProbe 0.1.1 — جایگزین 0.1.0

1) ZIP را کامل Extract کن؛ نسخهٔ قبلی را اجرا نکن. همان بازی آزمایشی باز باشد.
2) WLab-APIProbe-0.1.1.exe را اجرا کن؛ اگر UAC درخواست شد اجازه بده.
3) Wow.exe و صفحهٔ فعلی بازی را انتخاب کن و تیک رضایت را بزن.
4) فقط یک بار Identify API once را بزن.
5) READY-TO-SEND.zip را از پوشهٔ نتیجه بفرست و بگو بازی عادی ماند یا نه.

خروجی کوچک روی درایو بازی داخل WLabAPIProbe ذخیره می‌شود. دامپ ساخته نمی‌شود.
این نسخه قبل از خواندن، مسیر فایل پشت نگاشت را مستقل از فهرست ماژول‌ها بررسی می‌کند.
اگر فایل نگاشت ناشناس، متفاوت یا غیرقابل بررسی باشد، بدون خواندن حافظه متوقف می‌شود.
نیازی به نصب Python، Go، debugger یا ProcDump نیست؛ Windows PowerShell داخلی لازم است.
EXE امضای ناشر ندارد و اجرای ویندوز واقعی در محیط سازنده آزمایش نشده است.
اگر Windows یا نرم‌افزار امنیتی مانع شد، آن را غیرفعال نکن؛ متن خطا را بفرست.
در صورت خطا تست را تکرار نکن. این ابزار رمزگشا یا شاهد ارسال اطلاعات نیست.

WLab APIProbe 0.1.0 — آزمون محدود، یک بار

1) ZIP را کامل Extract کن. بازیِ آزمایشیِ همان نسخه باز باشد.
2) WLab-APIProbe-0.1.0.exe را اجرا کن؛ در صورت درخواست UAC اجازه بده.
3) Wow.exe را انتخاب کن، صفحهٔ فعلی بازی را مشخص کن و تیک رضایت را بزن.
4) فقط یک بار Identify API once را بزن. ابزار تلاش را خودکار تکرار نمی‌کند.
5) پوشهٔ نتیجه باز می‌شود؛ فقط READY-TO-SEND.zip را بفرست و بگو بازی عادی ماند یا نه.

خروجی کوچک روی درایو بازی در WLabAPIProbe قرار می‌گیرد. دامپ چندگیگابایتی ساخته نمی‌شود.
نیازی به نصب Python، Go، debugger یا ProcDump نیست. Windows PowerShell داخلی ویندوز لازم است.
ابزار unsigned است؛ در این محیط روی ویندوز واقعی اجرا نشده. اگر Windows یا نرم‌افزار امنیتی مانع شد، غیرفعالش نکن؛ متن خطا را بفرست.
اگر توقف/خطا دیدی، دوباره امتحان نکن؛ همان گزارش را بفرست.
این آزمون نه رمزگشا است و نه اثبات ارسال اطلاعات سخت‌افزاری.

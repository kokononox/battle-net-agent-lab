# WLab APIProbe 0.1.0

## هدف و معیار پایان
آزمون فقط ابهام اسلات API در `wow_loader.dll + 0x20A0750` را کاهش می‌دهد. فرضیهٔ فعلی **SetUnhandledExceptionFilter** است؛ هنوز تأیید نشده. رابطهٔ استاتیک return→local→slot قبلاً بررسی شده، نه اجرای آن در زمان زنده.

اگر تطبیق معتبرِ آدرس با export مدیریت خطای استاندارد حاصل شود، این شاخه به‌عنوان مسیر مستقیم جست‌وجوی رمزگشا کنار گذاشته می‌شود. این نتیجه دربارهٔ همهٔ handlerهای ممکن یا کل برنامه حکم نمی‌دهد. اگر تطبیق نامشخص باشد و اتصال مستقلی به صفحات هدف نداشته باشیم، شاخه پارک می‌شود؛ آدرس‌های تازه بدون معیار دنبال نمی‌شوند.

مسئلهٔ اصلیِ CPU/BIOS → population/serialization → ارسال TCP/3724 همچنان باز است. آزمون حاضر شاهد جمع‌آوری یا ارسال، رمزگشایی، کلید یا اجرای یک callback تولید نمی‌کند.

## اجرا
`START-HERE.txt` را دنبال کنید. خروجی کوچک روی **درایو خود بازی** در `WLabAPIProbe` ذخیره می‌شود؛ روی C جایگزین نمی‌شود. تنها لاگ‌های کوچک launcher و فایل lock مشترک در LocalAppData ذخیره می‌شوند. فایل گزارش `READY-TO-SEND.zip` است. بازی یا ابزارهای قبلی را همراه گزارش نفرستید.

## محدودیت‌های فنی
- Windows AMD64، Windows PowerShell و همان دو فایل دقیق قبلی لازم‌اند:
  - Wow.exe: `1c51e68c00e7183c2c187606d2c443c27252a629406454de4afec336e8c5753a`
  - wow_loader.dll: `c0a3c393db5cee834387e4f151fb97b109370330a0ed02310f597cad999b6b0c`
- PID و creation FILETIME، مسیرها، هش دیسک و اندازهٔ تصویر با module metadata کنترل می‌شوند. تطبیق فایل دیسک، همسان‌بودن همهٔ بایت‌های تصویر زنده را اثبات نمی‌کند.
- دسترسی فرایند فقط query/read است؛ SeDebugPrivilege فعال نمی‌شود. ابزار driver، injection، debugger، full dump، PSS، تغییر حفاظت یا نوشتن در بازی ندارد.
- برای آدرس ثابت، VirtualQueryEx پیش از خواندن اجرا می‌شود. PAGE_NOACCESS، PAGE_GUARD، MEM_PRIVATE، مرز یا allocation نامعتبر باعث توقف بدون RPM می‌شوند.
- حداکثر **یک فراخوانی مستقیم ReadProcessMemory با اندازهٔ دقیق ۸ بایت** وجود دارد. هیچ header یا صفحهٔ کدی خوانده نمی‌شود. metadata enumeration و خواندن فایل‌های دیسک جدا از این سقف‌اند. این ادعا ناظر به درخواست صریح ابزار است، نه جزئیات داخلی سرویس‌های ویندوز.
- پس از خواندن، هویت/نگاشت و هش‌های انتخابی دوباره بررسی می‌شوند؛ شکست آن‌ها pointer را از نتیجهٔ معتبر حذف می‌کند. این مراحل snapshot اتمیک یا تضمین نبود race نیستند.
- pointer فقط با moduleهای فهرست‌شده و exportهای **فایل دیسکی** kernel32.dll، KernelBase.dll یا ntdll.dll در SystemDirectory تطبیق داده می‌شود. تطبیق باید دقیق باشد؛ aliases حفظ می‌شوند؛ forwarder و offset تقریبی یا trampoline دنبال نمی‌شوند.
- GUI با Get-AuthenticodeSignature و Get-FileHash assertion امضا را می‌سازد. hash/status/subject با فایل مالک تطبیق داده می‌شود. trust.json مرز امنیتی مستقل در برابر دستکاری محلی نیست. هیچ EAT یا کد زنده‌ای برای اثبات دست‌نخوردگی خوانده نمی‌شود.
- ابزار کد دانلود یا ارسال خودکار ندارد. بررسی امضای Windows ممکن است طبق تنظیمات سیستم از cache یا سرویس‌های اعتبارسنجی OS استفاده کند؛ صفر بودن کل ترافیک سیستم ادعا نمی‌شود.
- Cancel فقط helper خود ابزار را متوقف می‌کند؛ بازی terminate نمی‌شود. وقفهٔ ۴۵ثانیه‌ای برای helper تضمین نمی‌کند عملیات سیستم‌عامل همیشه فوراً برگردند. نتیجهٔ ناقص باید ارسال شود، نه با تلاش‌های متعدد جایگزین.
- READY-TO-SEND فقط JSON و stdout/stderr/resultهای کوچکِ allowlist را شامل می‌شود، نه فایل بازی/دامپ/باینری حافظه. گزارش ممکن است مسیر محلی و PID داشته باشد.

## معنی وضعیت‌ها
- `api_slot_sample_complete`: نمونهٔ ۸‌بایتی از کنترل‌های ابزار گذشته؛ به‌تنهایی شناسایی API نیست.
- `signed_disk_export_address_match`: آدرس نمونه با export نام‌دار فایل دیسکیِ امضاشده منطبق است، با فرض متناظر بودن layout زنده. اثبات اجرای API یا دست‌نخورده بودن کد نیست.
- `unresolved`: تطبیق کافی نداریم؛ نام API حدس زده نمی‌شود.
- `read_stopped`: آماده‌سازی/دسترسی/کنترل‌ها شکست خورده؛ گزارش علت و تعداد بایت/درخواست را نگه می‌دارد.

## اعتبارسنجی و محدودیت تحویل
منبع، تست‌های mock، ساخت cross-compile و نتیجهٔ QA همراه بسته است. تست‌های fake target، childهای خود ابزار و PowerShell روی Linux معادل اجرای ویندوز یا تست بازی نیستند. **روی ویندوز واقعی در این محیط آزمایش نشده** و عادی‌ماندن بازی تضمین نمی‌شود. فایل EXE امضای ناشر ندارد. برای اجرا هیچ تنظیم امنیتی را غیرفعال نکنید. نیازی به نصب کامپایلر روی رایانهٔ کاربر نیست.

شاخهٔ main و BIOS Path GUI 0.2 تغییر داده نمی‌شوند؛ این ابزار مستقل است.

SSTP Read-only Observer 0.2
===========================
این بسته مشاهده‌گر هویت است، نه نسخه جدید فایروال، نه اتصال‌دهنده VPN و نه مجوز Apply.
روی برنامه فعلی کپی نشود. در یک پوشه مستقل محلی Extract شود.

اجرا
- وضعیت VPN را عوض نکن: نه قطع، نه وصل و نه تغییر پروفایل لازم است.
- وقتی Apply/Restore در حال اجرا نیست، Run-Observer.cmd را با Run as administrator اجرا کن؛ از همان حساب Windows که پروفایل VPN در آن است. با حساب مدیر دیگری اجرا نشود.
- اگر دقیقاً یک پروفایل SSTP قابل مشاهده باشد، فقط برای تشخیص انتخاب می‌شود. این انتخاب تأیید امنیتی یا اجازه استفاده در firewall نیست.
- اگر چند پروفایل یا موجودی نامعلوم باشد، ابزار به‌جای حدس متوقف و گزارش می‌سازد.
- فایل جدید SSTP-OBSERVER-02-*.json از همین پوشه را برگردان، حتی اگر diagnostic_completed=false شد. در صورت خطای پیش از ساخت گزارش، متن مرحله/کد خطا کافی است.

چه می‌خواند؟
- metadata پروفایل‌های CurrentUser و AllUsers، بدون فراخوانی API خواندن رمز.
- وقتی قطع است: همان GUID/scope/name/server و full-tunnel بودن، نبود اتصال RAS متناظر و بازخوانی پایدار.
- وقتی متصل است: GUID پروفایل و scope به RAS، handle/correlation نشست، آدرس PPP کلاینت، interface GUID/index/NET_LUID و بازخوانی هویت مرتبط می‌شوند. نام رابط به‌تنهایی مرجع هویت نیست.
- alias ناامن یا ابهام، اتصال VPN دیگر، تغییر سرور یا تغییر در حین خواندن موفقیت محسوب نمی‌شود.
- helper فعلی projection IPv4 را پشتیبانی می‌کند؛ نبود آن، IPv6-only یا رفتار نامعلوم نتیجه ناموفق/نیازمند بررسی می‌دهد، نه اجازه گسترده.

چه نمی‌کند؟
هیچ Apply، Restore، reset، تغییر rule/profile/route/hosts/DNS/VPN، dial/hangup، درخواست اینترنت، probe شبکه، اعتبارسنجی bootstrap گواهی یا فعال‌کردن guardian انجام نمی‌شود. ارتباطی با بازی یا نصب‌گر برقرار نمی‌کند. خاموش‌کردن بررسی TLS/گواهی وجود ندارد.

اطلاعات خصوصی
نام/آدرس VPN، GUID و LUID، IP کلاینت، handle و binding خام فقط در حافظه همان پردازش استفاده می‌شوند؛ در JSON نوشته یا ذخیره دائمی نمی‌شوند. گزارش فقط وضعیت‌ها، boolها و کدهای ثابت خطا را دارد. این ابزار هیچ چیزی را خودکار ارسال نمی‌کند.

راه‌انداز
ابتدا هش manifest پین‌شده و فایل‌ها را بررسی می‌کند؛ فقط چهار PS1 همین بسته را Unblock می‌کند. RemoteSigned فقط برای پردازش فرزند انتخاب می‌شود و تنظیم دائمی ExecutionPolicy تغییر نمی‌کند. محدودیت Group Policy دور زده نشود.
helper C# از سورس محلی با Add-Type کامپایل می‌شود؛ کامپایلر ممکن است فایل موقت معمول خود را بسازد. فایل گزارش نیز در همین پوشه نوشته می‌شود. عبارت فقط‌خواندنی ناظر به شبکه/پروفایل/credential است، نه ادعای نبود هرگونه نوشتن فایل در سیستم.

حد تأیید
۸۴ بررسی مدل در Linux و بررسی layout/helper کامپایل‌شده انجام شده، نه اجرای DLLهای بومی ویندوز. نتیجه Windows هنوز لازم است. موفقیت تشخیص هویت، endpoint سرور، آماده‌بودن DNS/TLS، شروع مجدد VPN، اجرای ایزولاسیون یا نبود نشتی را تأیید نمی‌کند. snapshot اتمیک نیست.

نکته معماری
پروفایل CurrentUser باید در context همان SID بررسی شود. SYSTEM نمی‌تواند به‌جای کاربر، CurrentUser خود را همان پروفایل فرض کند. این بسته فقط مشاهده می‌کند؛ روش نهایی هماهنگی محافظ SYSTEM با context کاربر هنوز ساخته نشده است.

# مشاهده محدود رفتار آغاز اجرای بتل‌نت

این آزمایش فقط روی ماشین ویندوز موقت و تازه GitHub اجرا می‌شود. نسخه رسمی bootstrap از مسیر موجود و با کنترل Authenticode/ناشر Blizzard دریافت می‌شود؛ نسخه آن ممکن است با Agent قدیمی 9824 و سیستم کاربر متفاوت باشد. هیچ بازی یا حسابی روی ماشین وجود ندارد.

دامنه اقدام: اجرای bootstrap، یک تلاش از پیش محدودشده برای انتخاب English US و Continue صفحه زبان با helper موجود؛ نه نصب کلاینت از صفحه بعد، نه پذیرش حقوقی، نه ورود به حساب، نه درخواست دانلود بازی. حداکثر ۱۲۰ ثانیه مشاهده پس از اجرا؛ کل job حداکثر ۹ دقیقه. حجم دانلود اولیه bootstrap تا ۱۲۸ MiB محدود است ولی ترافیک فرزندان سقف سخت بایتی ندارد. این آزمون، آزمون آپدیت WoW نیست.

شواهد:
- نمونه‌برداری TCP هر ۲۵۰ میلی‌ثانیه: نام فرایند/PID، IP عمومی و پورت مقصد، وضعیت و زمان اولین/آخرین مشاهده. انتساب بر پایه نام/PID است، نه اثبات امضای تک‌تک فرایندها؛ PID می‌تواند بازیافت شود. UDP/QUIC و اتصال‌های کوتاه ممکن است دیده نشوند. تعداد نمونه، تعداد بایت یا درخواست نیست.
- مقایسه cache سیستم DNS قبل/بعد، فقط برای پیشنهاد نام‌هایی که IP یکسان دارند؛ این روش نه انتساب DNS به فرایند را ثابت می‌کند نه hostname دقیق اتصال را. برای این کار reverse DNS یا درخواست حل نام اضافی ارسال نمی‌شود. cache همگانی ماشین است و با فعالیت سیستم مخلوط می‌شود؛ خطای cache به‌روشنی گزارش می‌شود.
- قراردادن SSLKEYLOGFILE در محیط پاک فرایند فرزند؛ فقط وجود فایل و شمار خطوط با قالب شناخته‌شده گزارش می‌شود. کلیدها هرگز منتشر نمی‌شوند و فایل حذف می‌شود. این اجرا packet capture ندارد و رمزگشایی واقعی را ادعا نمی‌کند. خروجی صفر به معنی نبود TLS یا telemetry نیست.
- گزارش قبلی bootstrap، امضا/هش و وضعیت GUI جداگانه حفظ می‌شود.

فقط دو JSON با schema سفیدلیست منتشر می‌شود، نه log، فایل اجرایی، کلید TLS یا payload. اجرای مجدد job مجاز نیست. نتیجه کامل‌شدن جمع‌آوری با موفقیت bootstrap/آپدیت یا تضمین عدم ارسال سخت‌افزار متفاوت است. خروجی فقط همان نسخه و همان بازه را توصیف می‌کند.

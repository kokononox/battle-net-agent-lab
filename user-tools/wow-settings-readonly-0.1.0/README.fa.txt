خواندن محدود تنظیمات WoW — بدون تغییر یا ارتباط شبکه

۱. ZIP را در یک پوشه معمولی Extract کنید. Administrator لازم نیست.
۲. Start.cmd را اجرا کنید و فایل _retail_\WTF\Config.wtf مربوط به همان بازی را انتخاب کنید.
۳. فقط فایل settings-result-....json ساخته‌شده کنار ابزار را ارسال کنید؛ خود Config.wtf را نفرستید.
اگر اجرا با سیاست اسکریپت مسدود شد، متن خطا را بفرستید؛ لازم نیست policy یا حفاظت ویندوز را عوض کنید.

این ابزار فقط هفت نام مشخص را بررسی می‌کند؛ مسیر کامل، تنظیمات حساب، تنظیمات دیگر و مشخصات واقعی CPU/BIOS در گزارش صادر نمی‌شوند. مقدارهای خارج از الگوی موردانتظار نیز حذف می‌شوند. هیچ درخواست DNS/HTTP، attach، certificate، تغییر firewall/hosts یا نوشتن روی فایل بازی/Config وجود ندارد. تنها فایل خروجی تازه ایجاد می‌شود.

این گزارش مقدارهای صریحِ فایل منتخب را نشان می‌دهد، نه مقدار مؤثر runtime یا پیش‌فرض بازی. نبود کلید به معنی خاموش/صفر نیست؛ چند مقدار تکراری بدون فرض اولویت حفظ می‌شوند. اگر بازی هم‌زمان فایل را تغییر دهد snapshot اتمی تضمین نمی‌شود. این ابزار تشخیص خودکار نصب/نسخه را انجام نمی‌دهد؛ انتخاب Config درست به عهده کاربر است.

engineSurvey و engineSurveyPatch کلید روشن/خاموشِ اثبات‌شده نیستند. آن‌ها را براساس نامشان صفر یا حذف نکنید. optOutIngameSurveys طبق متن تعبیه‌شده به دریافت survey مربوط است و شاهد خاموش‌کردن telemetry سخت‌افزار نیست. shop2TelemetryAllowed هم اثبات کنترل گزارش CPU/BIOS نیست.

آزمون محلی: ۱۶ بررسی منطق/خواندن فایل با PowerShell 7.4.7 روی Linux پاس؛ پنجرهٔ انتخاب فایل و اجرای واقعی Windows/Windows PowerShell 5.1 در این محیط آزموده نشده‌اند. بدون runtime یا dependency دانلودی است؛ از Windows PowerShell موجود استفاده می‌کند. ابزار اثبات ارسال/عدم ارسال داده نیست.

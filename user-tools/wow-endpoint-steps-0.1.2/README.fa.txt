WoW Endpoint Steps 0.1.2 — نسخهٔ بازبینی شش مقصد

برای ارتقا و روش آزمایش، UPDATE.fa.txt را بخوانید. Python از بستهٔ قبلی استفاده می‌شود؛ نصب یا تغییر ExecutionPolicy لازم نیست.

فقط برای Wow.exe انتخابی و یک مقصد IP/Port/TCP قانون ساخته می‌شود. Name و Group تصادفیِ ویژهٔ ابزار، journal قبل از ساخت، نگهبان پنج‌دقیقه‌ای، Restore.cmd و بررسی حذف حفظ شده‌اند. قانون در PersistentStore ذاتاً خودمنقضی نیست؛ نگهبان یا خود ابزار باید آن را حذف کنند. sleep/خاموشی/kill هم‌زمان یا خطای سیستم می‌تواند بازیابی را به تأخیر بیندازد. تا تأیید نبود قانون، پوشهٔ ابزار را حذف یا جابه‌جا نکنید.

بعد از ساخت و readback قانون، monitor فقط‌خواندنی شروع می‌شود: نمونه‌برداری TCP و خواندن رویدادهای مسدودسازی موجود Windows برای ۹۰ ثانیه. سیاست audit تغییر نمی‌کند. شما برای تست اتصال تازه بازی را عادی می‌بندید/باز می‌کنید؛ ابزار بازی یا حساب را کنترل نمی‌کند. ورود خودکار و تکرار خودکار login نداریم. در خطای احراز هویت دوباره تلاش نکنید.

پس از انتخاب مشاهده، خلاصهٔ monitor با JSON نتیجه ترکیب، قانون حذف و نبود آن کنترل می‌شود؛ سپس بازگشت رفتار عادی باید توسط شما تأیید شود. مرحلهٔ بعد خودکار شروع نمی‌شود. TCPهای کوتاه ممکن است از نمونه‌برداری جا بمانند، خواندن Security ممکن است ناممکن باشد و صفر نتیجه دلیل امنیتی نیست.

hosts، VPN، وایت‌لیست، تنظیم بازی، گواهی، ExecutionPolicy، audit policy و قوانین دیگر دست نمی‌خورند. packet_block_verified و rule_causality_proven عمداً false می‌مانند؛ WFP می‌تواند تصمیم block را نشان دهد ولی تطبیق آن با rule خاص انجام نشده است. محتوای TLS یا ارسال CPU/BIOS بررسی نمی‌شود.

گزارش اشتراکی output فقط hash، مقصدها، وضعیت سوکت، تعداد نمونه/رویداد و انتخاب‌های کاربر دارد. private-state شامل journal با مسیر بازی برای بازیابی است؛ هرگز آن را نفرستید. هیچ log خام Security یا اطلاعات ورود صادر نمی‌شود.

خطاهای فایروال: فقط firewall-error-….json را از output بفرستید و تا بازیابی تست تازه نکنید. اگر monitor آماده نشود، آزمایش باید متوقف و قانون بازیابی شود؛ ابزار به روش‌های پرخطر fallback نمی‌کند. در صورت شک، کنسول را ببندید و Restore.cmd را با Administrator اجرا کنید.

۵۶ آزمون محلی/mock پاس شده‌اند؛ اجرای واقعی این monitor روی Windows/بازی توسط سازنده آزمایش نشده است. اولین اجرا فقط یک مرحله باشد.

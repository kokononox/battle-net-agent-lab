اصلاحیهٔ WoW Endpoint Steps 0.1.1 — روی پوشهٔ قبلی نصب شود

۱) برنامهٔ قبلی و کنسول اصلی آن را ببندید. حداقل پنج دقیقه از شروع مرحلهٔ ناموفق بگذرد؛ این انتظار به‌تنهایی ثابت نمی‌کند قانون حذف شده است.
۲) محتوای ZIP اصلاحیه را مستقیماً داخل همان پوشه‌ای استخراج کنید که Start.cmd قبلی در آن است. اجازهٔ جایگزینی فایل‌های app، tests، راهنما، QA و manifest را بدهید. runtime، private-state و output را حذف یا جابه‌جا نکنید. این بستهٔ اصلاحیه Python را دوباره همراه ندارد و مستقل قابل اجرا نیست.
۳) Restore.cmd را با Run as administrator اجرا کنید. فقط اگر پیام Verified: no rules from this package journals remain نمایش داده شد، Start.cmd را اجرا کنید. اگر خطا داد ادامه ندهید؛ فایل جدید firewall-error-….json در output را بفرستید. private-state را نفرستید.
۴) Start.cmd را با Administrator اجرا کنید و فقط یک مرحله را امتحان کنید. در صورت خطا فایل firewall-error-….json جدید را بفرستید؛ تلاش‌های ساخت قانون/ورود را پشت‌سرهم تکرار نکنید.

چه چیزی اصلاح شد؟
- مقایسهٔ نوع پروتکل و فیلترهای برگشتی با تبدیل نوع و آرایهٔ صریح بازنویسی شد. آدرس منفرد با /32 نیز برای مقصدهای IPv4 همان IP پذیرفته می‌شود؛ دامنهٔ قانون گسترده نمی‌شود.
- فقط خواندنِ وضعیت اعمال/حذف rule تا پنج بار با فاصلهٔ کوتاه تکرار می‌شود؛ ساخت rule فقط یک بار است و fallback/ساخت دوبارهٔ خودکار ندارد.
- خطای عمومی قبلی به گزارش امنِ مرحلهٔ دقیق شکست، reason، کد عددی و نتیجهٔ مقایسه‌ها تبدیل شد؛ متن خام خطا، مسیر بازی، نام دستگاه یا اطلاعات حساب صادر نمی‌شود.
- مهلت عملیات PowerShell به ۶۰ ثانیه افزایش یافت؛ نگهبان پنج‌دقیقه‌ای، journal مالکیت، بازیابی و قفل مراحل حفظ شده‌اند.

چه چیزی هنوز معلوم نیست؟
نسخهٔ قبلی جزئیات خطای واقعی کاربر را ذخیره نکرده بود. علت دقیق خطای قبلی هنوز تشخیص داده نشده؛ رفع قطعی آن با این اصلاحیه بدون اجرای کاربر ادعا نمی‌شود. ۴۴ آزمون محلی/mock پاس شده‌اند، نه اجرای واقعی Windows Firewall. اگر علت از مجوز/سیاست Windows باشد این نسخه آن سیاست را دور نمی‌زند.

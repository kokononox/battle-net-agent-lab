# وضعیت واقعی، نه گواهی نشت‌ناپذیری
این snapshot منبع آخرین بستهٔ محلی 0.1.2 است، نه ادغام خودکار در موتور آزمایشی قدیمی مخزن. کاربر پس از افزودن IPهای تازهٔ Level3، اتصال whitelist و قطع نمونه‌های خارج فهرست را گزارش کرد. دامنه پشت CDN است و IPها در عمل چند بار تغییر کردند؛ whitelist آی‌پی فقط همان IPها را می‌شناسد، نه هویت قطعی دامنه. نمونه‌های ping/TCP شکست‌خورده به‌تنهایی اثبات قطع همهٔ پروتکل‌ها نیستند. شبکهٔ Wi-Fi بعد از restart با kill switch قدیمی کاربر وصل نمی‌شد تا Disable؛ کاربر رسیدگی را فعلاً متوقف کرد. این ایراد حل‌شده اعلام نشده. Kill switch قدیمی v1.2 و این برنامهٔ whitelist دو فایل/مولفهٔ یکسان نیستند. هیچ guarantee دربارهٔ boot/reboot/IPv6/LAN/همهٔ اپ‌ها از این sync نتیجه نمی‌شود. Apply خودکار، reset سراسری یا Force-Allow درخواست نشده است.

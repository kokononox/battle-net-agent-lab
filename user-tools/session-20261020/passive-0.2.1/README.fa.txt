نسخهٔ کامل و مستقل 0.2.1 — ضبط شبکهٔ بازی بدون گواهی، پراکسی یا تزریق

نصب:
کل بسته را در پوشهٔ جدید و محلی استخراج کنید. به پچ یا بستهٔ قبلی نیاز ندارد.
فایل‌های داخل ZIP را جداگانه اجرا یا جابه‌جا نکنید؛ runtime باید کنار Start.cmd باشد.
پایتون لازم داخل بسته است؛ Frida و mitmproxy در این بسته وجود ندارند.
Pktmon داخلی Windows x64 لازم است؛ گواهی نصب نمی‌شود.
مسدودی فعلی 5.bat را تغییر ندهید و هم‌زمان ابزار بررسی دیگری اجرا نکنید.

روش اجرا:
1. بازی و ابزارهای بررسی قبلی را ببندید. برنامه‌های غیرضروری را هم ببندید.
2. روی Start.cmd راست‌کلیک و Run as administrator بزنید.
3. از پنجرهٔ انتخاب فایل، فایل exe خودِ بازی (مثلاً Wow.exe) را انتخاب کنید.
4. وضعیت Pktmon نمایش داده می‌شود. اگر ضبط دیگری فعال است ادامه ندهید.
   برای رضایت به ضبط محلی و سیستمی بسته‌ها، CAPTURE را تایپ و Enter بزنید.
5. حتماً منتظر CAPTURE READY بمانید، سپس بازی را خودتان اجرا کنید.
   فقط تا صفحهٔ ورود بروید؛ نام کاربری، رمز یا کد ورود وارد نکنید.
6. ضبط تا 60 ثانیه ادامه دارد؛ Q در همین پنجره زودتر تمامش می‌کند.
   پنجره را با X نبندید. تا پایان تبدیل و نمایش مسیر JSON صبر کنید.
7. فقط فایل output/passive-network-....json را ارسال کنید.

حریم خصوصی:
فایل‌های ETL و PCAPNG داخل private-captures محلی می‌مانند و ممکن است
ترافیک حساس سایر برنامه‌ها را هم داشته باشند. آنها را ارسال نکنید.
JSON شامل مقصدهای TCP منتسب‌شده با نمونه‌برداری به برنامهٔ انتخابی/فرزندان
مشاهده‌شده، DNS سیستمی بدون اثبات تعلق به بازی، و SNI/HTTP قابل‌مشاهده است.
خودِ DNS می‌تواند نام سرویس‌های سایر برنامه‌ها را نشان دهد؛ قبل از اشتراک بررسی کنید.
مقدار واقعی مشخصات سخت‌افزار، بدنه، URL کامل و مقادیر هدر HTTP صادر نمی‌شود.
تشخیص نام/نشانهٔ سخت‌افزار فقط برای HTTP متنی بازسازی‌شده انجام می‌شود؛
نبودن نشانه اثباتِ ارسال‌نشدن اطلاعات نیست. بخش رمزگذاری‌شده رمزگشایی نمی‌شود.

محدودیت‌ها و ایمنی:
از Pktmon داخلی ویندوز استفاده می‌شود؛ نیاز به Windows x64 با دسترسی ادمین دارد.
هیچ Frida، attach، تزریق یا خواندن حافظهٔ بازی در این حالت اجرا نمی‌شود.
بازی اجرا/بسته/متوقف نمی‌شود. تنظیم VPN، فایروال، DNS، TLS و فیلترهای ضبط تغییر نمی‌کند.
فقط نشست ضبط Pktmon شروع و متوقف می‌شود. ضبط NIC تضمین مشاهدهٔ داخل VPN نیست.
DNS کش‌شده، DoH/DoT، ECH، QUIC و پروتکل اختصاصی ممکن است ناشناخته بمانند.
انتساب TCP نمونه‌برداری‌شده است؛ اتصال‌های کوتاه ممکن است از دست بروند.
UDP به پردازه منتسب نمی‌شود. PTR/DNS مشترک اثبات نام سرویس یا کاربرد آن نیست.
شمارش بایت شامل احتمال تکرار بسته و بازانتقال است؛ حجم دقیق آپلود برنامه نیست.
فایل‌های چرخشی جدا تحلیل می‌شوند؛ پیام تقسیم‌شده بین فایل‌ها ممکن است خوانده نشود.
پیشوند هر بسته تا 4096 بایت ذخیره می‌شود. فایل‌های خام خودکار پاک نمی‌شوند.
بودجهٔ نرم ضبط 96MiB است و بین بررسی‌ها ممکن است بیشتر شود؛ فضای کافی داشته باشید.
یک کارگر محدود 90ثانیه‌ای برای توقف همان نشستِ قابل‌تأیید ساخته می‌شود؛
سرویس یا تسک دائمی نیست و تضمین مطلق توقف در خرابی سیستم/مالکیت نامعلوم نمی‌دهد.
حین تست از ابزار Pktmon دیگری استفاده نکنید. نشست ناشناس خودکار متوقف نمی‌شود.
اگر پیام ATTENTION دیدید، وضعیت را محلی با pktmon status بررسی کنید و JSON را بفرستید.
در صورت نبود Pktmon یا عدم تأیید مالکیت، ابزار با خطا متوقف می‌شود؛
این پچ مشکل Wi-Fi/کیل‌سوییچ قبلی را اصلاح نمی‌کند.

اعتبارسنجی:
33 آزمون محلی واحد/ساختگی و بررسی نحوی پایتون انجام شده است.
اجرای واقعی این حالت روی ویندوز توسط سازنده آزمایش نشده؛ گزارش نخست برای تأیید سازگاری لازم است.
این یک ابزار تشخیصی است؛ ابزار پیشگیری از ارسال اطلاعات یا تأیید «فقط دانلود» نیست.

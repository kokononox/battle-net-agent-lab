بازیابی مستقل تست TLS
بازی و ابزار تست را ببندید. این ZIP را در پوشهٔ جدید استخراج کنید.
Restore.cmd را از همان حساب ویندوزی قبلی با Run as administrator اجرا کنید.
این نسخه ابتدا گواهی دقیق ثبت‌شدهٔ هر تست را از CurrentUser\Root حذف و نبودش را بررسی می‌کند؛
خطای توقف پراکسی دیگر نباید جلوی تلاش برای حذف گواهی را بگیرد.
بعد، فقط پراکسی‌های همان کاربر با هش باینری رسمی و خط فرمان مرتبط با همان تست بررسی می‌شوند.
فقط recovery-result.json را ارسال کنید. فایل‌های خصوصی، کلید CA یا کل پوشه را نفرستید.
فایل‌های ca و cleanup-state.json قبلی را تا تأیید بازیابی پاک نکنید.
مسدودی hosts، فایل 5.bat، بازی و VPN تغییر نمی‌کنند.
بررسی نحوی با parser واقعی PowerShell و بازبینی ایستای ترتیب عملیات انجام شده است؛
اجرای API گواهی و پراکسی روی Windows توسط سازنده آزمایش نشده است.
اگر status=attention_required یا root_absence_verified=false بود، گزارش را بفرستید.
no_owned_state_found یعنی برای این حساب state پیدا نشده؛ اثبات پاک‌سازیِ حساب دیگر نیست.

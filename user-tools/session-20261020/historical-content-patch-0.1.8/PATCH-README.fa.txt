اصلاحیهٔ Level3 Content Check 0.1.3 برای بستهٔ کامل 0.1.0 همین گفتگو

این فایل runtime ندارد؛ ZIP بزرگ قبلی را دوباره دانلود نکنید.
۱. پنجرهٔ ابزار بررسی محتوا را ببندید.
۲. محتویات این ZIP را مستقیم داخل پوشهٔ بستهٔ قبلی که Start.cmd و runtime در آن هستند Extract کنید و جایگزینی فایل‌ها را تأیید کنید. پوشهٔ app اصلاحیه باید با app قبلی ادغام شود، نه داخل آن.
۳. Start.cmd قبلی را با Run as administrator اجرا کنید؛ عنوان باید 0.1.3 باشد.
۴. VPN وصل، وایت‌لیست Apply، بازی و Battle.net ابتدا بسته؛ مراحل START و READY مثل قبل است. اگر STOP دیدید برای دورزدن خطا Resume نکنید.
۵. فقط گزارش JSON جدید را بفرستید. فایل بزرگ قبلی را حذف نکنید.

این نسخه دامنهٔ Level3 همراه IPهای دستی عمومی را می‌پذیرد و IPهای دستی را جدا علامت می‌زند. تعلق آن IPها به دامنه تأیید نمی‌شود. تطبیق هش تنظیمات با ژورنال فعال و متمم آدرس‌های فایروال همچنان اجباری است. IPها را حذف یا وایت‌لیست را Restore نکنید. هیچ شرط حفاظتی حذف نشده و فایروال/DNS/hosts تغییر نمی‌کند. این نسخه در محیط سازنده روی Windows اجرا نشده است.

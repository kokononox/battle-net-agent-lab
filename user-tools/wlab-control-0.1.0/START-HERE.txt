WLab Control 0.1.0 — فقط آزمون روی فرایند خود ابزار، نه بازی

1. Extract کن و WLab-Control-0.1.0.exe را اجرا کن.
2. بازی لازم نیست باز باشد. این برنامه از بازی capture نمی‌گیرد.
3. مسیر پیش‌فرض G:\WLabControl است؛ با Browse می‌توانی مسیر دیگری انتخاب کنی.
4. View EULA را بخوان، در صورت پذیرش تیک بزن و Run control tests once را یک بار بزن.
5. برنامه دو آزمون clone و معمولی را فقط روی فرزند آزمایشی خودش انجام می‌دهد.
6. پس از پایان فقط READY-TO-SEND.zip را بفرست؛ فایل‌های .dmp را محلی نگه دار.
7. اگر خطا داشت هم گزارش را بفرست؛ فعلاً تکرار نکن.

این نسخه مشکل capture بازی را حل‌شده اعلام نمی‌کند؛ آزمون کنترل برای تشخیص است.
هیچ آپلود خودکار یا تغییر سیاست امنیتی ندارد. نصب Python یا debugger لازم نیست.

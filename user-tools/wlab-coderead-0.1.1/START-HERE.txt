WLab CodeRead 0.1.1 — خواندن محدود، نه dump کامل

1. Extract کن و WLab-CodeRead-0.1.1.exe را اجرا کن.
2. بازی آزمایشی با همان build را باز نگه دار؛ Wow.exe و مرحلهٔ فعلی را انتخاب کن.
3. تیک تلاش فقط‌خواندنی را بزن و Read code once را فقط یک بار بزن.
4. پس از پایان فقط READY-TO-SEND.zip را بفرست، حتی اگر خطا داشت.
5. بگو بازی عادی ماند، فریز شد یا بسته شد. فعلاً تکرار نکن.

خروجی روی درایو بازی، مثلاً G:\WLabCodeRead\TIMESTAMP-ID است.
ProcDump، dump کامل، clone، debugger، تزریق یا تغییر حافظه استفاده نمی‌شود.
access denied/guard/no-access باعث توقف می‌شود، نه تلاش برای دورزدن.
Python یا debugger لازم نیست و ابزار Microsoft دانلود نمی‌شود.
آزمون اولیهٔ 0/7 عمدی و فقط مربوط به فرزندان خود WLab است.
Windows واقعی این روش هنوز در محیط ساخت آزموده نشده؛ README.fa.md را بخوان.

اصلاح این نسخه: پذیرش mapping خواندنی MEM_MAPPED با همان کنترل‌های هویت؛ بدون تغییر محافظت صفحات.
نقشهٔ query چهار محدوده هم در گزارش ثبت می‌شود.

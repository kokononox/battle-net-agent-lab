# عیب‌یاب فقط‌خواندنی DNS برای T1

این ZIP مکمل بسته قبلی است و runtime همراه ندارد. فایل‌های داخل آن را **داخل همان پوشه Level3-Request-Audit-T1 که runtime و app دارد** استخراج کنید؛ پوشه app ادغام می‌شود و هیچ فایل قبلی جایگزین نمی‌شود.

`Diagnose-Profile.cmd` را اجرا کنید. Administrator لازم نیست. آپدیت همچنان Pause بماند؛ BAT دیگری اجرا یا تنظیمی تغییر ندهید. این ابزار هیچ hosts/cache/firewall/فرایند/دانلودی را تغییر نمی‌دهد و hook ندارد؛ فقط resolver ویندوز و خطوط مربوط به همان۲۵ نام در hosts را می‌خواند. DNS lookup می‌تواند خود باعث درخواست DNS شبکه شود؛ بررسی محتوای ترافیک انجام نمی‌شود.

فایل `output/t1-dns-diagnostic-....json` را بفرستید، یا خطوط MISMATCH را کپی کنید. همه hosts سیستم، اطلاعات حساب یا payload صادر نمی‌شود؛ فقط۲۵ نام ثابت و آدرس‌های متناظرشان و کد عددی خطا هستند. چیزی خودکار upload نمی‌شود.

حتی اگر عیب‌یاب در این لحظه PASS داد، دستور Resume نیست. این ابزار فقط علت توقف پیش‌شرط T1 را روشن می‌کند؛ نبودن سطر در hosts، resolve ناموفق، پاسخ عمومی برای نام بسته یا پاسخ غیرعمومی مقصد باز باید جدا تفسیر شوند. از خطای فعلی نمی‌توان قطعیت کارکردن/نکردن BAT را نتیجه گرفت.

# مانیتور U2 — آزمون مرحله‌ای مقصدها

این نسخه جدا از U1 است. آتش‌دیواره کامل یا ابزار تشخیص قطعی تله‌متری نیست. هیچ Update/Pause/Play/Login/Repair یا تغییر فایل بازی انجام نمی‌دهد.

## هدف
بررسی کنیم آیا با بستن **یک نام دامنه اضافه** در کنار بلوک ثابت `telemetry-in.battle.net`، دانلود در همان بازه ادامه می‌یابد، متوقف می‌شود یا خطا می‌دهد. این پاسخ، محتوای داده ارسالی به دامنه یا ضرورت همیشگی آن را ثابت نمی‌کند.

## اجرای زمان‌بندی‌شده
1. بسته را در پوشه جدید استخراج کنید؛ فایل‌های U1 را جایگزین/ویرایش نکنید و دو نسخه را همزمان اجرا نکنید. WoW بسته، بازی در Pause، آپدیت خودکار OFF و بکاپ قدیمی محفوظ باشد. Battle.net را از tray کامل Exit کنید. اگر Agent باقی بود پیام را ارسال کنید؛ ابزار آن را kill نمی‌کند.
2. `Start-Scheduled-Trials.cmd` را با Run as administrator اجرا کنید؛ برای شروع `SCHEDULE` بنویسید.
3. هر مرحله پیش‌شرط‌ها را دوباره می‌سنجد. مسیر همان `G:\World of Warcraft` است؛ پس از تأیید واقعی شرایط `CONFIRM` و پس از دیدن فهرست دقیق دامنه‌ها `BLOCK` بنویسید.
4. Battle.net را فقط وقتی ابزار درخواست کرد دستی باز کنید؛ signed out بمانید. تا `READY FOR OBSERVATION ONLY` دانلود را Resume نکنید. اگر READY نیامد، Resume مجاز نیست؛ همین شکست یک نتیجه احتمالی مرحله است، نه مجوز دورزدن شرط یا اثبات علت.
5. پس از READY کاربر می‌تواند دستی Resume کند. ابزار **۱۲۰ ثانیه از READY** مشاهده می‌کند؛ این زمان از لحظه کلیک واقعی اندازه‌گیری نمی‌شود. Q پایان زودتر مشاهده است.
6. پایان تایمر فقط مشاهده را متوقف می‌کند، **نه دانلود را**. دستی Pause کنید، یا اگر تمام شده Finished را گزارش کنید. وضعیت و رفتار دانلود را صادقانه انتخاب کنید؛ خود ابزار درصد/حجم دانلود را اندازه نمی‌گیرد.
7. پیش از مرحله بعد Battle.net را از tray کامل Exit کنید. تا پردازش‌ها بازند مرحله بعد شروع نمی‌شود. بعد از بازیابی hosts، `NEXT` رفتن به مرحله بعد است؛ هر جواب دیگر پایان برنامه است.
8. اگر دانلود تمام شد برنامه مراحل بعد را کنار می‌گذارد؛ برای آزمون بیشتر بازی را پاک/rollback نکنید. فایل‌های `output/report-*.json` را بفرستید؛ **PRIVATE-RECOVERY را منتشر نکنید**.

## چرا کاملاً بی‌دخالت نیست؟
تغییر hosts اتصال باز قبلی، DNS داخلی/cache برنامه، مسیر IP مستقیم یا دامنه جایگزین را الزاماً قطع نمی‌کند. چرخش خودکار وسط یک دانلود ممکن است نتیجه گمراه‌کننده بدهد. بنابراین زمان‌بندی مشاهده خودکار است، اما بستن/بازکردن Battle.net و Resume/Pause دستی می‌ماند. ابزارها یا شبکه ممکن است cache دیگری هم داشته باشند؛ حتی بستن برنامه تضمین همه مسیرها نیست.

روند فایل‌ها، پیشرفت دانلود و cache بین مراحل تغییر می‌کند؛ این آزمایش غربالگری است، نه A/B هم‌شرط یا اثبات علت. ادامه دانلود ممکن است ناشی از cache/fallback باشد. توقف هم ممکن است به شبکه یا زمان‌بندی مربوط باشد. نتیجه مشکوک به آزمون برگشت‌پذیر مستقل نیاز دارد.

## بازیابی و خطرها
- hosts به‌صورت موقت و با بکاپ خصوصی/هش تغییر می‌کند. هر ورودی قبلی از فهرست آزمون باعث refusal می‌شود؛ چیزی خودکار پاک نمی‌شود.
- تمام نام‌های همین مرحله با resolver سیستم بررسی می‌شوند؛ اگر هر کدام loopback نشود READY داده نمی‌شود.
- در پایان هر مرحله hosts دقیقاً به اصل برمی‌گردد. **بعد از خروج برنامه دیگر بلوکی فعال نیست.** اگر Battle.net باز بماند ممکن است دوباره ارتباط برقرار کند؛ Pause معادل قطع شبکه نیست.
- پس از crash/power loss، با `Restore-Hosts-Only.cmd` و Administrator بازیابی کنید. اگر فایل hosts بیرون از ابزار تغییر کرده باشد، ابزار آن تغییر را overwrite نمی‌کند؛ recovery journal را حفظ و پیام را ارسال کنید.
- بلوک سرویس نسخه/CDN ممکن است READY را ناممکن کند، دانلود را stall کند یا باعث خطای لانچر شود. فایل بازی را ابزار تغییر نمی‌دهد، اما رفتار و نوشتن فایل توسط خود updater را کنترل یا rollback نمی‌کند.
- read-only API hooks ممکن است زمان‌بندی/پایداری را تغییر دهند. هیچ فرایند بازی/ضدتقلب attach نمی‌شود؛ حفاظت Windows/TLS/certificate ضعیف نمی‌شود.
- محدودیت‌های U1 پابرجاست: late attach، پوشش ناقص OpenSSL/HTTP2/QUIC، CPU literal منفی غیرقطعی، API success غیرمعادل دریافت سرور. خطای sampler و attach_failed گزارش قبلی هنوز علت اثبات‌شده یا تضمین رفع ندارند.
- لاگ فقط فراداده، نام دامنه، نتیجه resolver، بازه مرحله و پاسخ‌های کاربر است؛ payload/header/query/کلید TLS یا مقدار واقعی CPU صادر یا خودکار آپلود نمی‌شود.

نسخه Windows فقط بعد از پاس‌شدن gate بومی بسته قابل تحویل است. پاس unit tests روی Linux به معنی تست واقعی hosts ویندوز یا موفقیت آپدیت نیست.

رسید نامشخص ۰.۸.۱ و بازیابی تأییدشدهٔ آن تغییر نمی‌کنند. اکنون افزونهٔ کوچک بدون runtime و بدون تغییر قواعد برای اجرا در همان پوشهٔ ۰.۸.۱ ساخته شده است. مسیر/hash دو EXE و مقصد با آخرین request/result محلی تطبیق می‌یابد؛ آخرین گزارش بازیابی‌نشده با گزارش قدیمی خوب جایگزین نمی‌شود. این رکورد تاریخی جای query زندهٔ سیاست نیست.

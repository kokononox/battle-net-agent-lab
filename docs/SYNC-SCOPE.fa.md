# دامنه و حریم خصوصی همگام‌سازی

«اطلاعات جلسه» در این sync یعنی تحویل جامع و ساختاریافتهٔ هدف اصلی، مسیر تصمیم‌ها، وضعیت آخر، اعداد بررسی‌شده، خطاهای مهم، معماری، محدودیت‌ها و برنامهٔ ادامه؛ به‌همراه آخرین منبع معتبر و شواهد لازم برای ادامهٔ کار. **این کار mirror خامِ تمام گفتگوها یا تمامی پیوست‌ها نیست.**

## منتقل شده

- تمام فایل‌های متنی انتشار TagFix (کد/تست/راهنما/گزارش/manifest) پس از تطبیق با manifest همان بسته، بدون دستکاری منبع انتشار.
- منبع آزمایش مستقل GitHub و تست‌های sanitization، همراه probe GUI فقط‌خواندنی.
- پنج گزارش تصمیم‌ساز `Retail-...-to-share` از prepare، پایان مرور، refresh، metadata delta و scope؛ فایل‌ها بدون تغییر با SHA256 مشخص.
- مستندات فارسیِ context و تفکیک شواهد تاریخی/واقعی/مصنوعی. گزارش‌های خودکار runner در reports باقی‌اند.

## عمداً منتقل نشده

- فایل PRIVATE، manifest/receipt/plan خصوصی، مسیرهای شخصی سیستم، فایل‌های واقعی بازی، CASC/archive/idx/BLTE/staging/cache/part و SQLite کاربر.
- credential، token/cookie/کلید TLS، بدنهٔ خام حساس، raw log یا packet capture، screenshot یا Setup/Agent binary.
- متن خام چندمگابایتی گفتگوها و ZIPهای قدیمی unreviewed؛ ممکن است حاوی اطلاعات شخصی و مراحل منسوخ باشند. نکات مؤثر آن‌ها خلاصه شده‌اند، نه اینکه ادعا شود هر خط آن‌ها منتقل/دوباره تأیید شده است.
- محتوای مخزن تاریخی check-spy-app یا اجرای observer prototype روی بازی واقعی.

## نحوهٔ بازیابی

1. همین مخزن خصوصی را از main در یک پوشهٔ منبع تازه بگیرید؛ Lab موجود را جابه‌جا/پاک نکنید.
2. فایل‌های `docs/` و `docs/current-state.json` را بخوانید. مسیر Lab محلی داخل مخزن نگهداری نمی‌شود.
3. SHA فایل‌های دانلودر را با manifest کنترل کنید؛ `SYNC-MANIFEST.json` فهرست فایل‌های این عملیات است، نه امضای امنیتی مستقل.
4. unit suiteها را جدا اجرا کنید. `START-WINDOWS.cmd` فقط از پوشهٔ منبع؛ راهنما را رعایت کنید و برای ادامهٔ کاربر همان Lab را انتخاب کنید. این sync نیازمند prepare یا full scan تازه نیست.

مخزن خصوصی است، ولی خصوصی‌بودن جای حذف اطلاعات حساس را نمی‌گیرد. `.gitignore` دفاع کمکی است؛ push از API باید allowlist فایل داشته باشد. هیچ runtime folder را با glob عمومی بارگذاری نکنید.

## استثنای محدود آرشیو بیلد 70448 — درخواست صریح کاربر

کاربر در این مرحله صریحاً اجازه داد آرشیو ارسالی شامل فقط Wow.exe، wow_loader.dll و libxell.dll به قطعات کمتر از 25MB تقسیم و در همین مخزن خصوصی نگهداری شود. این استثنا فقط همین آرشیو با هش manifest در binaries/retail-70448 را پوشش می‌دهد و دامنهٔ قبلی برای لاگ خام، pcap، dump، کلید و مسیر شخصی برقرار است. مجوز انتشار عمومی یا اجرای بازی/دورزدن محافظت نیست. فعلاً manifest و ابزار بازسازی آمادهٔ sync است؛ حضور واقعی قطعات باید از upload-status.json کنترل شود. محدودیت اتصال متنی GitHub و انتظار اجازهٔ مرورگر باید صریح بماند؛ manifest جای باینری نیست.

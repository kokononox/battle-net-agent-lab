# ادامهٔ پروژه: رصد زمان اجرا، نه صرفاً انتخاب فایل

## مبنا و اصلاح کاربر

رسید Windows بستهٔ PROGRAM-OBSERVER-01 موفقیت reopen/بازمشاهده و ۱۵ نمونهٔ passive را نشان داد، اما هیچ فرایند منتخب پایدار و هیچ مقصدی منتسب نشد. این موفقیت، کشف مقصد زمان اجرای نصب‌کننده نبود. کاربر تصریح کرد فایل فقط انتخاب می‌شود و مقصدهای آن هنگام اجرا مشخص می‌شوند؛ سپس ساخت ادامه را خواست. رسید قبلی و محدودیت‌هایش حفظ شده‌اند. وضعیت جدید فایروال/VPN کاربر در این مرحله مجدداً پرس‌وجو نشده است.

## تحویل جدید

سورس و راهنما: [runtime-capture-v01](../analysis/unifiedfw-session-2026-10-27/runtime-capture-v01/README.fa.md).

- انتخاب candidate موجود، همان حساب، خواندنی و چند بار بازاعتبارسنجی؛ بدون تغییر candidate و baseline قدیمی.
- پیش از اجرای دستی هدف، فعال‌سازی موقت سه زیردستهٔ audit با تأیید محلی و backup محافظت‌شده: 4688/4689 و 5156/5157؛ بدون Allow جدید، تغییر DNS/VPN یا اجرای خودکار هدف.
- بررسی فقط‌خواندنی محافظه‌کارانهٔ ActiveStore؛ تمام پروفایل‌ها فعال و outbound Block. Allow موجود فقط در صورت تطبیق دقیق SstpSvc/svchost اصلی/TCP443/IPهای صریح محدود پذیرفته می‌شود؛ هر Allow بررسی‌نشده توقف می‌دهد.
- قبل از READY یک فرزند تشخیصی PowerShell با تلاش TCP بدون payload به 192.0.2.1:9 باید منع Winsock10013 و رخدادهای شروع/منع/پایان را نشان دهد. فقط این فرزند را خود ابزار اجرا می‌کند، نه نصب‌کننده. شکست این آزمون یعنی بدون READY و بدون دستور اجرای هدف.
- پنجرهٔ رصد حداکثر۹۰ثانیه؛ کاربر تنها پس از READY، نصب‌کننده را دستی از Explorer اجرا و پیش از پایان رصد خودش می‌بندد.
- انتساب با PID+مسیر+عمر نمونه و زنجیرهٔ والد؛ فرزندان نیازمند بررسی، PID reuse/پایان/رخدادهای اختلال مانع انتساب ساده. مسیرهای shared host صرفاً قابل مشاهده‌اند، نه مجاز.
- خروجی خصوصی فقط پیشنهادهای مرتبط و تأییدنشده؛ diagnostic عمومی فقط شمارش و stage/code. 5156 اثبات ارسال داده نیست، صفر نتیجه اثبات نبود ترافیک نیست.
- بازگردانی و بررسی ماسک‌های منطقی audit قبل از ذخیرهٔ پیشنهادها. شکست یا crash با pending محافظت‌شده حفظ می‌شود؛ اجرای دوبارهٔ همان بسته فقط بازیابی صریح و بدون capture می‌دهد. drift خارج از before/during باعث امتناع می‌شود. لاگ Security پاک نمی‌شود.

## حدود امنیتی غیرقابل حذف

این یک recorder آزمایشی است، نه enforcement/محیط ایزوله و نه تضمین no-leak یا جلوگیری از fingerprint. نصب‌کنندهٔ elevated ممکن است policy یا سرویس‌ها را عوض کند. بررسی دوره‌ای اتمیک نیست، هدف را متوقف نمی‌کند و نصب را undo نمی‌کند. IPC، سرویس‌های مستقل، DNS broker، ترافیک از قبل موجود، loopback و WFP ثالث پوشش را محدود می‌کنند. اگر تضمین ایزولاسیون پیش از اجرا لازم است، کاربر باید Cancel کند و نصب‌کننده را اجرا نکند. بسته فقط برای رایانهٔ آزمایشی مستقل است.

## آزمون‌ها و گام بعدی

- ۷۱۸ assertion جدید و۳۲ سناریوی callback؛۶۴ ترکیب قبل از audit و۵۱۲ سناریوی بازیابی نصب جزئی، جدا از شمارش assertionها.
- ۱۲۱۴ assertion رگرسیون: observer645،candidate236،picker260،journal73.
- parse نه فایل PowerShell، pin ده وابستگی، bootstrap، manifest، ZIP و استخراج تازه بررسی شد؛ C# کامپایل و journal واقعی روی Linux آزموده شد.
- **Windows native، رابط کاربری، SeSecurityPrivilege، audit واقعی و فرزند تشخیصی در محیط توسعه اجرا نشده‌اند.** آزمون بومی قبل از READY تنها gate نخستین اجرای Windows است، نه qualification کامل.
- گام بعد: فقط اجرای همین بسته روی PC آزمایشی با رضایت صریح؛ دریافت diagnostic عمومی جدید، بررسی preflight/selftest/restore و سپس انتساب واقعی. هیچ مقصدی خودکار approve نشود و Apply همچنان false بماند.

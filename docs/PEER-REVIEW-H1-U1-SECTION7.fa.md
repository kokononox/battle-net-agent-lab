## اثر بر کار فعلی
کاربر اکنون آزمون یک‌به‌یک مقصدها و زمان‌بندی خواسته است. نسخه U2 در مسیر جدا آماده شده:
- baseline ثابت telemetry-in.battle.net و هر بار دقیقاً یک دامنه اضافه؛ نه block انباشته شش دامنه.
- baseline و شش مرحله با پنجره مشاهده ۱۲۰ ثانیه پس از READY؛ پایان پنجره Update را Pause نمی‌کند.
- بین مراحل باید کاربر Battle.net را دستی ببندد؛ تا پردازش‌ها بازند مقصد بعدی اعمال نمی‌شود. تغییر hosts وسط یک اتصال زنده به‌عنوان آزمایش معتبر جا زده نمی‌شود.
- consent، Resume/Pause/Exit و NEXT دستی می‌مانند. این زمان‌بندیِ مشاهده و ترتیب آزمون است، نه آزمایش بی‌دخالت روی بازی.
- چون پیشرفت فایل/cache بین مراحل تغییر می‌کند و hook هم فعال است، ادامه/توقف غربالگری است؛ نه اثبات causal necessity یا اثبات ارسال تله‌متری.
- domain news، OAuth، سرویس نسخه و CDN به‌خودی‌خود تله‌متری یا بدخواه شناخته نمی‌شوند.
- اگر نسخه قبل از پایان جدول کامل شود، مراحل بعد حذف می‌شوند؛ game reset/rollback/Repair/حذف یا دانلود مجدد ۱۳۰GB مجاز/لازم نمی‌شود.

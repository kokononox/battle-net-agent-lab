# نتیجه آماده‌سازی WoW Retail بدون حساب — c2

## نتیجه محدود و مستقیم

روی Windows 2025 گیت‌هاب، بدون ورود به حساب، Agent متعلق به همین آزمایش درخواست POST /install برای محصول Retail با شناسه wow را با HTTP 201 و پاسخ JSON به اندازه ۱۴۵۸ بایت جواب داد. این آزمایش Classic نیست. وجود فرم نصب بدون حساب مشاهده شد؛ دانلود موفق بازی هنوز اثبات نشده است.

کد منبع: `570893880b0e9a04f99f11c8abdefd072ccf2cdd`

اجرای CI: `40446450901`؛ آزمون‌ها، مشاهده و اعتبارسنجی همگی success. موفقیت CI به معنی موفقیت دانلود نیست.

## پاسخ مشاهده‌شده

| --- | --- |

نام‌گذاری معنای دقیق کدهای ۸۰۰ و ۷۰۴ در این مرحله بررسی نشده است. تنها مشخص است از کدام بخش پاسخ آمده‌اند. صفر بودن authentication صرفاً نبود خطای اعلام‌شده در این پاسخ آماده‌سازی است؛ اجازه نهایی دانلود یا عدم نیاز به حساب در همه مراحل را ثابت نمی‌کند. صفر بودن min_spec نیز ادعای ارزیابی جامع سخت‌افزار نیست.

وجود بخش eula طبق سیاست این آزمایش، مستقل از مقدار برگشتی آن، مانع بررسی حقوقی محسوب شد؛ هیچ پذیرش شرایطی ارسال نشد. مسیر نصب و زبان با درخواست بعدی تنظیم نشده‌اند. مقدار finalized صادر نشده و درباره وضعیت واقعی آن ادعایی نداریم.

## زنجیره اجرا و حریم خصوصی

- bootstrap با هش ثابت و امضای مجاز تطبیق داشت.
- bootstrap فقط تا ادامه زبان مشاهده شد؛ سپس Agent متعلق به آزمایش با رابط محلی راه‌اندازی شد.
- handshake محلی GET /agent با HTTP 200 توکن ارتباط محلی داد؛ این توکن حساب Battle.net نیست.
- یک GET /game، خلاصه خالی را برگرداند؛ سپس فقط یک POST /install انجام شد.
- شش بررسی هویت انجام شد؛ دو بار گذار محدود به فایل موقت با همان هش و امضای معتبر پذیرفته شد؛ شکست هویت ثبت نشد.
- هش Agent این اجرا: `ee5ef234ebe83004fff9e2937b60862436c698ed8908e89335fa105d80f3d630`؛ نباید آن را با باینری Agent آزمایش‌های قدیمی یکی دانست.
- توکن، پاسخ خام، مسیرها، UUIDها، داده رابط کاربری و باینری‌ها منتشر نشده‌اند؛ cleanup تلاش شد.

EU/enUS و Windows x64 پروفایل آزمایش‌اند، نه ترجیح استنباط‌شده کاربر. سرویس عمومی versions نسخه 12.1.5.70575 را اعلام کرد؛ این کشف مستقل ثابت نمی‌کند Agent دقیقاً همان build را انتخاب کرده است.

## چه چیزی انجام یا ثابت نشد؟

هیچ ورود حساب، POST /install/wow برای نهایی‌سازی، پذیرش حقوقی، جعل کشور، دور زدن حداقل سیستم، درخواست دانلود محتوای بازی، اجرای بازی یا دسترسی به نصب کاربر انجام نشد. آماده‌سازی می‌تواند موجب ترافیک و تغییر وضعیت Agent شود؛ آزمایش dry-run یا دارای سقف سخت ترافیک فرزندان نبود.

این مرحله شبکه را ابزارگذاری نکرد؛ بنابراین داده ارسالی هنگام دانلود، رسید سرور و اطلاعات سخت‌افزاری این فاز را ثابت نمی‌کند. شواهد پیشین ارسال پیش از لاگین جدا هستند و به تمام مراحل دانلود تعمیم داده نمی‌شوند. پرسش منشأ/نشان‌گذاری فایل‌های WoW همچنان در صف است.

## قدم بعدی

بررسی مستند ساختار انتخاب زبان و مسیر در فرم نصب، سپس ارائه شرایط حقوقی واقعی برای بررسی و تأیید صریح کاربر پیش از هر پذیرش. فقط پس از رفع مشروع پیش‌نیازها می‌توان آزمایش انتقال محدود محتوای بازی و رصد ترافیک آن را طراحی کرد. بستن این مرحله به حساب کاربری یا دور زدن خطاها توجیه ندارد.

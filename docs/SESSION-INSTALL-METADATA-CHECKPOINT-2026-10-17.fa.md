# ادامهٔ جلسه تا دریافت و تأیید متادیتای Install — ۲۰۲۶-۱۰-۱۷

این checkpoint خلاصهٔ قابل‌ادامهٔ تصمیم‌ها، شواهد و کدهای جدید است؛ رونویسی کامل گفتگو یا بستهٔ نصب نیست. فقط شاخهٔ `patch-audit-20261016` تغییر کرده است. main، releaseها و workflowها دست‌نخورده‌اند.

## وضعیت فعلی
- هدف pinشده `12.1.5.70391` است، نه ادعای آخرین نسخهٔ آنلاین. نسخهٔ نصب گزارش‌شده `12.1.0.69933`؛ پروفایل Windows/x86_64/EU/enUS.
- مرور آفلاین v3 روی Lab ذخیره‌شده به پایان رسیده است؛ اسکن سنگین قبلی را تکرار نکنید. شمار انتخاب یکتای گزارش‌شده 1,578,013 است: مختصات ذخیره‌شده برای 1,531,167 و وضعیت نامعلوم برای 46,846 مورد.
- مجموع 132,637,194,719 بایت، جمع اندازهٔ encoded در متادیتاست، **نه حجم موردنیاز اینترنت**. نامعلوم را missing/corrupt ننامید.
- `installation_ready=false` و `required_network_download_bytes=null` همچنان معتبرند. سیاست انتخاب فروشنده، کلوزر لازم، اثبات تازهٔ محتوای محلی و آزمون نصب واقعی Windows هنوز حل نشده‌اند.

## پیشرفت‌های جدید و مرز ادعا
1. ممیزی آمادگی: 85 آزمون بدون شکست (73 بازاجرای محدود متادیتا/پلنر + 12 مورد منفی جدید). این 568 آزمون تاریخی را دوباره اجرا نکرده است.
2. مدل تراکنش مستقل مصنوعی: 45 آزمون متمایز در سه اجرای نهایی متوالی گذشت؛ 11 نقطهٔ قطع پیشروی، 4 نقطهٔ بازگشت و 12 خطای I/O تزریقی. مدل سه فایل تولیدشده، نسل immutable و اشاره‌گر سفارشی دارد؛ CASC، قطع برق فیزیکی، دیسک واقعاً پر یا Windows بومی نیست. ایراد نادر descriptor اشاره‌گر بعد از replace و مسیر retry fsync اصلاح و آزموده شد. به اپدیتر اصلی متصل نشده است.
3. استخراج مستقل مرجع Install از build-config pinشده: 15 آزمون گذشت. این گزارش تاریخی فقط مرجع را ثابت می‌کرد، نه حضور فایل.
4. ابزار saved-install-review-1: 36 آزمون Linux گذشت، از جمله CLI مستقل با کش ناموجود. مسیر Windows فقط مدل‌سازی شده است. اجرای واقعی کاربر `bound_install_metadata_unavailable` داد؛ صفر بایت Install خواند و نبود آن در **مسیر دقیق** را گزارش کرد، نه نبود کل بازی یا خرابی.
5. با اجازهٔ صریح بعدی کاربر، فقط یک GET مستقیمِ همین متادیتا در محیط پژوهشی دستیار انجام شد: HTTP 200، بدون redirect یا fallback. 23,106 بایت BLTE دریافت و به 24,078 بایت رمزگشایی شد. EKey و CKey مستقل مورد انتظار هر دو مطابقت کردند. محتوای آرشیو صفر بایت، تغییر بازی/Lab صفر.

## مجوزها و توقف
- اجازهٔ شبکه فقط همان **یک دریافت Install** بود و مصرف شد؛ مجوز عمومی شبکه، دانلود asset یا تکرار خودکار نیست.
- هیچ اجازه‌ای برای خواندن payload آرشیو، نوشتن بازی/Lab، حذف Lab، بازسازی inventory یا شروع مجدد اسکن داده نشده است.
- اجازهٔ فعلی sync مربوط به ثبت مستندات/کد در همین شاخه است؛ release یا نصب نمی‌سازد.
- موفقیت کشف هویت Install اجازهٔ نصب واقعی یا ادعای سلامت بازی نیست.

## گام بعدی
بررسی آفلاین و محدود ساختار **همین بایت‌های Install تأییدشده**، با parser سخت‌گیر، آزمون‌های منفی، کنترل انتهای فایل و ثبت ابهام‌ها. معنای تگ‌ها و رابطهٔ Install/Download/Root/Encoding را بدون شاهد حدس نزنید؛ Install به‌تنهایی الزاماً کل محتوای لازم بازی را توصیف نمی‌کند. اگر بایت‌ها در محیط بعدی موجود نبودند، از کاربر فایل دقیق/اجازهٔ محدود بخواهید، نه دریافت خودکار.

## مسیرهای ادامه
- `research/session-checkpoint-20261017/`: شواهد، کدهای جدا و اسکریپت‌های منشأ این checkpoint.
- `install-fetch/FETCH-RECEIPT.json`: آخرین دریافت موفق؛ این نتیجه از گزارش قدیمی install-reference و گزارش کش ناموجود جدیدتر است.
- `synthetic-transaction/`: مدل مصنوعی، مستقل و Linux-only؛ به writer واقعی منتقل نشده است.
- `saved-install-review/`: کد و آزمون‌های ابزار فقط‌خواندنی، نه نصاب.
- `provenance-scripts/`: اسکریپت‌های محیط پژوهشی با مسیرهای `/data`؛ آرشیو منشأ هستند و فرمان قابل‌اجرا روی بازی کاربر نیستند. فایل fetch را خودکار اجرا نکنید؛ اجازهٔ یک‌باره مصرف شده است.
- وابستگی‌های موجود ابزار Install در `downloader/patch_audit_lab/` قرار دارند؛ فایل‌های این checkpoint یک ZIP خودبسنده یا release جدید نیستند. هش ZIPهای قبلاً تحویل‌شده برای تطبیق حفظ شده، خود ZIPها در این commit قرار نگرفته‌اند.
- اعداد آزمون‌ها مربوط به suiteها و زمان‌های متفاوت‌اند؛ آن‌ها را به عنوان یک suite مستقل جمع نکنید. هنگام sync آزمون‌ها دوباره اجرا نشده‌اند؛ فایل‌های Python فقط از نظر syntax کنترل شده‌اند.

# نتیجهٔ بررسی محدود متادیتای Classic Era

## دستاورد واقعی

پس از تأیید کاربر، شش GET مستقیم HTTPS فقط به سرویس نسخهٔ Blizzard و host رسمی برگشتی `level3.blizzard.com` انجام شد. این مرحله روی محیط Linux اجرا شد؛ قالب TACT مستقل از سیستم‌عامل است. این یک آزمایش نصب روی ویندوز نیست. پروفایل Windows/x86_64/EU/enUS فقط هدف آزمایشی پیشنهادی است، نه پروفایل اثبات‌شدهٔ کاربر.

- snapshot سرور EU در زمان گزارش: `wow_classic_era`، نسخهٔ `1.15.9.70003`، BuildId=`70003`.
- config ساخت `2417084b8b041ee120d02d4adf31b0bc` و config CDN `f065eade5276a5ac05606e60a4c5a1f7` دریافت و MD5 هر دو با مرجع نسخه مطابقت داده شد.
- manifestهای نصب و دانلود با اندازهٔ دقیق اعلام‌شده در config دریافت شدند؛ EKey، checksumهای BLTE و CKey هر دو تأیید شدند. layoutهای شناخته‌شدهٔ IN_v1 و DL_v1 کامل و بدون بایت اضافی parse شدند.
- کل بدنه‌های دریافت‌شده: **4,957,673 بایت**؛ زمان از آغاز بررسی تا پایان دریافت/بررسی manifestها **43.438 ثانیه**. سقف مصوب 64 MiB و 600 ثانیه افزایش نیافت. این شمارش بدنهٔ HTTP است، نه تمام بایت‌های TLS/شبکه.
- هیچ encoding بزرگ، محتوای فایل بازی، archive، patch، Agent، نصب/initialize/update/repair، حساب یا فایل کاربر درخواست/اجرا نشد. کد محصول و hash نسخه در ابزار کشف hardcode نشده‌اند؛ هر اجرای تازه نیازمند مجوز تازه و workspace بدون receipt قبلی است. snapshot ثبت‌شده فقط مشاهدهٔ همان لحظه است، نه وعدهٔ آخرین نسخه برای همیشه.

جزئیات شش URL، status، اندازه و SHA256 در `reports/classic-era-metadata-preflight.json` ثبت شده است. فایل‌های binary و پاسخ‌های خام در مخزن منتشر نشده‌اند.

## نتیجهٔ اندازه‌گیری، نه ادعای حجم نصب

فهرست دانلود 220,158 کلید encoded یکتا دارد. جمع اندازهٔ **تمام** ورودی‌های این manifest، بدون انتخاب هیچ پروفایل، **8,516,078,649 بایت، حدود 7.93 GiB** است. عدد با دو مسیر مستقل — جدول parseشده و خواندن مستقیم رکوردهای binary — تطبیق داده شد؛ کلید تکراری یا مقدار خالی دیده نشد. فهرست نصب 262 ورودی دارد؛ این شمار فایل‌ها در manifest است، نه شمار همهٔ فایل‌های ذخیرهٔ CASC.

این جمع **حجم نصب Windows/enUS، ترافیک واقعی Agent، فضای لازم staging یا حجم آپدیت از نسخهٔ قدیمی نیست**. جمع unfiltered به همهٔ پلتفرم‌ها، زبان‌ها، ناحیه‌ها و variantها تعلق دارد. حتی مقدار `install-size` در config فقط اندازهٔ خود manifest نصب است. `required_update_bytes` و `full_install_size_bytes` عمداً null مانده‌اند.

Classic نیز tagهای نوع 16384 با نام‌های Alternate، HighRes و Talebound دارد. بنابراین کوچک‌تر بودن آن مسئلهٔ معنا و اولویت انتخاب را خودبه‌خود حل نمی‌کند. همان سیاست حدسی Retail را به Classic منتقل نکردیم. موفقیت parser و hash هم اثبات انتخاب درست Agent نیست.

## گام عملی بعد و مرز مجوز

مرحلهٔ متادیتای مصوب تمام شده است. قدم بعد، **تهیهٔ baseline آزمایشی Classic در یک Windows VM دورریختنی با نصب رسمی، بدون حساب و جدا از Retail** است. این بار دانلود محتوای بازی و تغییر فایل‌های VM وجود خواهد داشت؛ مجوز قبلی شامل آن نیست. نصب build جاری فقط baseline/آزمون نصب تازه است و هنوز تست آپدیت از نسخهٔ قدیمی به جدید نخواهد بود.

پیش از اجرای نصب: محصول/build باید دوباره کشف شود؛ فضای واقعی volume مقصد و محل staging کنترل شود؛ حداکثر زمان job و مسیرهای مجاز/cleanup تعیین شود؛ شکست در این بررسی‌ها باید پیش از شروع نصب متوقف شود. 7.93 GiB مجوز یا تضمین سقف سخت دانلود Agent نیست: ابزار فعلی سقف سخت شبکهٔ فرایندهای فرزند را پیاده نکرده است. پیش از اجرا این محدودیت باید صریح باشد؛ سقف metadata به Agent تعمیم داده نمی‌شود. هیچ workflow نصب خودکاری با این commit فعال نشده است.

پس از اجازهٔ مجزای کاربر برای دانلود/نصب آزمایشی، پیاده‌سازی و اجرای آن گام انجام می‌شود. سپس مشاهدهٔ انتخاب‌ها و رفتار نوشتن/استفادهٔ دوبارهٔ محتوا، و بعد آزمون واقعی نسخه‌به‌نسخه با baseline قدیمی معتبر. حذف مانع کامل سیاست Retail و نویسندهٔ تراکنشی CASC هنوز باقی است؛ معماری updater مستقل به‌صورت پنهانی Agent-dependent نشده است.

## قابلیت بازبینی

`classic-metadata-lab/preflight.py` دریافت نسخه/config، `manifests.py` ادامهٔ همان budget/deadline برای دو manifest، و `test_preflight.py` پانزده آزمون مصنوعی transport/config دارد. redirect، retry، HTTP fallback، اسکن، login یا دانلود بازی ندارند. parser/verifier از `updater-core/` موجود استفاده می‌کند. تست‌های transport بعد از دریافت واقعی اجرا شدند؛ اثبات دریافت واقعی همان receipt است، نه تعداد تست‌ها. این کد daemon/worker یا راهنمای import به Notion نیست.

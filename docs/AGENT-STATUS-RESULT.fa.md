# نتیجهٔ واقعی مشاهدهٔ وضعیت Agent

## شاهد Windows

[رسید ثابت](https://github.com/kokononox/battle-net-agent-lab/blob/78254a6265f50367f2914a7664221cbc73658271/reports/agent-status-latest.json) مربوط به source `bba31e04b2e50951e01ad4e654ede65290c06521` و run `39099954745`، attempt=1 است. schema و source/run identity با کد همان اجرا دوباره بررسی شدند. صرف push یا نتیجهٔ تست مصنوعی، جای این رسید قرار نگرفت.

- handshake محلی `/agent`: HTTP 200 و وجود token، بدون ورود حساب.
- دقیقاً یک `GET /game` با header authorization محلی همان اجرا: HTTP 200، پاسخ دو بایتی، شکل `empty_object`، صفر entry.
- مجموع دو درخواست؛ همان PID/مسیر فایل امضاشده/مالک listener قبل و بعد تأیید شد.
- هیچ login، initialize محصول، install/update/repair بازی یا باز کردن فایل بازی درخواست نشد. token، raw response، نام محصول یا link صادر نشدند.

این شاهد پاسخ‌دادن رابط مشاهده‌ای بدون حساب در همین محیط است. ضرورتی برای token با این آزمایش ثابت نشده، چون درخواست مقایسه‌ای بدون token به `/game` ارسال نشد. صفر محصول در VM تازه به وضعیت نصب کاربر، نسخهٔ Retail، حجم دانلود یا موفقیت آپدیت تعبیر نمی‌شود. `game_update_without_login_proven=false` و `retail_policy_proven=false` باقی‌اند. خود راه‌انداز/Agent در VM موقت state و شبکهٔ خودشان را داشته‌اند؛ «صفر نوشتن» یا سقف سخت شبکهٔ فرزند ادعا نمی‌شود.

## پیشنهاد منطقی برای مرحلهٔ بعد

پیش از نصب Classic باید اندازهٔ تازهٔ آن و محصول دقیق معلوم شود. جدول community در [TACT](https://wowdev.wiki/TACT) `wow_classic_era` را برای Classic Era معرفی می‌کند، اما خود جدول هشدار outdated دارد؛ بنابراین فقط candidate است، نه اثبات اینکه یک build تاریخی هنوز جاری/قابل دریافت است. رقم «حدود 50 MB» در نمونهٔ cascette برای متادیتای یک build، حجم کل بازی نیست و به جای آن استفاده نمی‌شود.

مسیر کم‌خطرترِ بعدی، خواندن مستقیم متادیتای عمومی رسمیِ Classic Era با downloader محدود خودمان است، نه `POST /install` صرفاً برای دیدن اندازه. سورس Installer که بررسی شد، product form و finalization دارد؛ به آن dry-run تضمین‌شده نسبت داده نمی‌شود. پیش‌فرض USA، locale یا MonitorPid آن بدون بررسی کپی نمی‌شود.

### دامنهٔ تازهٔ پیشنهادی، هنوز اجرا نشده و نیازمند تأیید

- فقط متادیتای رسمی `wow_classic_era` برای آزمایش Windows x64 / EU / enUS؛ این انتخاب آزمایش است، نه ادعای پروفایل نصب کاربر.
- سقف کل body دریافت‌شده 64 MiB و سقف مدت 10 دقیقه؛ سقف‌ها توسط downloader خودمان قابل اعمال‌اند، نه ترافیک غیرقابل‌سقف Agent.
- کشف snapshot تازهٔ نسخه و خواندن config و manifestهای لازمِ کوچک فقط در همان سقف؛ بدون دانلود payload بازی، encoding بزرگ خارج سقف، fallback نامحدود یا شروع صف دانلود. اگر کلید/فایل لازم در سقف قابل بررسی نبود، نتیجه unknown و توقف است؛ اجازهٔ بیشتر خودکار فرض نمی‌شود.
- بدون Agent product initialization، درخواست نصب/آپدیت/تعمیر، حساب، فایل کاربر یا تغییر نصب اصلی. فقط خلاصهٔ نسخه/هش/اندازه و محدودیت‌ها در مخزن قرار می‌گیرد؛ فایل بازی صادر نمی‌شود.

این دامنهٔ شبکهٔ بازی در این گام اجرا نشده است. پس از تأیید و اندازه‌گیری، امکان جا شدن نصب و staging بر اساس همان مقصد و build بررسی می‌شود. عدد فضای آزاد RUNNER_TEMP فقط برای volume همان اجرای گذشته است و تضمین runner بعدی نیست. نصب تازهٔ build جاری نیز تست نسخه‌به‌نسخه نیست؛ baseline قدیمیِ معتبر و target تازه‌تر جدا لازم‌اند. موفقیت Classic به Retail تعمیم کامل داده نمی‌شود.

## وضعیت مخزن

کد، workflow یک‌باره و رسید دو درخواست همگام‌اند. این sync فقط مستندسازی نتیجه و پیشنهاد مرز بعدی است؛ اجرای جدیدی درخواست نمی‌کند و معماری موتور مستقل را عوض نمی‌کند. فعلاً فقط تأیید دامنهٔ metadata بالا لازم است؛ نه کپی 130 گیگی، نه فایل تازه و نه رمز حساب.

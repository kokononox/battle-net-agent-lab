# تنظیم غیرنهایی فرم نصب Retail بدون حساب — c4

## نتیجه مستقیم

روی Windows 2025 گیت‌هاب، بدون حساب، یک POST /install/wow با finalized=false و زبان enUS و مسیر تازه و خالی متعلق به آزمایش ارسال شد. پاسخ HTTP 201، دارای فرم معتبر و ۱۶۶۳ بایت بود. مقدار finalized در پاسخ نیز false بود.

| بخش | پیش از درخواست | پس از درخواست |
| --- | --- | --- |
| Agent | 0 | 0 |
| authentication | 0 | 0 |
| min_spec | 0 | 0 |
| game_dir | 800 | 0 |
| language | 704 | 0 |
| eula | 0 | 0 |
| tome_path | 0 | 0 |

این مشاهده نشان می‌دهد فرم در همین اجرای بدون حساب پس از درخواست غیرنهایی خطای مسیر و زبان اعلام نکرد. معنی رسمی کدهای ۸۰۰ و ۷۰۴، نصب کامل یا انتقال بازی از آن نتیجه نمی‌شود.

## ابهام مسیر — مانع ادامه بی‌قید

response_game_dir_matches_requested=false: رشته game_dir برگشتی با رشته ارسالی یکسان نبود. آزمایش فقط برابری دقیق رشته‌ها را سنجید؛ نرمال‌سازی حروف/جداکننده، رابطه والد/فرزند، یا وجود واقعی مسیر برگشتی بررسی نشده است. بنابراین نه خروج از مسیر را ثابت می‌کند و نه تطبیق امن مقصد را. مسیر خام صادر نشد و به مقصد برگشتی برای کار بعدی اعتماد نشد.

گام بعدی قبل از هر دانلود: طبقه‌بندی مسیر برگشتی، بدون انتشار خود مسیر، به برابری نرمال‌شده، زیرپوشه مقصد متعلق به آزمایش، خارج از مقصد یا مسیر نامعتبر. تنها سپس می‌توان مقصد و توقف مطمئن آزمایش انتقال را طراحی کرد.

## درخواست و کنترل‌ها

- پیش از درخواست، finalized اولیه دقیقاً false، خطای authentication و min_spec صفر و enUS در هر سه آرایه list/text/speech بود؛ در غیر این صورت درخواست ارسال نمی‌شد.
- مسیر تازه در RUNNER_TEMP روی درایو ثابت ساخته شد؛ مسیر و اجداد بدون reparse و مقصد خالی بررسی شد.
- فضای لازم اعلام‌شده Agent 52,000,000,000 بایت بود؛ حداقل فضای آزاد با حاشیه ۱۰ GiB برابر 62,737,418,240 بایت محاسبه شد. فضای آزاد مقصد 235,862,560,768 بایت بود. این ظرفیت، تضمین اندازه دانلود کامل نیست.
- payload فقط finalized=false، game_dir، language=[enUS]، selected_asset_locale=enUS و selected_locale=enUS داشت.
- پارامتر حساب، کشور، پذیرش EULA و تنظیم دورزدن حداقل سیستم وجود نداشت.
- دقیقاً سه درخواست بعد از handshake: GET /game، POST /install و POST /install/wow. هیچ retry، /update، درخواست finalized=true، polling نصب یا اجرای بازی انجام نشد.
- هشت بررسی هویت، چهار تأیید گذار موقت محدود با همان هش و امضا، و هیچ شکست هویتی ثبت شد. cleanup پردازش متعلق به آزمایش تلاش شد.
- هیچ توکن، مسیر خام، UUID، پاسخ خام، داده رابط کاربری یا باینری منتشر نشد.

## EULA و محدودیت استنتاج

پرچم eula در پاسخ true و کد خطایش صفر باقی ماند؛ معنی این پرچم تأیید نشده است. این مشاهده پذیرش قبلی/جدید شرایط توسط کاربر را ثابت نمی‌کند. eula_review_pending در بخش فرم اولیه گزارش، سیاست احتیاطی ابزار است، نه خطای اعلام‌شده سرور. بخش form عمداً پاسخ اولیه را حفظ می‌کند؛ نتیجه بعدی در form_update جداست.

finalized=false خواسته شد و همان مقدار در همین پاسخ دیده شد؛ این نه تضمین تمام اثرات جانبی Agent است، نه اثبات اینکه هیچ داده‌ای جابه‌جا نشده. سقف سخت بایت برای فرزندان وجود نداشت. درخواست صریح شروع محتوای بازی یا دانلود کامل صادر نشد؛ محتوای شبکه هم در c4 ابزارگذاری نشده است. بنابراین انتقال موفق بازی، ارسال مشخصات در فاز دانلود و ذخیره سرور هنوز ثابت نشده‌اند. پرسش دوم فایل‌های بازی شروع نشده است.

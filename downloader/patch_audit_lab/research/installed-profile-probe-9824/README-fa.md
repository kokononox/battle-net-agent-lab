# بررسی فقط‌خواندنی دو فایل برای هویت و پروفایل نصب Retail

این بستهٔ مستقل پس از اجازهٔ صریح کاربر برای خواندن `.build.info` و build-config معرفی‌شده در آن ساخته شده است. هیچ اسکن یا خواندن payload آرشیو، دسترسی محتوایی به Lab، دانلود یا تغییر بازی انجام نمی‌دهد. EXE یا آپدیتر کامل نیست.

## اجرا روی سیستم کاربر

1. ZIP را در پوشه‌ای تازه **خارج از بازی و Lab** استخراج کنید؛ پوشهٔ Lab قبلی را جابه‌جا نکنید.
2. بازی و Battle.net را ببندید و `CHECK-INSTALLED-PROFILE.cmd` را اجرا کنید.
3. باید `Diagnostic build: installed-profile-probe-1` دیده شود.
4. **پوشه‌ای که مستقیماً `.build.info` داخل آن است** را انتخاب کنید؛ معمولاً ریشهٔ World of Warcraft، نه `_retail_`، نه `Data` و نه Lab. اگر فایل در پوشهٔ انتخابی نباشد، ابزار متوقف می‌شود و دنبال آن اسکن نمی‌کند.
5. فقط `INSTALLED-PROFILE-to-share.json` را از مسیر اعلام‌شده ارسال کنید. فایل خام `.build.info`، config یا فایل‌های PRIVATE را ارسال نکنید. اگر متوقف شد، فقط JSON خطای امنِ خروجی را ارسال کنید.
6. هنوز `CONTINUE-ONE-BATCH.cmd` را اجرا نکنید. نتیجهٔ این مرحله باید ابتدا بررسی شود.

Python 3.10+ لازم است؛ هیچ pip یا اجرای Administrator لازم نیست. نسخهٔ فعلی روی Linux/Python3.13 آزمایش شده و اجرای native Windows آن در این محیط تأیید نشده است. قرارداد rename ویندوز در تست مدل شده، نه روی فایل‌سیستم ویندوز اجرا شده است.

## دامنهٔ دقیق خواندن

- فقط `.build.info` با سقف ۱ MiB؛ انتخاب دقیقاً یک ردیف active برای Retail؛ header تایپ‌دار و BOM پشتیبانی می‌شود.
- فقط `Data/config/aa/bb/BUILD_KEY` که `BUILD_KEY` از همان ردیف آمده و دقیقاً ۳۲ رقم hex کوچک است؛ حداکثر ۴ MiB. مسیر از ورودی دلخواه یا lookup شبکه ساخته نمی‌شود.
- MD5 کل config باید با کلید آن یکی باشد. `build-uid=wow` و قالب نام Retail بررسی و نسخهٔ config با نسخهٔ ردیف، اگر وجود داشته باشد، تطبیق داده می‌شود. MD5 هویت محتواست، نه امضای ناشر یا تأیید کامل نصب.
- هیچ `Data/data`، index، archive یا پوشهٔ بازی enumerate نمی‌شود. هیچ بازی/Agent/native binary اجرا نمی‌شود. هیچ فایل Lab خوانده یا تغییر نمی‌کند.
- هیچ fallback به مسیر دیگر، ورژن اینترنتی، بازی دیگر یا انتخاب زبان/region حدسی وجود ندارد.

## پروفایل و حریم خصوصی

پروفایل فقط یک **projection تشخیصی از tagهای شناخته‌شدهٔ همان ردیف active** است؛ سیاست انتخاب vendor، فهرست قطعی فایل‌ها یا سلامت فایل‌های بازی نیست. `?` برای token شناخته‌شده به‌عنوان نحو شناخته می‌شود، نه اثبات انتخاب vendor. شناسه‌های اختیاری `acct-*?` و `geoip-*?` فقط شمرده می‌شوند و هرگز برای تعیین region یا locale استفاده نمی‌شوند.

حالت پشتیبانی‌شدهٔ فعلی: Windows / x86_64 / EU و localeهای فهرست‌مجازِ برنامه‌ریز. نبودن locale، چند region/platform/architecture، token ناشناخته یا پروفایل پشتیبانی‌نشده باعث `profile=null` و کد تشخیصی ثابت می‌شود؛ نه حدس و نه ادامهٔ خودکار. هویت نسخه ممکن است تأیید شود ولی پروفایل نامعلوم بماند.

فقط نسخه، هویت MD5 config، پروفایل فهرست‌مجاز و شمارنده‌های نحوی صادر می‌شوند. مسیرها، raw tags، branch، KeyRing، مقادیر account/geoip و فیلدهای config ناشناخته صادر یا در خطا چاپ نمی‌شوند. فایل خام در Results کپی نمی‌شود. جزئیات exception و traceback چاپ نمی‌شود؛ فقط مرحله، نوع خطا، کد ثابت و errno/WinError عددی مجازند.

گزارش به Lab/snapshot قبلی متصل نشده و قابل import به‌عنوان اثبات محتوا نیست. projection هدف Download هنوز اجرا نشده است. تشخیص config مساوی با target پژوهشی، حتی اگر رخ دهد، به معنی نیازنداشتن به آپدیت یا آماده‌بودن نصب نیست. مقدار دانلود لازم null می‌ماند.

## انتشار خروجی

فقط در پوشه‌ای جدید، بیرون بازی و Lab، گزارش نوشته می‌شود. ورودی‌ها پیش/پس از خواندن و قبل/بعد از انتشار با fingerprint کنترل می‌شوند. symlink/reparse و فایل ورودی چند-hardlink رد می‌شوند. انتشار Windows با rename بدون جایگزینی مقصد، و POSIX با hardlink بدون جایگزینی است. فایل رقیب بازنویسی نمی‌شود؛ تغییر ورودی پس از انتشار باعث حذف خروجی خود ابزار می‌شود. مدل fingerprint، OS snapshot یا حفاظت در برابر نویسندهٔ مهاجم نیست.

## روش CLI

```bash
python -B installed_profile_probe.py --game-root "ROOT_CONTAINING_BUILD_INFO" --out-new "NEW_FOLDER_OUTSIDE_GAME_AND_LAB"
```

در Linux از مسیر فیزیکی بدون symlink استفاده کنید؛ در محیط پژوهشی `/data` alias است و باید از realpath استفاده شود. CLI بدون `--out-new` فقط JSON را در stdout چاپ می‌کند؛ redirection داخل بازی یا Lab مجاز نیست.

## تست و بازاجرا

`run_experiments.py` همین پوشه ۳۱۹ تست قبلی و ۴۷ تست جدید را اجرا می‌کند: مجموع ۳۶۶. نتیجهٔ قطعی در `TEST-RESULTS.json` و logها ثبت می‌شود. تست‌های جدید شامل دقیقاً دو خواندن فایل بازی، نبود scan/network، سقف اندازه، انتخاب ردیف مبهم، MD5/نسخهٔ ناهماهنگ، عدم حدس زبان/region، حریم خصوصی، symlink/hardlink، انتشار بدون overwrite و cleanup هستند.

game rootها و `.build.info` تست‌ها مصنوعی‌اند. فقط یک نمونهٔ config واقعی پین‌شده نیز در root مصنوعی آزموده می‌شود. فایل نصب یا Lab واقعی کاربر در این محیط موجود نیست؛ اجرای موفق بسته باید روی سیستم کاربر تأیید شود. تست‌های Windows با مدل/تزریق روی Linux انجام می‌شوند.

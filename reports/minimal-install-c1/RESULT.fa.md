# نتیجه واقعی پایلوت C1 شش‌تایی

منبع: run 40156142523، کد اجراشده d80b63c38ef9acbc2bc21accd7994784cb689442. هر شش گزارش artifact بازیابی و با schema، شناسه اجرا، replica، commit منبع و SHA256 آرشیو تطبیق داده شدند؛ هیچ محیطی حذف نشده است.

- **r1 و r2، کنترل بدون تغییر hosts:** نصب بر اساس معیار از پیش ثبت‌شده signed_binary_version_v1 تأیید شد.
- **r3 و r4، telemetry-in.battle.net:** پیش از اجرای نصب‌کننده، بررسی اثر override در resolver تأیید نشد؛ هدف اجرا نشد.
- **r5، level3.blizzard.com و r6، us.version.battle.net:** همان توقف پیش از اجرای نصب‌کننده؛ هدف اجرا نشد.
- هر چهار مداخله backup و override ثبت‌شده دارند؛ flush با کد صفر ثبت شده، ولی resolver_verified=false است. در هر چهار محیط hosts اصلی بازیابی شد. کنترل‌ها hosts را تغییر ندادند و نیازی به restore نداشتند.

این batch شامل شش job ولی فقط دو اجرای نصب‌کننده است، نه شش نصب موفق و نه چهار شکست نصب ناشی از انسداد دامنه. چهار آزمایش حذف مقصد هنوز معتبر اجرا نشده‌اند. درباره ضروری بودن level3 یا us.version، غیرضروری بودن telemetry، مسدود بودن همه راه‌های آن یا نبود نشتی نتیجه‌ای نداریم. timestamp خالی در چهار مداخله ناشی از اجرا نشدن هدف است و با مقدار فرضی پر نشده است.

## اشکال انتشار و اصلاح آن
هر شش artifact وجود داشتند؛ push گزارش تجمیعی به دلیل جلو رفتن شاخه با non-fast-forward رد شد. گزارش‌ها از artifactهای همان اجرا بازیابی شدند، نه از اجرای مجدد یا بازسازی حدسی.

ناشر بعدی پیش از push یک artifact تجمیعی نگه می‌دارد. commit فقط-گزارش روی تازه‌ترین سرشاخه cherry-pick می‌شود؛ push عادی و حداکثر سه تلاش دارد. تعارض گزارش باعث توقف می‌شود؛ force-push یا بازنویسی تغییرات جدید انجام نمی‌شود. دو آزمون Git محلی، حفظ تغییرات غیرمرتبط و توقف در تعارض گزارش را بررسی می‌کنند. این اصلاح هنوز در job انتشار GitHub بازآزمایی نشده است.

## گام بعد
پیش از اجرای مجدد نصب‌های مداخله‌ای، probe محدود resolver باید علت‌ها را تفکیک کند: پاسخ IP غیرصفر، پاسخ sinkhole، خطای DNS و timeout؛ با بررسی قبل از تغییر، پس از تغییر و پس از بازیابی. probe فعلی فقط boolean می‌دهد و علت دقیق مشخص نیست. guard نباید برای گرفتن نتیجه مثبت حذف شود یا هر خطای DNS به عنوان انسداد موفق پذیرفته شود.

با این commit بازیابی، نصب تازه‌ای مجاز/شروع نمی‌شود. نسخه منجمد Unified Firewall 0.9.10 تغییری ندارد؛ فایل اجرایی نهایی ایزولاسیون هنوز آماده نیست.

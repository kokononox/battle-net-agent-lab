# گزارش وضعیت فعلی — بدون اصلاح یا فعال‌سازی

## فقط این کار
۱. پنجره‌های قبلی ابزار را ببندید و ZIP را کامل در پوشه‌ای جدید استخراج کنید.
۲. فقط Read-System.cmd را اجرا کنید. درخواست Administrator مربوط به همین ابزار را بررسی و تأیید کنید.
۳. فایل system-audit-report.json از همین پوشه را پیش از ارسال بررسی و سپس ارسال کنید. اگر فرمان خطا داد، audit-error.json را ارسال کنید. journal، فایل hosts، فهرست خصوصی یا backupهای خود را ارسال نکنید.
۴. فعلاً Enable، Prepare، Resume، Diagnose، فایل۹۹ یا EmergencyReset را اجرا نکنید.

این فرمان تنظیمات شبکه را تغییر نمی‌دهد: هیچ قانون فایروال، VPN، DNS، route، hosts، IPv6 binding، registry، task یا سرویس را تغییر/حذف/فعال نمی‌کند. فقط فایل گزارش خود را کنار ابزار می‌نویسد؛ گزارش قبلی خود ابزار در همین مسیر جایگزین می‌شود. پنجرهٔ فرمان برای خواندن نتیجه منتظر کلید می‌ماند و سپس بسته می‌شود. سرویس یا نگهبان دائمی نصب نمی‌شود. هیچ DNS lookup یا اتصال آزمایشیِ عمدی اجرا نمی‌شود.

## چه چیزی خوانده می‌شود
- نسخه و معماری Windows و PowerShell؛ وضعیت profileهای فایروال در ActiveStore/PersistentStore، شمار قواعد قدیمی/نام‌دار و سایر Allowهای خروجی.
- journal اصلی همین دستگاه با کنترل checksum/ACL و مقایسهٔ تصویر دقیق و معنایی سه قاعدهٔ ابزار؛ فقط نتیجهٔ مقایسه صادر می‌شود، نه GUID، IP یا خود journal. هیچ lock file جدیدی ساخته نمی‌شود. اگر journal هنگام خواندن عوض شود، علامت می‌خورد؛ snapshot اتمیک/مجوز تغییر نیست.
- وجود و profileهای ذخیره‌شدهٔ فایل کیل‌سوییچ قدیمی، بدون نام VPN یا سرور. وجود state ثابت نمی‌کند متعلق به همین دستگاه یا مجاز به restore است.
- hosts: شمار markerهای BLIZZARD-BLOCK، خرابی/توازن آن‌ها، شمار aliasهای فهرست BAT۶ داخل/بیرون marker، وجود sinkhole برای level3.blizzard.com و شمار backupهای BAT. محتوای خام hosts صادر نمی‌شود؛ SHA256 آن برای مقایسه گزارش می‌شود. ورودی متفاوتِ این دامنه لزوماً sinkhole تلقی نمی‌شود؛ مقدار واقعی نیز صادر نمی‌شود.
- مقدار DisabledComponents رجیستری IPv6 و شمار bindingهای روشن/خاموش adapterهای قابل‌مشاهده؛ وضعیت پس از reboot اثبات نمی‌شود.
- شمار اتصال‌های Windows VPN از حساب elevated و AllUser، DNS و NRPT، routeهای پیش‌فرض، نشانگرهای WinINet proxy همان حساب elevated، و وضعیت دو سرویس BFE/MpsSvc. IP، نام رابط، نام/رمز/سرور VPN یا URL proxy صادر نمی‌شود.

هر بخش status جدا دارد. unavailable یعنی نتوانستیم بخوانیم؛ معادل خالی یا سالم نیست. ابزار اجازهٔ فعال‌سازی صادر نمی‌کند؛ activation_approved و complete_security_audit همیشه false هستند. network_settings_changed_by_tool=false بیانگر نبود فرمان تغییردهنده در این ابزار است؛ ثابت نمی‌کند برنامهٔ دیگری همزمان چیزی را تغییر نداده است.

## محدودیت‌ها
این گزارش ممیزی کامل امنیتی یا گواه نبود نشتی نیست. قواعد نامرتبط، درایورها، taskها، افزونه‌های WFP، VPNهای غیرWindows، proxyهای WinHTTP/برنامه‌ها، adapterهای مخفی و بسته‌های واقعی شبکه به‌صورت جامع بررسی نمی‌شوند. شمار سایر Allowها به‌تنهایی میزان خطر را تعیین نمی‌کند. وجود تنظیم فعلی ثابت نمی‌کند ما یا ابزار قبلی آن را ایجاد کرده‌ایم. گزارش مبنای پاک‌سازی خودکار یا Force-Allow نیست.

در UAC با حساب متفاوت، برخی بخش‌های user-scoped مربوط به همان حساب elevated هستند؛ گزارش این scope را مشخص می‌کند. شناسه‌ها و آدرس‌ها عمداً حذف شده‌اند، بنابراین بررسی برخی تداخل‌ها ممکن است بعداً به اطلاعات محدود دیگری نیاز داشته باشد. فایل را قبل از ارسال بررسی کنید.

آزمون‌ها فقط روی runnerهای Server اجرا می‌شوند؛ جای Windows10/11 واقعی یا دستگاه کاربر نیستند. رسیدهای همراه، آنچه واقعاً آزموده شده و مسیر غیرمدیر/UAC آزموده‌نشده را مشخص می‌کنند.

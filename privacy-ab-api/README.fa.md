# آزمون H1: مسدودسازی یک دامنه با مشاهده از تولد فرایند

هدف: مقایسهٔ راه‌اندازی بدون حساب در دو ماشین تازهٔ میزبانی‌شده، baseline و block_telemetry. فقط دامنهٔ telemetry-in.battle.net در hosts ماشین موقت به loopback نگاشت می‌شود؛ فایل اصلی در پایان برگردانده می‌شود. این محدودسازی کل آپلود نیست و مسیر IP مستقیم، دامنهٔ جایگزین، resolver مستقل یا ترافیک رمزگشایی‌نشده همچنان ممکن است.

## ثبت و دروازهٔ اجرا
- روش موفق G1: توقف ریشه و فرزندان، بررسی امضای Blizzard و هش تصویر، نصب قلاب فقط‌خواندنی، سپس resume.
- خودآزمایی root/child، اولین درخواست، نوشتن چندبخشی، WSASend و ورودی منفی EncryptMessage باید همگی موفق باشند. آزمون SSPI با context نامعتبر صرفاً چیدمان بافر و گرفتن ورودی را می‌سنجد؛ رمزنگاری یا ارسال TLS واقعی را اثبات نمی‌کند. دادهٔ مصنوعی در شواهد واقعی قرار نمی‌گیرد.
- باینری آغازگر به هش de5d32d4ea5eed5a9e120027fb68b370976dbfecc8f2a8f91305977f0b87fcaf مقید است. دیگر تصاویر باید امضای معتبر Blizzard داشته باشند؛ تفاوت نسخهٔ فرزندان هنگام تحلیل بررسی می‌شود.
- HTTP روی Winsock با sN و ورودی پیش از TLS از EncryptMessage با ctxN مشخص می‌شود. ctxN موفقیت محلی رمزنگاری است، نه سند ارسال یا پذیرش سرور. شکست API هرگز به‌عنوان درخواست موفق مونتاژ نمی‌شود.
- برخلاف G1، Host معتبر به چهار مقصد محدود نمی‌شود تا مقصد جایگزین قابل مشاهده باشد. HTTP/2، OpenSSL و QUIC در متن روشن این ابزار پوشش ندارند. بازاستفادهٔ context TLS و ترتیب فراخوانی هم‌زمان محدودیت دارند.
- pktmon هم‌زمان فقط فرادادهٔ شبکه و SNI/DNS را صادر می‌کند؛ ارتباط PID از جدول نمونه‌برداری‌شده تخمینی است. فایل خام موقت حذف می‌شود؛ کلید TLS ذخیره نمی‌شود. درخواست‌های API به PID و هش همان تصویر متصل‌اند.

## محدودیت نتیجه
پنجرهٔ یکسان ۱۲۰ ثانیه، فقط ادامهٔ زبان، بدون دکمهٔ Install، حساب، بازی یا آپدیت کامل. عکس ماشین، build، مدل CPU و هش فرایندها ثبت می‌شوند؛ دو VM دقیقاً یک سخت‌افزار/IP نیستند و این یک جفت تکرار است، نه نتیجهٔ آماری. نبود دادهٔ سخت‌افزاری در مشاهده تضمین نبود آپلود نیست. اثر انگشت فایل‌های بازی و انتقال A به B هنوز آزمایش نشده است.

## اجرا و هزینه
فقط یک push با پیام دقیق `lab: approved process-birth TLS telemetry A-B comparison h1` روی شاخهٔ پژوهش اجرا را فعال می‌کند؛ rerun پذیرفته نیست. از windows-2025 استاندارد و ubuntu-latest استاندارد استفاده می‌شود؛ runner بزرگ/پولی فعال نمی‌شود. مصرف سهمیهٔ Actions تابع حساب است و رایگان بودن تضمین نمی‌شود. این ابزار برای اجرای مستقیم روی سیستم کاربر نیست.

# بررسی آفلاین نشانگر محلی CASC

این ابزار فقط‌خواندنی، فرضیهٔ نشانگر وابسته به نام میزبان را روی **نسخهٔ موجود** بررسی می‌کند؛ بازی، Agent، ورود به حساب یا دانلود تازه لازم ندارد. فقط Python 3 و کتابخانهٔ استاندارد لازم است. کد را پیش از اجرا می‌توانید بخوانید.

## اجرا

فایل ZIP را باز کنید و در همان پوشه اجرا کنید:

```powershell
python origin_check.py "D:\World of Warcraft"
```

برای مقایسهٔ نشانگرهای دو نسخهٔ موجود، بدون چاپ خودِ نشانگر:

```powershell
python origin_check.py "D:\World of Warcraft" "E:\WoW-copy"
```

می‌توان مسیر مستقیم پوشهٔ `Data/data` را هم داد. مسیرها فقط روی رایانهٔ خودتان در خط فرمان استفاده می‌شوند؛ وارد خروجی JSON نمی‌شوند. اگر خواستید نتیجه بررسی شود، **فقط JSON خروجی** را بفرستید، نه فایل بازی، نام میزبان یا مسیر خصوصی.

## معنی نتیجه

- `marker_layout_observed`: دست‌کم یک بلوک معتبر از ۱۶ رکورد cross-link در محدودهٔ خوانده‌شده پیدا شد.
- `matches_current_hostname_prediction`: آیا بخش هفت‌بایتیِ نشانگر با پیش‌بینی `MD5(hostname + "data/data")` برای رایانهٔ فعلی مطابقت دارد؟ در نسخهٔ کپی‌شده از میزبان دیگر ممکن است false باشد؛ false هویت مبدأ را تعیین نمی‌کند.
- `two_copy_marker_sets_equal`: در صورت داشتن نشانگر در هر دو نسخه، آیا مجموعهٔ نشانگرهایشان برابر است؟ این نتیجه به معنی برابری کل فایل‌ها یا اثبات یک شخص مشترک نیست.
- `marker_variants`: تعداد نشانگرهای متمایز مشاهده‌شده. چند نشانگر می‌تواند ناشی از تاریخچهٔ مختلط باشد؛ ابزار علت را حدس نمی‌زند.
- مقدار null یعنی شاهد کافی برای آن مقایسه به دست نیامده است.

**نبود تطبیق، نبود نشانگر در کل بازی را ثابت نمی‌کند.** این ابزار ابزارِ اثبات هویت کاربر، اکانت، ماشین فیزیکی یکتا یا منشأ جعل‌ناپذیر نیست. نام‌های میزبان می‌توانند تکراری یا تغییرکردنی باشند. هفت بایت MD5 شناسهٔ قطعی نیست. وجود این ساختار به‌تنهایی ارسال آن به سرور را هم ثابت نمی‌کند.

## حدود و ایمنی

- هیچ اتصال شبکه، اجرای بازی/Agent، تغییر رجیستری یا نوشتن فایل بازی ندارد.
- فقط پیشوند ۶۴KiB از حداکثر ۶۴ آرشیو `data.NNN` را می‌خواند؛ حداکثر ۴MiB خواندن محتوای آرشیو.
- نام میزبان و مقدار/هش نشانگر در خروجی چاپ نمی‌شوند.
- پیوند نمادین، reparse point و فایل hard-linked رد می‌شوند؛ تغییر هویت/اندازه/زمان فایل در حین بررسی موجب رد نتیجه می‌شود. بهتر است Battle.net و بازی بسته باشند.
- هر شاهد ساختاری به ۱۶ شمارهٔ شاخص متمایز، شمارهٔ آرشیو سازگار، اندازه و flags و tail مناسب، و checksum A برای تک‌تک رکوردها نیاز دارد. checksum B بررسی نمی‌شود؛ اعتبار کل کانتینر ادعا نمی‌شود.
- قالب‌های پشتیبانی‌نشده یا پیشوندهای خارج از محدوده نامعلوم می‌مانند. خطای I/O پیام خصوصی چاپ نمی‌کند.

## اعتبار آزمون

```powershell
python -m unittest discover -s . -p "test_*.py"
```

۱۰ آزمون مصنوعی شامل تطبیق میزبان، تغییر میزبان، حفظ نشانگر در کپی، checksum خراب، تکرار رکورد، دادهٔ ناقص و رد لینک‌ها همراه ابزار است. این آزمون‌ها **جای نمونهٔ واقعی Agent را نمی‌گیرند**.

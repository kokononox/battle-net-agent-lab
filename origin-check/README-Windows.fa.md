# نسخه مستقل ویندوز — نسخه ۲

این بسته حاوی CASCOriginCheck.exe است؛ نصب پایتون لازم ندارد.

۱. ZIP را کامل باز کنید؛ برنامه را از داخل ZIP اجرا نکنید.
۲. Battle.net و WoW را ببندید.
۳. CASCOriginCheck.exe را باز کنید. برنامه به دسترسی Administrator نیاز ندارد.
۴. با Browse پوشه موجود WoW یا پوشه Data/data را انتخاب کنید.
۵. برای مقایسه دو نسخه، پوشه دوم را هم انتخاب کنید؛ در غیر این صورت خالی بگذارید.
۶. Check offline را بزنید. در هر نوبت حداکثر ۶۴ آرشیو و از هر آرشیو حداکثر ۶۴KiB خوانده می‌شود.
۷. اگر آرشیو بیشتری باشد، دکمه Next batch (64 max) فعال می‌شود. با آن دسته بعد را بررسی کنید؛ نیازی به حذف یا جابه‌جایی فایل‌ها نیست.
۸. برای ارسال نتیجه هر دسته، Copy JSON result را بزنید و فقط همان JSON را بفرستید. Check offline همیشه از دسته اول شروع می‌کند. تغییر پوشه هم نیاز به شروع دوباره با همین دکمه دارد.

برنامه فقط پیشوند محدود آرشیوهای موجود را می‌خواند. به حساب وارد نمی‌شود، اتصال شبکه ندارد و بازی/Agent را اجرا یا فایل بازی را تغییر نمی‌دهد. نام میزبان، مسیرها و هش نشانگر در JSON خروجی قرار نمی‌گیرند.

محدودیت مهم: این آزمون، نبودن نشانگر در کل بازی یا هویت قطعی شخص/اکانت/دستگاه را ثابت نمی‌کند. نسخه واقعی Agent در آزمایش‌های قبلی هنوز تطبیق مثبت این نشانگر نداشته است؛ برنامه برای آزمودن فرضیه روی آرشیو موجود است.

matches_current_hostname_prediction یعنی مقایسه با نام میزبان رایانه فعلی، نه شناسایی رایانه ناشناخته‌ای که فایل را از آن گرفته‌اید. two_copy_marker_sets_equal فقط برابری مجموعه نشانگرهای مشاهده‌شده است، نه برابری کل فایل‌ها.

فایل اجرایی گواهی امضای دیجیتال تجاری ندارد (unsigned)؛ ممکن است ویندوز یا ابزار امنیتی هشدار بدهد. این هشدار را نشانه ایمن بودن برنامه تلقی نکنید و برای اجرا، محافظت‌های سیستم را خاموش نکنید. می‌توانید به‌جای آن کد قابل‌بررسی یا بسته پایتون را استفاده کنید. build-receipt.json شامل SHA256 فایل اجرایی و نتیجه آزمون نسخه ساخته‌شده است.


رفع خطای archive_limit: نسخه ۱ با دیدن بیش از ۶۴ آرشیو، پیش از بررسی متوقف می‌شد. نسخه ۲ بیش از ۶۴ آرشیو را به دسته‌های محدود تقسیم می‌کند؛ سقف خواندن هر نوبت همچنان ۴MiB است.

فیلدهای جدید:
- total_eligible_archives: تعداد آرشیوهای دارای شماره پشتیبانی‌شده.
- archives_checked: تعداد آرشیوهای همین دسته.
- archives_not_checked_this_run: تعداد آرشیوهایی که در همین نوبت خوانده نشده‌اند؛ شامل دسته‌های دیگر است.
- next_batch_start: اگر null نباشد، دسته بعد وجود دارد.
- archive_scan_complete: فقط وقتی true است که تمام آرشیوهای موجود، در همین نوبت و با شناسه پشتیبانی‌شده بررسی شده باشند. این فیلد هم به معنی بررسی کل محتوای بازی نیست.
- observed_batch_marker_sets_equal: فقط مقایسه نشانگرهای همین دسته، نه همه آرشیوها. مقایسه کامل دو مجموعه، هنگام بررسی ناقص به‌جای حدس زدن null می‌ماند.
- unsupported_archive_ids: تعداد آرشیوهایی با شماره بالاتر از محدوده پشتیبانی این روش. وجودشان مخفی نمی‌شود و نتیجه کامل اعلام نمی‌شود.

هیچ نتیجه منفی از یک دسته، نبود نشانگر در کل بازی را ثابت نمی‌کند. برنامه نشانه‌ای را که هنوز پیدا نشده، موفقیت یا نبود قطعی اعلام نمی‌کند.

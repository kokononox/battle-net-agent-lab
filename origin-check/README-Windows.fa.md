# نسخه مستقل ویندوز — نسخه ۵

این ZIP حاوی CASCOriginCheck.exe است؛ نصب پایتون یا دسترسی Administrator لازم نیست. عنوان پنجره باید v5 باشد. فایل unsigned است؛ برای اجرای آن محافظت‌های سیستم را خاموش نکنید.

## بررسی جدید: تطبیق دو فایل کوچک با بیلد رسمی 70448

۱. ZIP را در یک پوشه جدا کامل استخراج کنید؛ برنامه را از داخل ZIP اجرا نکنید.
۲. Battle.net و WoW را ببندید.
۳. برنامه را باز کنید و با Browse اول، پوشه اصلی WoW را انتخاب کنید؛ پوشه‌ای که .build.info و Data و _retail_ دارد. مسیر مستقیم Data/data یا _retail_ هم شناسایی می‌شود.
۴. کادر دوم (Second copy) را خالی بگذارید.
۵. دکمه Verify build 70448 files را بزنید. برای این آزمایش Archive diagnostics یا Next batch لازم نیست.
۶. با Copy JSON result نتیجه را کپی و فقط همان JSON را ارسال کنید.

این حالت ابتدا .build.info را می‌خواند، ولی فقط تطبیق آن با Product=wow و بیلد فعال 12.1.5.70448 و کلید 88d5e8ef05ec5a8446cdec93d142d7c6 را گزارش می‌کند. فیلدهای دیگر متادیتا، مسیرها یا نام میزبان صادر نمی‌شوند. اگر بیلد عوض شده باشد، بررسی با build_mismatch متوقف می‌شود؛ بیلد دیگری خودکار جایگزین نمی‌شود.

سپس فقط این دو فایل مشخص در _retail_/Utils خوانده و هش می‌شوند؛ اجرا نمی‌شوند:
- WowVoiceProxy.exe
- WowWindowsExceptionHandler.dll

مرجع اندازه و CKey آن‌ها از پیکربندی رسمی همین بیلد و IN manifest آن استخراج شده است؛ هش پیکربندی و EKey/chunk/CKey فهرست نصب هنگام ساخت مرجع بررسی شده‌اند. این بررسی معادل داشتن یک نصب کامل دیگر یا امضای دیجیتال ناشر نیست.

## معنی نتیجه

- active_build_matched: متادیتای فعال نصب با بیلد مورد انتظار تطبیق داشت.
- content_verified: اندازه و هش کامل همان فایل با یکی از واریانت‌های رسمی همین بیلد یکسان است.
- hash_mismatch: اندازه مطابق یکی از واریانت‌هاست، ولی هش همان فایل مطابقت ندارد. علت می‌تواند متفاوت باشد؛ ابزار تقلب یا بدافزار اعلام نمی‌کند.
- size_not_in_reference: اندازه فایل در مرجع انتخابی نبود؛ فایل بزرگ یا متفاوت خودکار خوانده نمی‌شود.
- not_found: فایل در مسیر مشخص‌شده پیدا نشده؛ نبود نشانگر در کل بازی از این نتیجه استنباط نمی‌شود.
- all_selected_components_match فقط درباره همین دو فایل است. فایل اصلی Wow.exe، wow_loader.dll و آرشیوهای data.NNN در این حالت خوانده نمی‌شوند.

تطبیق مثبت، فقط تطبیق بایت‌های فایل‌های انتخاب‌شده با مرجع رسمی است؛ نه شناسایی شخص یا رایانه دانلودکننده، نه نبود نشانگر در دیگر فایل‌ها یا کانتینرها، نه اثبات سلامت/امنیت کل نصب.

## حدود و حریم خصوصی

سقف کل خواندن این حالت، شامل .build.info و دو فایل، ۴MiB است. متادیتا حداکثر ۶۴KiB پذیرفته می‌شود. نه شبکه‌ای استفاده می‌شود، نه بازی/Agent اجرا می‌شود و نه فایل بازی یا متادیتای نصب نوشته می‌شود. خروجی فقط در پنجره و در صورت انتخاب شما در Clipboard قرار می‌گیرد.

فایل‌های symlink/reparse/hardlink رد می‌شوند؛ اثر انگشت فایل قبل/هنگام/بعد از خواندن بررسی می‌شود. این کنترل‌ها ادعای اثبات race-free بودن سیستم‌عامل ندارند. تغییر فایل موجب source_changed می‌شود.

در تطبیق مثبت فقط CKey مرجع عمومی نشان داده می‌شود؛ هش محتوای غیرمنتظره صادر نمی‌شود. برای ادامه فایل بازی، سرآیند خام، نام رایانه، مسیر خصوصی یا هش شناسه نفرستید.

## حالت قبلی آرشیوها

Archive diagnostics همان بررسی محدود نسخه‌های قبل است: حداکثر ۶۴ پیشوند ۶۴KiB در هر دسته، با Next batch برای ادامه. قواعد تأیید نشانگر در این نسخه تغییر نکرده‌اند. این حالت جدا از Verify build 70448 files است؛ برای کار فعلی فقط دکمه تطبیق بیلد را بزنید.

build-receipt.json هش SHA256 فایل اجرایی و نتیجه آزمون داخل نسخه ساخته‌شده را ثبت می‌کند. هش بسته و exe پس از دریافت هم کنترل می‌شود. فایل امضای دیجیتال تجاری ندارد؛ هشدار ویندوز را نشانه ایمن بودن برنامه تلقی نکنید و محافظت‌ها را خاموش نکنید.

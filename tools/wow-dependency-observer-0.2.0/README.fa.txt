WoW Dependency Observer 0.2.0 — بستهٔ مستقل Windows x64
جایگزین آزمایشی نسخهٔ 0.1.0. نسخهٔ قبلی را برای ضبط دوباره اجرا نکنید.

اجرای ساده:
۱) ZIP را کامل در یک درایو محلی NTFS غیر از C و غیر از درایو ویندوز استخراج کنید، مثلاً H:\WoW-Observer-020.
   روی درایو مقصد حداقل ۲ گیبی‌بایت و روی درایو ویندوز حداقل ۱ گیبی‌بایت فضا لازم است.
   اجرا از داخل ZIP، مسیر شبکه، FAT/exFAT، C و درایو سیستم پذیرفته نمی‌شود.
۲) همهٔ پنجره‌های Procmon را ببندید. بازی را عادی باز کنید و در صفحهٔ ورود نگه دارید. رمز وارد نکنید.
۳) روی Start.cmd راست‌کلیک کنید و Run as administrator بزنید. Wow.exe همان نصب در حال اجرا را انتخاب کنید.
۴) برای برچسب وضعیت فعلی ایزولاسیون عدد 1 را وارد کنید. این انتخاب فقط برچسب است و تنظیمی تغییر نمی‌دهد.
۵) اگر Procmon64.exe رسمی قبلی را دارید LOCAL بزنید و آن را انتخاب کنید.
   در غیر این صورت DOWNLOAD برای دریافت از Microsoft است؛ ممکن است زیر ایزولاسیون شکست بخورد، ابزار محدودیتی باز نمی‌کند.
   نسخهٔ مورد انتظار Procmon 4.12 با SHA مشخص و امضای معتبر Microsoft است. نسخهٔ متفاوت رد می‌شود.
۶) وقتی بازی عادی در صفحهٔ ورود است CAPTURE را تایپ کنید. ضبط حدود ۲۰ ثانیه است؛ بازی را عادی باز نگه دارید.
۷) بعد از پایان، تنها فایل dependency-result-....json در پوشهٔ output را بفرستید.
   فایل capture.pml یا پوشهٔ captures را ارسال نکنید. خواندن PML حداکثر ۱۲۰ ثانیه مهلت دارد.

تغییرهای مهم:
- XML اصلاً ساخته نمی‌شود و Procmon برای تبدیل PML دوباره اجرا نمی‌شود.
- فایل خام و دانلود ابزار کنار همین بسته و در پوشهٔ captures ذخیره می‌شوند، نه LocalAppData.
- ضبط سراسری حداکثر زمان درخواستی ۲۰ ثانیه دارد؛ اندازه و فضای آزاد هر ۰٫۲۵ ثانیه پس از آمادگی بررسی می‌شوند.
- سقف نرم PML برابر ۱۲۸ MiB است. زمان انتظار آمادگی و تأخیر توقف/سیستم می‌توانند باعث عبور از آن شوند؛ سقف سخت نیست.
- زیر ۱ GiB فضای آزاد در مقصد یا ویندوز، یا گذشتن از زمان نظارتی، درخواست توقف فقط برای Procmon خود ابزار صادر می‌شود.
- ابزار فرآیند ناشناخته را به اجبار نمی‌بندد. اگر مالکیت Procmon مشخص نباشد، باید خودتان Capture را متوقف و پنجره‌اش را ببندید.
- Procmon از درایور کرنلی Microsoft استفاده می‌کند. فایل درایور، تنظیمات خودش و فعالیت ویندوز ممکن است همچنان روی C نوشته شوند.
  این ابزار تضمین «هیچ نوشتنی روی C» یا تضمین جلوگیری مطلق از پرشدن دیسک ندارد.

چه چیزی می‌دهد؟
- مقصد IP/پورت و عملیات ارسال/اتصال برای Wow.exe انتخاب‌شده و نامزدهای مرتبط، نام ماژول‌های موجود، سرنخ ماژول در استک شبکه اگر قابل نگاشت باشد.
- ارتباط نامزدها با PID/زمان یا پوشهٔ بازی علامت‌گذاری می‌شود؛ نسبت والد/فرزند یا علت ارسال توسط DLL قطعی نیست.
- جمع طول ارسال موفق صرفاً عدد ثبت‌شدهٔ Procmon است، نه حجم یکتای محتوای آپلود.
- دریافت‌ها به اشتباه به‌عنوان مقصد ارسال گزارش نمی‌شوند؛ فقط شمارش جدا دارند.
- نام دامنه از روی IP حدس زده نمی‌شود و DNS آنلاین یا دریافت سمبل انجام نمی‌شود.
- فقط نمونهٔ کوتاه پس از بازشدن بازی است؛ شروع اجرای بازی و همهٔ فعالیت‌های احتمالی را پوشش نمی‌دهد.
- TLS رمزگشایی نمی‌شود. نتیجه مشخص نمی‌کند CPU/BIOS ارسال شده یا نشده است.

قالب و خطا:
خوانندهٔ مستقیم فعلاً فقط PML v9 را می‌شناسد. اگر نسخهٔ متفاوت یا فایل ناقص باشد، analysis_inconclusive می‌دهد.
هیچ تبدیل XML، تعمیر فایل خام، دست‌کاری نسخهٔ فرمت یا تفسیر «خالی = امن» انجام نمی‌شود.
اگر خطا رخ داد، فایل JSON را بفرستید؛ ضبط را خودسرانه چند بار تکرار نکنید.
فایل خام حداقل تا بررسی نتیجه نگه داشته شود؛ بعد از بسته‌شدن همهٔ Procmonها، فقط پوشهٔ captures همین بسته را می‌توانید حذف کنید.

حریم خصوصی و محدودیت:
ضبط خام سراسری است و ممکن است مسیر، فرمان اجرا، رجیستری و اطلاعات فرآیندهای دیگر داشته باشد.
خروجی کوچک مسیر کامل، فرمان اجرا، مقادیر BIOS/CPU، محیط، آدرس‌های استک و محتوای خام را صادر نمی‌کند.
نام فایل‌ها، PID و IPهای مقصد در JSON باقی می‌مانند؛ پیش از اشتراک عمومی بازبینی کنید.
گواهی، hosts، فایروال، وایت‌لیست، VPN، ExecutionPolicy و تنظیم بازی تغییر داده نمی‌شوند؛ دیباگر/تزریق وجود ندارد.
اجرای Procmon می‌تواند بر عملکرد/سازگاری اثر بگذارد. این بسته روی ویندوز واقعی توسط سازنده آزمایش سرتاسری نشده است.
آزمون‌ها مصنوعی/کد هستند، نه تضمین سازگاری با این بازی یا ساختار ضبط دستگاه شما.
Python همراه بسته است؛ نصب Python یا تغییر ExecutionPolicy لازم نیست.

بررسی امضای Microsoft حتی در حالت LOCAL ممکن است با خدمات اعتماد ویندوز ارتباط برقرار کند.
تنظیم دسته‌های ضبط Procmon و کامل‌بودن ثبت شبکه تأییدشده نیست؛ خروجی بدون رویداد نتیجهٔ امنیتی نمی‌دهد.

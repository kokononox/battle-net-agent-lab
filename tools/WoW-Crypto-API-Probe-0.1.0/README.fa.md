# بررسی ورود به APIهای رمزگذاری WoW — نسخهٔ 0.1.0

این بسته مرحلهٔ بعد از آزمون ناموفق SSLKEYLOGFILE است. به‌جای اتصال Frida، بازی را از ابتدا زیر **دیباگر رسمی Microsoft CDB** اجرا می‌کند و فقط رسیدن اجرا به چند API را گزارش می‌دهد. این کار هنوز خواندن محتوای آپلود یا شناسایی مقصد ارسال مشخصات CPU/BIOS نیست.

## پیش‌نیاز مهم

Windows x64، کامپایلر داخلی .NET Framework 4 و **CDB نسخهٔ x64 از Microsoft Debugging Tools for Windows** لازم است. اگر نصب نیست، بسته خودکار چیزی دانلود/نصب نمی‌کند و بازی اجرا نمی‌شود.

برای تهیهٔ رسمی CDB از راهنمای Microsoft و نصب‌کنندهٔ Windows SDK استفاده کن؛ در فهرست اجزای نصب فقط **Debugging Tools for Windows** را انتخاب کن. نصب کامل SDK لازم نیست:

https://learn.microsoft.com/en-us/windows-hardware/drivers/debugger/debugger-download-tools

مسیر متداول بعد از نصب:

`C:\Program Files (x86)\Windows Kits\10\Debuggers\x64\cdb.exe`

فقط کپی‌کردن cdb.exe به‌تنهایی کافی نیست؛ آن را از محل نصب خودش، کنار DLLهای رسمی مربوطه انتخاب کن. برنامه نسخهٔ امضای Microsoft را مستقلاً اعتبارسنجی نمی‌کند؛ خودت فقط ابزار رسمی نصب‌شده را بده. حفاظت امنیتی ویندوز را خاموش نکن.

## اجرا

1. ZIP را در پوشهٔ قابل‌نوشتن استخراج کن. بازی را کامل ببند. روی **Start.cmd** دوبار کلیک کن. نیازی به PowerShell یا تغییر ExecutionPolicy نیست. راه‌انداز دو فایل EXE متعلق به ابزار را از منابع همین بسته کنار فایل‌ها می‌سازد، نه داخل پوشهٔ بازی.
2. اگر CDB خودکار پیدا نشد، **Choose cdb.exe (x64)** را بزن و آن را از محل نصب رسمی بده. سپس **Choose Wow.exe** و فایل همان بازی قبلاً بررسی‌شده را انتخاب کن.
3. **Start lab probe** را بزن و هشدار دیباگ آزمایشگاهی را بخوان. اول یک برنامهٔ کنترل کوچک زیر دیباگر اجرا می‌شود. فقط اگر نشانهٔ رسیدن به breakpoint کنترل دیده شود، بازی خودکار از ابتدا زیر دیباگر اجرا می‌شود.
4. به صفحهٔ ورود برس و سپس بازی را عادی ببند؛ ورود به حساب برای این مرحله لازم نیست. فقط فایل **crypto-api-result-….json** کنار Start.cmd را بفرست.

### اگر بازی/دیباگر متوقف شد

- اگر پنجرهٔ CDB در prompt یک خطای ناشناخته ایستاد، `qd` را بنویس و Enter بزن. برای ردکردن خطا یا دورزدن محافظت بازی، پی‌درپی `g` نزن.
- اگر بازی در حال اجراست ولی گیر کرده، پنجرهٔ CDB را فعال کن، **Ctrl+C** بزن، سپس در prompt بنویس `qd` و Enter.
- `qd` از بازی جدا می‌شود و دیباگر را می‌بندد؛ ممکن است بازی باز بماند، آن را عادی ببند.
- **پنجرهٔ CDB را با ضربدر نبند و دستور `q` نزن**؛ این کار می‌تواند بازی زیر دیباگر را خاتمه دهد. بستن پنجرهٔ خود ابزار هم CDB را جدا نمی‌کند.
- اگر اجرای ابزار یا کامپایل توسط سیاست سیستم ممنوع شد، فقط متن خطای کامپایل یا وضعیت ثابت ابزار را بده؛ حفاظت یا سیاست سازمانی را غیرفعال نکن.

## آزمون کنترل چیست؟

ProbeControl.exe از Control.cs ساخته می‌شود و فقط تابع Windows GetCurrentProcessId را فراخوانی می‌کند. قبل از بازی، breakpoint این API تحت CDB و با همان سازوکار فایل فرمان آزمایش می‌شود. شکست کنترل باعث **اجرانشدن بازی** می‌شود.

موفقیت کنترل صرفاً کارکرد پایهٔ دیباگر/فرمان و دریافت نشانه را نشان می‌دهد؛ ثابت نمی‌کند breakpointهای SSPI/OpenSSL همگی resolve شده‌اند یا بازی دیباگ‌پذیر است. این کنترل برای جلوگیری از تعبیر نادرست یک اجرای خراب به «بازی رمزگذاری ندارد» است.

## چه چیز ثبت می‌شود؟

- درخواست breakpoint برای `sspicli!EncryptMessage` و `secur32!EncryptMessage`.
- جست‌وجوی نمادهای قابل‌دسترسی `SSL_write` و `SSL_write_ex` هنگام بارگذاری ماژول‌ها.
- breakpointها یک‌بارمصرف‌اند و بعد از مشاهدهٔ اولین نشانهٔ هر دسته دوباره درخواست نمی‌شوند؛ با این حال سربار دیباگ و اسکن ماژول صفر نیست.
- گزارش فقط وضعیت‌ها و نشانه‌های ثابت را از خطوط مستقل لاگ استخراج می‌کند. فرمان‌ها هیچ بافر درخواست، کلید TLS، رمز عبور، حافظهٔ CPU/BIOS، stack یا محتوای بسته‌ای را نمی‌خوانند یا dump نمی‌کنند.

### محدودیت تفسیر

- `api_entry_observed`: حداقل یک نشانهٔ رسیدن به API هدف در اجرای بازی دیده شده است. این هنوز اثبات موفقیت ارسال، مقصد شبکه یا نوع محتوای آن نیست.
- رسیدن به EncryptMessage فقط مسیر SSPI را نشان می‌دهد؛ SSPI کاربردهای غیر TLS هم دارد و این نشانه به‌تنهایی Schannel را ثابت نمی‌کند.
- `no_target_api_entry_observed`: در بخش بررسی‌شده نشانه‌ای دیده نشده؛ **نبود رمزگذاری یا تله‌متری نیست**. OpenSSL با لینک استاتیک، نمادهای خصوصی/مخفی، توابع دیگر و پردازش‌های فرزند ممکن است پوشش داده نشوند.
- `debugger_control_failed_game_not_launched`: کنترل اولیه تأیید نشده و بازی از این مسیر اجرا نشده است.
- `debugger_probe_not_confirmed`: اجرای فرمان‌های مرحلهٔ بازی تأیید نشده است. لاگ خام را نفرست.
- نشانه‌های ready/scan به معنی resolveشدن همهٔ breakpointها نیستند. نشانه‌های متنی نیز گواهی رمزنگاری‌شده یا ضدجعل نیستند.
- اجرای بازی زیر دیباگر ممکن است رفتار را تغییر دهد، راه‌اندازی/ورود را خراب کند یا با سامانه‌های محافظتی ناسازگار باشد. **تضمین نبود ریسک حساب/محدودیت داده نمی‌شود**. فقط محیط آزمایشی و بدون حساب ارزشمند استفاده کن؛ ابزار محافظت بازی را دور نمی‌زند.

## حریم خصوصی، تغییرات و توقف

- CDB واقعاً به پردازش کنترل و سپس بازی متصل می‌شود و breakpoint در حافظه قرار می‌دهد؛ **این روش کاملاً منفعل یا بدون تغییر اجرای پردازش نیست**. DLL تزریقیِ ابزار، پروکسی، گواهی، تغییر فایروال، hosts یا ExecutionPolicy ندارد. دیباگر به‌صورت طبیعی پردازش را در رویدادها موقتاً متوقف و ادامه می‌دهد.
- اجرای معمول بازی می‌تواند شبکه و فایل‌های خودش را به کار بگیرد؛ این بسته ترافیک را مسدود نمی‌کند.
- دیباگر ممکن است پیام‌های debug معمول برنامه، نام ماژول‌ها، آدرس‌ها و مسیرها را در لاگ محلی بنویسد. حتی بدون خواندن بافرها، **این لاگ می‌تواند حساس باشد**.
- پوشهٔ هر جلسه با ACL اختصاصی کاربر جاری و SYSTEM ساخته می‌شود:

`%LOCALAPPDATA%\WowCryptoProbe\<شناسهٔ جلسه>`

- **هیچ فایل `*-debugger-local.log` یا پوشهٔ جلسه را نفرست.** فقط JSON خروجی برای اشتراک است. این گزارش مقدار بافر یا متن خام دیباگر و مسیرهای خصوصی را شامل نمی‌شود؛ هش فایل بازی، کد خروج دیباگر، نشانه‌ها و محدودیت‌ها در آن هستند.
- حداکثر **۴ MiB ابتدای لاگ** برای استخراج نشانه‌ها خوانده می‌شود؛ اگر این حد پر شود، خروجی‌های دیرتر ممکن است از دست بروند. **سقف سخت اندازهٔ لاگ یا مدت دیباگ وجود ندارد**. در آزمون اولیه فقط به صفحهٔ ورود برس و سپس خارج شو، نه دانلود طولانی یا بازی طولانی.
- مسیر نمادها یک پوشهٔ خالی محلی است؛ مسیر symbol server از محیط به ارث برده نمی‌شود. این تنظیم، اثبات مسدودبودن همهٔ شبکهٔ دیباگر/بازی نیست.
- SSLKEYLOGFILE از محیط همین اجرای دیباگر حذف می‌شود؛ محیط عمومی کاربر/سیستم عوض نمی‌شود. فایل‌های خام خودکار آپلود یا پاک نمی‌شوند. بعد از خروج/جداسازی امن CDB و بسته‌شدن بازی، پوشهٔ همان جلسه را دستی پاک کن.
- اگر مسیر پوشهٔ خصوصی فاصله/نویسهٔ غیر ASCII داشته باشد و نام کوتاه معتبر در دسترس نباشد، ابزار **بدون اجرای هدف** متوقف می‌شود؛ تنظیمات 8.3 یا امنیت سیستم را برای آن عوض نکن.

## هویت و وضعیت آزمون

فقط Wow.exe قبلاً بررسی‌شده با SHA-256 زیر پذیرفته می‌شود:

`1c51e68c00e7183c2c187606d2c443c27252a629406454de4afec336e8c5753a`

کنترل فایل قبل از اجراست، نه گواهی حافظه یا همهٔ پردازش‌های فرزند.

**۲۰ آزمون هسته موفق‌اند.** رابط و برنامهٔ کنترل با C# 5 و مراجع .NET Framework 4.8 برای x64 کامپایل آزمایشی شده‌اند. **CDB، اجرای فرمان‌های آن، رابط ویندوز، ACL و بازی در محیط توسعهٔ Linux اجرا نشده‌اند**؛ کنترل اولیهٔ بسته برای بررسی بخشی از این فاصله روی سیستم آزمایشی توست. موفقیت واقعی اجرای ویندوز هنوز ادعا نمی‌شود.

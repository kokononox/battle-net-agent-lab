# تشخیص توقف بازی زیر CDB — ۰.۱.۰

کنترل ۰.۱.۳ روی سیستم آزمایشی موفق شده است. این بسته آن کنترل را تکرار نمی‌کند؛ فقط بازیِ قبلاً تحلیل‌شده را بدون breakpointهای API نسخهٔ Crypto Probe زیر CDB اجرا می‌کند تا توقف بعدی را جدا کنیم.

**این ابزار محتوای آپلود، CPU/BIOS یا کلید TLS را نمی‌خواند.** هیچ اصلاح RIP بازی، تحویل اجباری استثنا با gN/gh، دورزدن loader یا تضمین سازگاری بازی/حساب ندارد. دیباگر حتی بدون hook، زمان‌بندی و رفتار اجرایی را تغییر می‌دهد؛ این آزمایش منفعل شبکه نیست.

## اجرای کوتاه

1. بازی و ابزارهای دیباگ قبلی را عادی ببند. ZIP را در پوشهٔ جدید قابل‌نوشتن استخراج و `Start.cmd` را اجرا کن. نصب تازه و دسترسی Administrator لازم نیست؛ اگر سیاست سیستم مانع شد، آن را غیرفعال نکن.
2. همان CDB رسمی x64 را انتخاب کن (اگر خودکار پیدا نشد)؛ سپس `Wow.exe` مربوط به همان پوشهٔ قبلی را انتخاب کن. SHA256 بازی و `wow_loader.dll` باید با نسخهٔ قبلی برابر باشند؛ نسخهٔ متفاوت اجرا نمی‌شود.
3. **Start lab game** را بزن و پیام آزمایش را تأیید کن. ورود به حساب لازم نیست؛ از حساب ارزشمند استفاده نکن.
4. اگر CDB خودش روی prompt متوقف شد: **Copy stop command** را بزن، در CDB پیست کن و Enter بزن. سپس **Save JSON** را بزن.
5. فقط فایل **stop-survey-result-….json** را بفرست. سپس در promptِ CDB، `qd` و Enter بزن تا جدا شود. دستور `q` یا ضربدر CDB ممکن است بازی را ببندد؛ از آن‌ها و ادامهٔ اجباری خطای ناشناخته با `g`، `gh` یا `gN` استفاده نکن.

اگر بازی به صفحهٔ ورود عادی رسید، گزینهٔ **Game reached normal login screen** را علامت بزن، بازی را عادی ببند و JSON را ذخیره کن. این موفقیت هم به‌تنهایی چیزی دربارهٔ محتوای ترافیک ثابت نمی‌کند.

اگر بازی/دیباگر در حال اجرا گیر کرد و prompt نداری، Ctrl+C در پنجرهٔ CDB می‌تواند prompt بدهد. **این کار ممکن است رویداد فعلی را با وقفهٔ خودت عوض کند**؛ اگر قبل از ثبت انجامش دادی، گزینهٔ **I used Ctrl+C BEFORE recording this stop** را علامت بزن. این نتیجه را توقف اصلی بازی تلقی نمی‌کنیم. برای جداسازی از prompt، `qd` بزن. جداسازی تضمین نمی‌کند بازی بازیابی شود.

اگر گزینه‌ها را بعد از ذخیره تغییر دادی، دوباره **Save JSON** بزن و فقط جدیدترین فایل را بفرست. بسته خودش بازی را نمی‌کشد، خودکار جدا نمی‌شود و بستن رابط آن هم دیباگر را جدا نمی‌کند.

## فرمان ثبت برای کپی دستی

این فرمان فقط آخرین رویداد، RIP و ماژولِ حاوی آن را در لاگ محلی چاپ می‌کند؛ ادامهٔ اجرا یا نوشتن رجیستر ندارد:

```text
.echo WGS_BEGIN_01; .lastevent; r rip; lm a @rip; .echo WGS_END_01
```

اسکریپت راه‌اندازی فقط پیام بارگذاری DLLها را از توقف به اعلان تبدیل می‌کند (`sxn ld`)، یک نشانگر ثابت می‌نویسد و با `g` از توقف اولیهٔ دیباگر ادامه می‌دهد. برای توقف‌های بعدی بازی هیچ فرمان ادامهٔ خودکاری ندارد. breakpointِ API/SSL/loader اضافه نمی‌شود. اگر بدون ثبت دستی از prompt جدا شوی، ممکن است JSON محل توقف را نداشته باشد؛ آن را حدس نمی‌زنیم.

## حریم خصوصی و محدودیت

- JSON فقط کد استثنا، first/second chance، دستهٔ ماژول و RIP نسبی به ابتدای همان ماژول را از آخرین بلوک کامل ثبت‌شده بیرون می‌آورد. نشانی مطلق، مسیر کاربر، stack، محتوا یا raw log صادر نمی‌شود. نام ماژول‌های خارج از فهرست محدود با `other_module` جایگزین می‌شود.
- `wow_loader + 0x1e4f20c` فقط با توقف قدیمی مقایسه می‌شود؛ تطبیق، اثبات ضدتقلب، اجرای handler یا TLS نیست. hash دیسک هم تأیید هویت حافظهٔ بارگذاری‌شده نیست.
- لاگ محلی ممکن است پیام‌های debug یا مسیرهای خصوصی داشته باشد. **debugger-local.log و پوشهٔ جلسه را نفرست.** هیچ آپلود خودکاری انجام نمی‌شود.
- فقط حداکثر ۲ MiB انتهای لاگ خوانده می‌شود. بلوک ثبت ناقص نادیده گرفته می‌شود؛ اگر بلوک کامل قدیمی‌تر موجود باشد، وجود بلوک جدید ناقص جداگانه اعلام می‌شود. فایل لاگ روی دیسک سقف اجباری ندارد؛ پس از ثبت نتیجه، آزمایش را بی‌دلیل باز نگذار.
- پوشهٔ جلسه با ACL کاربر جاری و SYSTEM زیر `%LOCALAPPDATA%\WowCdbStopSurvey\<شناسه>` ساخته می‌شود. پس از خروج/جداسازی واقعی می‌توان همان پوشه را دستی پاک کرد.
- child processها، مقصدها، کلیدها یا محتوای TLS پوشش داده نمی‌شوند. گواهی، فایروال، hosts، تنظیمات بازی و ExecutionPolicy تغییر نمی‌کنند. سه متغیر محیطی symbol/keylog فقط از محیط فرزند CDB حذف می‌شوند؛ محیط سیستم تغییر نمی‌کند.
- امضای CDB مستقلاً در این ابزار تأیید نمی‌شود؛ همان نسخهٔ رسمی نصب‌شده را بده. منابع و هش‌های بسته برای بررسی همراه آن‌اند. هیچ بازی، DLL بازی یا نصب‌کننده‌ای همراه بسته نیست.

## آزمون توسعه

۲۲ آزمون parser، محاسبهٔ RVA، حذف نام‌های ناشناخته و quote فرمان موفق شده‌اند. رابط با C#5 و مراجع .NET Framework 4.8 برای x64 کامپایل شده است. **اجرای واقعی Windows/CDB/بازی و کلیک‌های رابط در محیط توسعه آزمایش نشده‌اند.** موفقیت کنترل ۰.۱.۳ متعلق به گزارش قبلی سیستم توست، نه آزمایش این بسته.

# آزمایش P13: شرط بومی NET_LUID در WFP

فقط آزمایش CI ویندوز؛ نصب روی دستگاه کاربر ممنوع. این مرحله یک kill switch کامل نیست.

سه فیلتر پایدار BLOCK به مسیر یک exe آزمایشی با نام تصادفی محدودند: IPv4 روی رابط غیرمجاز، IPv4 به مقصد غیرمجاز، و تمام IPv6 همان exe. هیچ PERMIT عمومی یا دست‌کاری پیش‌فرض پروفایل‌ها وجود ندارد. کنترل دوم از فایل اجرایی یکسان با مسیر دیگری استفاده می‌کند.

هویت رابط از تبدیل index ↔ NET_LUID و GUID بومی IP Helper گرفته می‌شود؛ نام نمایشی وارد شرط نمی‌شود. مقدار شرط IP_LOCAL_INTERFACE از نوع UINT64 است؛ این مقدار LUID ورود RAS نیست. ALE_APP_ID از API رسمی استخراج می‌شود. برنامه بومی با SDK ویندوز کامپایل می‌شود، نه تعریف دست‌ساز ABI.

provider و sublayer و سه فیلتر در تراکنش BFE نوشته یا حذف می‌شوند. بازخوانی سخت‌گیرانه اشیای خودی شرط حذف است. ژورنال P2 نوشتن پیشاپیش و بازیابی در پردازش تازه را ثبت می‌کند. توقف عمدی هنگام تراکنش و بعد از commit آزموده می‌شود. فیلترها پس از خروج نصب‌کننده باقی می‌مانند؛ هیچ سرویس یا نگهبان اختصاصی نصب نمی‌شود.

محدودیت‌ها: runner اتصال SSTP واقعی ندارد؛ رابط خروجی واقعی و LUID loopback جایگزین مثبت/منفی آزمون هستند، نه اثبات اتصال SSTP. تغییرنام رابط، قطع/وصل VPN، ریبوت، IPv6 بسته‌ای، نشست‌های ازقبل‌باز، UDP، DNS، LAN، محدودسازی کل دستگاه و bootstrap SSTP در این مرحله اثبات نمی‌شوند. enum کامل فیلترهای WFP بیگانه انجام نمی‌شود؛ مقایسه عدم تغییر به قواعد/پروفایل‌های Windows Firewall در P8 محدود است. ژورنال سند رمزنگاری‌شده/امضاشده نیست و از ACL ادمین/SYSTEM استفاده می‌کند؛ مدیر محلی متخاصم خارج از مدل است.

فقط رسید شمارشی محدود و هش سورس بارگذاری می‌شود. مسیر، IP، GUID، LUID، ژورنال و inventory خصوصی بارگذاری نمی‌شوند. cleanup فقط کلیدهای دقیق خودی را پس از audit حذف می‌کند؛ تعارض به reset عمومی منتهی نمی‌شود.

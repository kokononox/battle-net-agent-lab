# مشاهدهٔ محدود متادیتای Install ذخیره‌شده

نسخهٔ مورد انتظار: `saved-install-review-1`

این بسته فقط پژوهشی و خواندنی است؛ نصب‌کننده، اپدیتر یا ابزار تشخیص خرابی بازی نیست.

## اجرا

۱. بازی و Battle.net را ببندید. Lab قبلی را حذف، جابه‌جا یا اصلاح نکنید.
۲. ZIP را در یک پوشهٔ **تازه، خارج از بازی، Lab و بسته‌های قبلی** استخراج کنید.
۳. `CHECK-SAVED-INSTALL.cmd` را اجرا کنید. Python 3.10+ با tkinter لازم است؛ Administrator لازم نیست.
۴. همان Lab موجود دارای `LAB-ONLY.json` و سپس ریشهٔ همان بازی دارای `.build.info` را انتخاب کنید؛ نه Data یا _retail_.
۵. فقط فایل `INSTALL-REVIEW-to-share.json` را از زیرپوشهٔ تازهٔ Results بفرستید.

اگر توقف کرد، فقط متن خطای امن را بفرستید؛ تنظیم دسترسی، اسکن، استخراج یا دانلود نکنید.
Cancel در هر انتخاب‌گر، بدون بررسی ورودی‌ها و بدون ساخت گزارش خارج می‌شود.

## دامنهٔ دقیق

- اتصال ذخیره‌شدهٔ قبلیِ Lab، مرجع‌های دیتابیس بسته، هویت هدف و نام‌ها/stat همان snapshot دوباره کنترل می‌شوند؛ این اسکن محتوای آرشیو نیست.
- از بازی فقط همان دو فایل قبلاً مجاز: `.build.info` و build-config دقیق نام‌برده‌شده.
- از raw-cache فقط **یک فایل**:

```text
objects/d7c8cd9845e2b5d39821678f481324da-24078.decoded
```

- اندازه باید دقیقاً ۲۴٬۰۷۸ بایت باشد. یک فراخوانی خواندن، حداکثر همان مقدار؛ سپس MD5/CKey، SHA256 و ثبات stat بررسی می‌شوند.
- مرجع CKey، EKey و اندازه از config هدف با MD5 و SHA256 دوباره اعتبارسنجی می‌شود؛ جایگزین یا تنظیم دستی pin وجود ندارد.
- اگر فایل دقیق موجود نبود: گزارش `bound_install_metadata_unavailable`؛ **نه جست‌وجو، نه کش جایگزین، نه استخراج آرشیو و نه دانلود**.
- سقف ۲۴٬۰۷۸ بایت مربوط به فایل raw-cache Install است، نه کل متادیتای اتصال قبلی Lab/config؛ آن کنترل‌های قبلی همچنان برقرارند.
- صفر خواندن raw Download/Encoding، صفر خواندن payload آرشیو، صفر شبکه و صفر تغییر بازی/Lab. رابط خط فرمان و رابط انتخاب پوشه، یک کنترل منع عملیات socket نیز نصب می‌کنند؛ این کنترل sandbox امنیتی سیستم‌عامل نیست.
- خروجی فقط در پوشه‌ای تازه و جدا، بدون بازنویسی گزارش قبلی است.

## معنای نتیجه

`bound_install_identity_observed_policy_unresolved` یعنی محتوای فایل دقیق با CKey مرجع تطبیق دارد.
فقط ده بایت اولِ محتوای عمومی تأییدشده به شکل hex، و دو مقدار بایت بدون تفسیر صادر می‌شود.
هیچ اسم فایل، فهرست entry، tag، مسیر خصوصی یا سیاست نصب حدسی صادر نمی‌شود.
parser معنایی Install هنوز ادعا نمی‌شود؛ header صرفاً مشاهده است، نه اثبات قالب/پلتفرم یا سیاست فروشنده.

این گام هنوز مجموعهٔ لازم برای نصب، سلامت فایل‌های بازی، نسل فعال CASC، امضای ناشر، حجم لازم دانلود یا آمادگی نصب را اثبات نمی‌کند.
`installation_ready=false`، `apply_authorized=false` و `required_network_download_bytes=null` باقی می‌مانند.
نبودن فایل دقیق در این محل یعنی نامشخص، نه مفقود/خراب بودن بازی یا نبودن آن در همهٔ محل‌ها.

## خط فرمان

```text
python -B saved_install_review.py --lab "EXISTING_LAB" --audit-dir "pinned_metadata" --game-root "SAME_GAME_ROOT" --out-new "NEW_SEPARATE_OUTPUT"
```

## حدود آزمون

آزمون‌های کش موفق با بایت‌های **مصنوعی** و جایگزینی صریح مرجع، فقط در کد آزمون اجرا می‌شوند؛ برنامهٔ قابل اجرا هیچ پارامتر تغییر pin ندارد.
ورودی مصنوعی با pin واقعی تولید رد می‌شود.
مسیر نبودن cache با pin/config واقعی هدف و Lab/game مصنوعی آزمایش می‌شود.
فایل Install واقعی کاربر و اجرای Windows بومی در این محیط آزمایش نشده‌اند؛ شاخهٔ عدم بازنویسی Windows فقط مدل شده است.
کنترل ثبات، بر stat و مجموعه‌نام‌ها متکی است، نه snapshot سیستم‌عامل یا حفاظت در برابر نویسندهٔ خصمانه.

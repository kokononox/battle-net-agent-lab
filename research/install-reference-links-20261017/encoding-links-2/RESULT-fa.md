# اصلاح توقف install_changed

گزارش واقعی کاربر در Windows / Python 3.13.16 نشان داد هش فایل Install درست، مشاهدات هر کانال ثابت، و تنها تفاوت بین APIهای stat و fstat مربوط به st_ctime_ns بوده است. این خروجی نشانهٔ خرابی یا تغییر فایل بازی نیست.

نسخهٔ install-encoding-links-2 کنترل‌های زمانی هر کانال را کامل حفظ می‌کند و فقط ctime را از پل مقایسهٔ دو API روی ویندوز کنار می‌گذارد. سایر فیلدهای هویت و اندازه/mtime/link و هش‌های دقیق همچنان الزامی‌اند. هیچ افزایش مجوز، بودجهٔ خواندن، دانلود یا تغییر بازی/Lab اضافه نشده است.

۶۹ آزمون Linux موفق: شامل ۵۹ آزمون قبلی و ۱۰ آزمون جدید کنترل هویت. تفاوت Windows به‌صورت مصنوعی شبیه‌سازی شده است؛ اجرای بومی نسخهٔ اصلاح‌شده روی Windows و بررسی Encoding واقعی هنوز انجام نشده است. فایل Encoding واقعی در محیط دستیار این مرحله خوانده نشده است.

گام بعد: نسخهٔ جدید را خارج از بازی و Lab در پوشهٔ تازه استخراج و CHECK-INSTALL-ENCODING.cmd را اجرا کنید. پس از تأیید همان محدودهٔ فقط‌خواندنی، Lab موجود را انتخاب و JSON جدید را ارسال کنید. تمام پرچم‌های آمادگی/مجوز نصب همچنان false هستند.

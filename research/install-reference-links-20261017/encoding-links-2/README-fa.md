# بررسی فقط‌خواندنی پیوند Install و Encoding

این بسته نصب‌کننده، آپدیتر یا تعمیرکنندهٔ بازی نیست. هدف فقط بررسی ارجاع‌های متادیتای یک بیلد ثابت است؛ نه اثبات کامل بودن نصب فعلی یا تعیین فایل‌های لازم برای نصب.

## اصلاح نسخهٔ install-encoding-links-2

در خروجی تشخیص روی Windows / Python 3.13.16، هش Install درست بود، هر کانال مشاهده ثابت ماند و فقط st_ctime_ns بین stat و fstat تفاوت داشت. در این نسخه، fingerprint کامل مسیر با همان مسیر و fingerprint کامل handle با همان handle مقایسه می‌شوند؛ ctime از هیچ مقایسهٔ زمانی حذف نشده است. فقط در مقایسهٔ بین دو API روی ویندوز، ctime کنار گذاشته می‌شود؛ شناسهٔ device/inode، اندازه، mtime و تعداد لینک‌ها باید همچنان دقیقاً برابر باشند. بررسی هش کامل Install و Encoding و تمام محدودیت‌های خواندن قبلی برقرار است.

این اصلاح بر مبنای تشخیص واقعی ارسال‌شده است، ولی اجرای بومی نسخهٔ اصلاح‌شده روی ویندوز هنوز تأیید نشده است. ۶۹ آزمون محلی شامل شبیه‌سازی تفاوت ثابت ctime و رد تغییرات واقعی در هر کانال موفق بوده‌اند.

بسته را **در پوشهٔ تازه و جدا از نسخهٔ قبلی** استخراج کن. پس از اجرا باید Diagnostic build: install-encoding-links-2 دیده شود. نسخهٔ تشخیصی قبلی را لازم نیست تکرار کنی.

## اجرا در ویندوز
۱. کل ZIP را در پوشه‌ای تازه، **بیرون از پوشهٔ بازی و Lab** استخراج کن. از داخل ZIP اجرا نکن. Python 3.10 یا جدیدتر لازم است؛ نصب هیچ کتابخانه‌ای با pip لازم نیست.
۲. فایل `CHECK-INSTALL-ENCODING.cmd` را اجرا کن. پس از خواندن و تأیید محدودهٔ دسترسی، **همان Lab موجود** را انتخاب کن؛ نه پوشهٔ بازی. نیازی به اجرای Administrator یا تغییر دسترسی‌ها نیست.
۳. پس از پایان، فقط فایل `INSTALL-ENCODING-LINKS-to-share.json` را از زیرپوشهٔ جدید `Results` همین بسته بفرست. کل Lab یا فایل‌های بازی را نفرست. اگر اجرای ابزار متوقف شد، متن تشخیص کنسول را بفرست.

## اجازهٔ دسترسی جدید و محدود
این مرحله برخلاف بررسی قبلی، محتوای فقط **یک فایل Encoding ذخیره‌شدهٔ مشخص** را می‌خواند. پنجرهٔ آغاز اجرا برای همین دسترسی تأیید می‌گیرد:
- فقط مسیر دقیق `objects/8d0576391f8e80ce55940381fc3f674a-200255318.decoded` در Lab انتخاب‌شده.
- یک گذر برای هش و هویت، حداکثر 200,255,318 بایت؛ سپس خواندن شاخص و صفحه‌های منتخب همان متادیتا، حداکثر 32 MiB اضافه. سقف مجموع خواندن Encoding برابر 233,809,750 بایت است.
- فایل کوچک `target-install.metadata` داخل بسته، متادیتای Install از دریافت محدود قبلاً مجازشده است؛ اندازه و MD5 و SHA256 آن پیش از استفاده بررسی می‌شود. فایل اجرایی بازی نیست.
- هیچ خواندن آرشیو/payload، فایل بازی، Download، شبکه، جست‌وجوی کش، اسکن مجدد، دانلود، SQLite یا تغییر بازی/Lab انجام نمی‌شود. فقط گزارش جدید در `Results` بسته نوشته می‌شود.

اگر فایل دقیق ذخیره‌شده موجود نبود، گزارش «نامعلوم» تولید می‌شود. **فایلی دانلود، جابه‌جا یا تغییرنام نده؛ اسکن را تکرار نکن.** نامعلوم به معنی خراب یا مفقود بودن فایل بازی نیست. توقف پس از پنج دقیقه یا عدم تطابق نیز مجوز ادامهٔ خودکار نیست.

## معنی نتیجه و محدودیت‌ها
تمام رکوردهای Install، شامل نسخه‌های هم‌نام با منطقه‌های مختلف، بررسی می‌شوند؛ ابزار «اولین نام مشابه» را انتخاب نمی‌کند. توافق CKey/EKey/اندازه تنها توافق متادیتا است، نه صحت payload، سیاست رسمی نصب یا آماده‌بودن بازی. snapshot قبلی Lab و مشخصات نصب فعلی در این مرحله دوباره اعتبارسنجی نمی‌شوند. تمام پرچم‌های مجوز نصب/اعمال همچنان false می‌مانند.

آزمون‌های خودکار در Linux انجام شده‌اند؛ اجرای بومی ویندوز و اجرای مثبت روی Encoding واقعی هنوز اینجا انجام نشده است. آزمون مثبت از دادهٔ مصنوعی با جایگزینی صریح ثابت‌ها فقط در تست استفاده می‌کند؛ ابزار تولیدی ثابت‌های جایگزین‌پذیر در خط فرمان ندارد.

روش خط فرمان اختیاری: `python -B metadata_link_review.py --help`، سپس `python -B metadata_link_review.py --lab "D:\path\to\existing-Lab"`. اجرای خط فرمان با `--lab` همان دسترسی محدود توضیح‌داده‌شده را شروع می‌کند و پنجرهٔ تأیید ندارد.

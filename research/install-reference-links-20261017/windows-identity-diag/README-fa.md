# تشخیص اختلاف مشخصات فایل داخل بسته

این بسته رفع خطا یا ادامهٔ بررسی Encoding نیست. فقط علت توقف install_changed را روشن می‌کند؛ هیچ کنترل نصب/آپدیت را دور نمی‌زند.

۱. دو فایل CHECK-INSTALL-IDENTITY.cmd و install_identity_diag.py را **کنار CHECK-INSTALL-ENCODING.cmd در همان پوشهٔ استخراج‌شدهٔ قبلی** قرار بده. فایل target-install.metadata قبلی را دست‌نخورده نگه دار؛ این بسته آن را جایگزین نمی‌کند.
۲. CHECK-INSTALL-IDENTITY.cmd را اجرا کن. نیازی به انتخاب Lab، اجرای Administrator، تغییر دسترسی یا اجرای دوبارهٔ بررسی قبلی نیست.
۳. کل خروجی متنی کنسول، به‌خصوص JSON را بفرست. نام پوشه‌ها و مقدار شناسه/زمان فایل در گزارش نمی‌آیند؛ فقط نام فیلدهای متفاوت و نتیجهٔ تطابق هش‌ها گزارش می‌شوند.

محدوده: فقط فایل target-install.metadata کنار همین ابزار، حداکثر 24,078 بایت در یک خواندن. صفر خواندن Lab، Encoding، فایل بازی یا آرشیو؛ بدون شبکه، نوشتن گزارش روی دیسک یا ادامهٔ خودکار. مشخصات مسیر و handle پیش/پس از خواندن جداگانه مقایسه می‌شوند. در صورت تفاوت، ابزار تشخیصی فقط همان فایل کوچک را با اندازهٔ دقیق کنترل و هش می‌کند؛ به مرحلهٔ اصلی ادامه نمی‌دهد.

۹ آزمون Linux موفق بوده‌اند؛ Windows بومی هنوز آزمایش نشده و علت قطعی خطای گزارش‌شده تا دریافت خروجی این تشخیص معلوم نیست. اختلاف APIهای stat و fstat یک احتمال است، نه نتیجهٔ اثبات‌شده.

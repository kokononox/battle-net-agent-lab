# G56 — یک ادامهٔ کنترل‌شده فقط از صفحهٔ زبان

ابتدا همان کنترل مثبت بومی x86/x64 لازم است. پس از preflight امضا/pin نصب‌کننده و gate دو مقصد با استثناهای مدیریت CI، ناظر قبل از resume فعال می‌شود. birth time فرایند اصلی با GetProcessTimes نگه داشته می‌شود. UIA فقط‌خواندنی کاندیدای دقیق Window=Battle.net Setup + Continue فعال یکتا + radio انگلیسی فعال و بدون خطا/truncation را پیدا می‌کند؛ این فقط precondition است و مجوز کلیک عمومی نیست.

wrapper بومی قبل از عمل، marker رضایت hosted، pin/اندازه فایل، مسیر دقیق تصویر فرایند و زمان ساخت فرایند و پنجره visible یکتا را دوباره بررسی می‌کند. سپس فقط یک ticket با CreateNew مصرف می‌کند. از scripts/language_advance.cs موجود در همان commit استفاده می‌شود: ساختار RawView، گروه یکتای Select a language، radio دقیق English (US/United States)، Continue یکتا، نبود متن حقوقی/ورود/خطا و نبود کنترل Edit/password/Document الزامی است. انتخاب انگلیسی در صورت نیاز و Invoke فقط روی همان Continue، پس از بازبینی صفحه و Runtime identity کنترل‌ها انجام می‌شود. Install/ورود/شرایط/نصب بازی کلیک نمی‌شود. نتیجه نامعلوم/timeout/refusal هرگز باعث retry عمل نمی‌شود.

gate قبل/بعد عمل و در هر probe بررسی می‌شود. کل مشاهده حداکثر۱۲۰ثانیه از resume است؛ پس از Continue بخشی از همین پنجره باقی می‌ماند، نه تضمین دانلود کامل. تمام محدودیت‌های API-based، async/TLS/نام مقصد/IP مشترک/همان نبودن تنظیم RC باقی است. ناظر هرگز نبود فینگرپرینت را از GET یا داده خالی نتیجه نمی‌گیرد. گزارش فقط metadata و سرنخ‌ها، بدون URL کامل، مقادیر هدر/بدنه/UI است.

خروجی محدود به شکل chunkهای Base64 همراه SHA256 و run/source چاپ می‌شود تا محدودیت تک‌خط طولانی لاگ وب مانع خواندن گزارش نشود. این رمزگذاری امنیتی نیست؛ خروجی همچنان فقط داده حذف‌اطلاعات‌شده است. فایل خصوصی journal و export فایروال منتشر نمی‌شوند. محصول RC و سیستم کاربر تغییر نمی‌کند.

# G71 — انتساب کلید به پاسخ و فیلد، بدون تأیید بی‌دلیل حریم خصوصی
هدف فقط کلید نامنطبق G70 است: جفت‌کردن درخواست/پاسخ HTTP روی همان TLS context، تشخیص header یا body/table field و بررسی برابری با دریافت مستقل عمومیِ پیش از اجرا. هیچ raw path/key/query/body/header-value یا نام آزاد صادر نمی‌شود. منشأ محلی، وابستگی علّی یا بی‌خطر بودن با یک equality نتیجه‌گیری نمی‌شود.

ResponseOrigin درخواست GET موفق EncryptMessage و پاسخ موفق DecryptMessage را با HTTP/1 framing و FIFO همان context جفت می‌کند. Content-Length و chunked بدون extension/trailer پشتیبانی می‌شوند. ambiguity، پاسخ بدون درخواست، non-GET، context نامعلوم، close-delimited، cap یا protocol switch reject است. informational response صف را مصرف نمی‌کند. content-encoding ناشناخته برای body قابل تفسیر نیست؛ فقط header مستقل باقی می‌ماند. سقف ورودی 16MiB و نگهداری پاسخ 8MiB است. این ابزار read-only است؛ return value، request یا response buffer را تغییر نمی‌دهد.

مسیر پاسخ فقط اگر با مجموعهٔ ثابت routeهای metadata/summary از agent,bna,bnt مطابق باشد نام‌گذاری می‌شود؛ بقیه <other_route> هستند. نام field/header هم فقط از vocabulary ثابت صادر می‌شود. شکل schema با !STRING/!HEX/!DEC برای جدول لازم است؛ exact value از substring یا token جدا می‌ماند. تقدم در گزارش، ترتیب observation کامل‌شدن پاسخ نسبت به مشاهدهٔ target است، نه ساعت قطعی threadها.

همان هفت GET عمومی ثابت قبلی قبل از اجرای target دریافت می‌شوند؛ این بار response headers نیز فقط در فایل PRIVATE همان runner برای equality نگه داشته می‌شوند. این‌ها از مسیر/کلید مشاهده‌شده ساخته نمی‌شوند؛ query، cookie، auth، proxy و redirect ندارند و اعتبار TLS/revocation لازم است. نه lookup تازه به catalog، نه دریافت URL دلخواهِ target و نه مقصد مجاز تازه داریم. برابری token با سند مستقل، بدون استنتاج معتبر مسیر کامل CDN، به‌تنهایی آن endpoint را عمومی/مجاز نمی‌کند.

110 تست کشف شد؛ Linux یک تست Windows را skip کرد. دو کنترل بومی TLS x86/x64 اکنون یک پاسخ HTTP واقعیِ TLS با ETag و جدول BuildConfig را به کلید synthetic وصل می‌کنند، از همان SSPI hook و pairer استفاده می‌کنند و equality مستقل fixture را نیز کنترل می‌کنند. ده کنترل دیگر حفظ شده‌اند: مجموع 12. شکست کنترل قبل از target مانع اجرای آن است. trust مربوط به fixture قبل از target حذف می‌شود و production validation تغییر نمی‌کند.

پایهٔ G69 و هشت overlay ثبت‌شدهٔ G70 با SHA256 ثابت، مستقیم از Git blob خوانده می‌شوند؛ تبدیل پایان‌خط working tree در pin دخالت ندارد. فقط پوشهٔ runtime محلی ساخته می‌شود، پایه‌ها و main و Unified Firewall Desktop 0.9.10 تغییر نمی‌کنند. محدودیت شبکه، process guard، UI و پاک‌سازی همان قبل است. فقط یک مشاهدهٔ 120ثانیه‌ای با همان دو مقصد و استثنای مدیریت CI، بدون login یا Install click؛ تکرار خودکار target پس از failure نداریم. پوشش دانلود کامل و نبود fingerprint ادعا نمی‌شود.

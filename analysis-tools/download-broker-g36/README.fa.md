# G36 — نمونهٔ آفلاین کارگزار دانلود

این یک نمونهٔ قرارداد درخواست و ساخت درخواستِ خروجی است، نه EXE، proxy سازگار با نصاب، ابزار فعال ضد فینگرپرینت، یا دانلودکنندهٔ آنلاین. هیچ socket/TLS/فایروالی در broker ایجاد نمی‌شود. Transport فقط دادهٔ fixture را در حافظه برمی‌گرداند.

## رفتار
- تنها ورودی کلاینت JSON با یک فیلد دقیق `resource_id` است؛ URL، header، cookie، method، query، body، range یا فیلد اضافی پیش از فراخوانی transport رد می‌شود.
- شناسه باید در کاتالوگ مورد اعتماد موجود باشد. درخواست GET از host/path ثابتِ کاتالوگ و هدرهای ثابت بازسازی می‌شود؛ بایت خام درخواست کلاینت منتقل نمی‌شود.
- پورت خروجیِ برنامه‌ریزی‌شده 443 و scheme آن https است؛ این فقط plan است، نه اتصال TLS اجراشده.
- کاتالوگ تنها همان دو میزبان دقیق قبلی را می‌پذیرد. query، fragment، percent encoding، مسیر غیر ASCII، traversal، کلید ناشناخته و resource تکراری رد می‌شوند.
- کاتالوگ باید با SHA-256 مورد اعتماد تطبیق کند و هر resource سابقهٔ بررسی داشته باشد. hash باید در استقرار واقعی از مرجع مورد اعتماد بیاید، نه همان کلاینت. یک hash یا عبارت approved به‌تنهایی صحت بررسی حریم خصوصی را اثبات نمی‌کند.
- تنها پاسخ 200 با اندازه و SHA-256 دقیق به فراخواننده تحویل می‌شود. redirect/خطا/اندازه یا hash اشتباه رد می‌شود. این بررسی، اصالت ناشر و امنیت فایل را به‌تنهایی ثابت نمی‌کند.
- `catalog.deny-all.json` خالی است؛ هیچ مسیر واقعی یا فایل Battle.net با این کار مجاز نشده است.

## آزمون

```bash
python -I analysis-tools/download-broker-g36/test_broker.py
```

27 آزمون شامل دانلود fixture، بازسازی دقیق درخواست، رد شناسه در URL/query/body/header و Cookie، JSON تکراری/نامعتبر، تغییر policy، پاسخ redirect/دستکاری‌شده و1000درخواست با فیلد تزریقی اجرا می‌شوند. ایجاد socket در مدت اجرای هر آزمون عمداً ممنوع است. markerها و فایل‌ها ساختگی‌اند؛ نشانی `/audit-fixture/file.bin` مسیر واقعی تأییدشده نیست و به هیچ سروری ارسال نمی‌شود.

## مرز اعتماد و محدودیت‌ها
این کتابخانه مرز امنیتی بین کدهای یک پردازش نیست. کاتالوگ، کد، digest اعتماد و روند بررسی باید در استقرار آینده در اختیار کنترلر مورد اعتماد و دور از دسترس برنامهٔ هدف باشند؛ فراخوانندهٔ مهاجم نباید بتواند Catalog یا transport بسازد یا تغییر دهد.

الگوی ثابت path/header/query فرصت ارسال فیلد دلخواه را کاهش می‌دهد، اما pathِ تأییدشده هم ممکن است اطلاعات داشته باشد؛ بررسی معنایی و منشأ آن ضروری است. فهرست منابع در این نمونه کاملاً ساختگی است. انتخاب resource، ترتیب، تکرار و زمان درخواست‌ها هم می‌توانند کانال جانبی باشند؛ محدودیت جلسه/بودجه/ترتیب هنوز پیاده نشده‌اند. IP عمومی و fingerprint TLS آیندهٔ کارگزار حذف نمی‌شوند. هیچ ادعای حذف همهٔ فینگرپرینت‌ها نداریم.

نسخهٔ آتی برای شبکهٔ واقعی به transport با اعتبارسنجی عادی TLS، محدودسازی IP/redirect، سقف streaming و timeout، منشأ و اصالت فایل، cache امن، کنترل پردازش و آزمون بازیابی نیاز دارد. این نمونه کل فایل fixture را در حافظه می‌گیرد و برای دریافت واقعی فایل بزرگ طراحی نشده است.

سازگاری نصاب Battle.net، منابع لازم، امکان نصب از cache و حالت اجرای دستی تحت Job هنوز آزموده نشده‌اند. هیچ TLS interception، CA جدید، bypass امضا، استثنای فایروال یا تغییر Windows task اضافه نشده است. ابزارهای قدیمی و main تغییر نکرده‌اند.

# G22 — علت توقف آغاز نصب، بدون تغییر سیاست اتصال

یک اجرای واقعی با همان دو مقصد level3.blizzard.com و us.version.battle.net روی Windows GitHub-hosted تازه؛ نسخه Desktop 0.9.10 و source مرحله G21 تغییر نمی‌کنند. خروج مستقیم نصاب بسته و عبور پروکسی همچنان نیازمند نام/SNI دقیق، IP عمومی pinned و مالک native TCP با هویت زنده و عضویت Job است. DNS، مقصد سوم، CA، استثنای گواهی یا مجوز تازه اضافه نشده است.

## فقط مشاهدهٔ هدفمند
- نوع/طول/نسخهٔ header رکورد TLS و نام نوع handshakeهای آشکار، پیشنهاد انتخاب نسخه/cipher از ServerHello و alertهای آشکارِ پیش از رکوردهای protected ثبت می‌شوند. payload، random، session ID، گواهی یا کلید صادر نمی‌شوند. parser در مواجهه با framing ناشناخته فقط invalid_framing را ثبت می‌کند و سیاست عبور را تعیین نمی‌کند. انتخاب ServerHello، اثبات موفقیت handshake نیست؛ application_data در TLS1.3 معنی محتوای داخلی را روشن نمی‌کند.
- کدهای قالب‌دار Blizzard/HRESULT و کدهای شناخته‌شده WinHTTP از حداکثر ۳۲ log کوچک در ریشه‌های مربوط به همین نصب استخراج می‌شوند. متن خام، path، URL، header و شناسهٔ کاربر منتشر نمی‌شوند. شمارش کلمات صرفاً تطبیق لغوی است، نه تشخیص علت.
- Schannel/System و CAPI2/Operational از زمان شروع همین مشاهده فقط خوانده می‌شوند. اگر log خاموش/غیرقابل‌خواندن باشد، همین وضعیت ثبت می‌شود؛ ثبت وقایع فعال یا تغییر داده نمی‌شود. فقط event ID، سطح، error code و alert/internal-stateهای عددی مجاز خارج می‌شوند. scope کل VM در پنجرهٔ زمانی است؛ انتساب رخداد به نصاب اثبات نشده.
- Windows firewall، بازیابی، استثنای بسیار محدود SvcRestartTask، بازهٔ ۱۸۰ثانیه‌ای، validator کلیک و محدودیت حساب/بازی همان G21 هستند. هیچ کلیک ناشناخته، TLS decryption یا bypass اعتبارسنجی وجود ندارد.
- گزارش دارای manifest/hash در stdout و artifact مستقل Linux نگهداری می‌شود. token فقط در Linux collector است و وارد نصاب نمی‌شود.

## هدف نتیجه
علت اولیهٔ توقف پس از زبان را با کد خطا و metadata ارتباط روشن کنیم؛ نه اعلام نصب موفق، نه اثبات کافی/ناکافی‌بودن دو مقصد و نه نام‌گذاری حدسی ۲۴ بایت رمز‌شده به‌عنوان تله‌متری. هنوز کل زنجیره و نبود هر نشت اثبات نشده‌اند. مرز در برابر Administrator مخرب یا تزریق در Runner اثبات نشده است.

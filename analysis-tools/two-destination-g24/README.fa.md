# G24 — آماده‌سازی ابطال گواهی، سپس نصب محدود
با اجازهٔ کاربر، پیش از ایزوله‌سازی یک TLS handshake بومی به us.version.battle.net اجرا می‌شود. Windows بررسی آنلاین ابطال، نام، زنجیره، زمان و ریشهٔ قابل‌اعتماد را انجام می‌دهد. callback فقط زنجیرهٔ بدون خطا با Online را قبول می‌کند؛ هیچ درخواست HTTP کاربردی ارسال نمی‌شود. بازی، حساب و Setup در این مرحله اجرا نمی‌شوند. Windows می‌تواند اطلاعات CA را برای بررسی زنجیره از شبکه دریافت و در کش جاری کاربر ذخیره کند. مقصدهای درج‌شده در گواهی فقط advertised هستند، نه گزارش واقعی fetch. اثبات packet-level یا کش خالی ادعا نمی‌شود. کش SYSTEM و همهٔ حساب‌ها آماده اعلام نمی‌شود. اگر اعتبارسنجی موفق نشود، نصاب اجرا نمی‌شود.
پس از آن همان gate دو مقصد G22، همان مالکیت Job، همان سیاست بازیابی و UI محافظه‌کار فعال است. هیچ مجوز CA به gate اضافه نشده. نتیجه فقط برای runner با آماده‌سازی معتبر است، نه نصب سرد و مستقل با دو مقصد. نصب موفق تا شاهد واقعی اعلام نمی‌شود.

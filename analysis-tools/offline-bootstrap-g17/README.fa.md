# G17 — مشاهدهٔ بوت‌استرپ واقعی با خروج شبکهٔ بسته

نسخهٔ Unified Firewall Desktop 0.9.10 تغییر نمی‌کند. این آزمایش تنها روی یک ماشین موقت GitHub-hosted Windows اجرا می‌شود.

- نصاب رسمی: SHA256 `f4643a2086c0cecb1ab68cc601bf38c1a0a6f7ef5914ad03375cc9449385bec6`، اندازهٔ 4700880 بایت؛ تغییر هویت یا رد WinVerifyTrust مانع اجراست.
- پیش از اجرا، همهٔ پروفایل‌ها DefaultOutbound=Block و قوانین Allow قبلی غیرفعال می‌شوند؛ فقط دو اجرایی مدیریت runner استثنا هستند. هیچ مجوز خروجی برای نصاب، فرزندان یا پراکسی صادر نمی‌شود.
- CreateProcess معلق، انتساب Job قبل از Resume، محیط فرزند بدون توکن‌ها و تنظیمات CI، مشاهدهٔ ۹۰ثانیه‌ای و پایان Job. دریافت پیام‌های Job تضمین ثبت هویت همهٔ فرایندهای کوتاه‌عمر نیست.
- رابط گرافیکی فقط مجاز است در صورت احراز دقیق صفحهٔ زبان، یک Continue را اجرا کند. ادامهٔ صفحهٔ گزینه‌های نصب، ورود حساب و دانلود بازی درخواست نمی‌شود.
- پاکسازی مستقل SYSTEM فقط پس از پایان Job، نبود تغییر ثبت سرویس/تسک و نبود نامزد زندهٔ شناخته‌نشده در محدوده‌های بررسی‌شده اجازهٔ بازیابی فایروال دارد. مورد ناشناخته باعث امتناع از بازیابی و دور انداختن ماشین می‌شود، نه حذف کورکورانهٔ سرویس.
- خروجی صرفاً JSON پالایش‌شده است؛ PID، مسیر کامل، متن آزاد UI، محیط، فایل اجرایی و بکاپ فایروال منتشر نمی‌شود.

موفقیت این آزمون یعنی «نصاب واقعی زیر سیاست خروج بسته مشاهده و پاکسازی شد»، نه نصب موفق، نه کشف کامل زنجیره، نه اثبات بسته‌بودن همهٔ مسیرهای خروج، نه تفکیک محتوای دو مقصد. شاهد شبکه یک canary IPv4/TCP1119 و بررسی سیاست است؛ رهگیری جامع بسته‌ها نیست.

# G29 — کنترل محیطی بدون اجرای Setup
فقط یک VM تازهٔ Windows با همان آماده‌سازی G26، همان دانلود/hash/اعتبارسنجی Setup و همان آماده‌سازی Online گواهی پیش از gate. فایل Setup فقط دانلود/بررسی می‌شود و اجرا نمی‌شود. مسیر CreateProcess و Run نصاب از helper این کنترل حذف شده؛ Driver هم شاخهٔ اجرای Setup/UI/کلاینت ندارد. یک فراخوانی منفی helper run پیش از gate باید installer_execution_disabled_in_control بدهد.

پس از گیت دو مقصد،270ثانیه بدون هدف نصب مشاهده می‌شود. probe بیرون Job باید403 و بدون upstream dial باشد. BITS همان مراقبت قبلی را دارد. Snapshot فقط‌خواندنیِ SYSTEM برای چهار task با hash هویتِ G26، XML خصوصی، hash action/principal/owner-group-DACL و در ابتدا/پایان binding/تصویر شناخته‌شده را می‌خواند. handler COM هیچ taskی activate و taskی اجرا/تغییر داده نمی‌شود؛ Schedule.Service فقط API خواندن scheduler است. query/helperها خودشان بخشی از محیط ابزارند؛ این یک آزمایش matched کامل یا اثبات actor نیست.

فقط diffهای پالایش‌شده، زمان تقریبی مشاهده و برابری قبل/بعد صادر می‌شوند. فاصلهٔ درخواست polling حدود10ثانیه است، نه تضمین پوشش پیوسته. transientهای کوتاه ممکن است دیده نشوند. امضای جدید تصاویر سه task بررسی نشده و binding ناموجود/نامعتبر unknown می‌ماند. هیچ exemption تازه، به‌خصوص برای Enabled، داده نمی‌شود. policy و classifier قدیمی بدون تغییر باقی‌اند.

تغییر task بدون اجرای نصاب نشان می‌دهد چنین تغییری در محیط ابزار هم ممکن است؛ ثابت نمی‌کند تغییرِ G26 همان actor را داشته یا امن بوده است. نبود تغییر در یک VM هم ثابت نمی‌کند نصاب مقصر بوده است. نتیجهٔ مشاهده، نتیجهٔ restore، وضعیت CI و آمادگی نصب جدا گزارش می‌شوند. اگر restore رد شود، policy آزاد نمی‌شود و گزارش از رسید کوتاه/live backscroll بازیابی می‌شود. Desktop0.9.10 و شاخهٔ اصلی تغییر نمی‌کنند.

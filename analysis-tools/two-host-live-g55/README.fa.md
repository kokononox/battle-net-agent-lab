# G55 — بررسی فقط‌خواندنی UI Automation پس از کنترل مثبت بومی

ادامه G54 بدون کلیک یا جلو بردن صفحه نصب/زبان. کنترل مثبت x86/x64 باید در همان run/commit پاس شود. سپس helper فقط‌خواندنی C# از منبع مخزن کامپایل و قبل از ایزولاسیون آماده می‌شود. helper فقط پنجره‌های متعلق به PIDهای مشاهده‌شده را پیمایش می‌کند، کنترل Edit/Document/password/hidden را نمی‌خواند و متن خام یا مقدار فیلد صادر نمی‌کند. سقف۱۲۸node/عمق۶ و deadline داخلی۳.۵ثانیه و timeout بیرونی۶ثانیه دارد. UI provider ممکن است ناقص/مسدود باشد؛ خطا و timeout پوشش کامل تلقی نمی‌شود.

نوع کنترل، label ثابت، marker لغوی و وضعیت enabled گزارش می‌شود؛ وجود marker تشخیص قطعی صفحه یا علت توقف نیست. helper هیچ Invoke/Select/SendKeys/SetValue ندارد. همان pin و امضای معتبر و gate دو IP با استثناهای CI حفظ شده است؛ ناظر همچنان API-based است، نه اثبات مستقل روی سیم. هیچ تغییر در RC یا دستگاه کاربر رخ نمی‌دهد.

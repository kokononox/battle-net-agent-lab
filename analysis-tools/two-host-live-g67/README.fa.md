# G67 — اصلاح خطای marker و مقایسه با ثابت مستقل نصاب

هدف همان حریم خصوصی دادهٔ خروجی به دو مقصد است؛ نه آزمون دوبارهٔ نصب.

## شواهد مستقل و اصلاح
نصاب رسمی از https://downloader.battle.net/download/installer/win/1.0.68/Battle.net-Setup.exe بدون اجرا دریافت شد. طول 4700880 و SHA256 برابر f4643a2086c0cecb1ab68cc601bf38c1a0a6f7ef5914ad03375cc9449385bec6 با نصاب پین‌شدهٔ آزمایش‌ها تطابق دارد. رشتهٔ ثابت ASCII برابر phoenix-agent/1.0 در offset ده‌دهی 3580116 قرار دارد. این مقدار از رشته‌های ثابت باینری گرفته شده، نه ترافیک مشاهده‌شده. فقط equality کامل و case-sensitive با User-Agent واقعی گزارش می‌شود؛ prefix-match یا افزودن خودکار مقدار مشاهده‌شده به allowlist وجود ندارد.

مرجع مستقل https://wowdev.wiki/index.php?title=Ribbit&oldid=37050 نقش seqn در پیگیری تغییرات نسخه/کش را توضیح می‌دهد؛ همچنین هشدار می‌دهد seqn ردیف summary و endpoint از 2022 الزاماً یکی نیستند. پاسخ عمومی فعلی نیز marker واقعی ## seqn = دارد. parser قدیمی #? فقط صفر یا یک # را می‌پذیرفت؛ پس seqn کلی سند را از دست می‌داد. G67 این خطا را اصلاح و شمارهٔ کلی سند summary را از شمارهٔ ردیف‌های محصول جدا می‌کند.

عدم تطابق قبلی در G65/G66 برای رد فرضیهٔ شمارهٔ توالی کافی نبود. تا پایان G67 معنای query و equality واقعی User-Agent همچنان تأیید نشده است.

## روش و مرزها
58 تست محلی شامل نمونهٔ واقعی marker دو #، تمایز seqn سند از ردیف محصول، عدم افشای مقدار و رد suffix/نسخه/حروف متفاوت UA می‌گذرند. همان کنترل‌های بومی x86/x64، بررسی کامل گواهی/ابطال، محدودیت دو مقصد و استثنای قبلی مدیریت CI، زمان مشاهدهٔ محدود و cleanup حفظ شده‌اند. نسخهٔ 0.9.10 و main تغییر نمی‌کنند. کنترل‌ها قبل از اجرای نصاب دوباره روی ویندوز اجرا می‌شوند.

raw path/query/header/body و شناسه و hash شناسه منتشر نمی‌شود. گزارش فقط نتیجهٔ equality و ساختار محدود است. تطابق ثابت عمومی یک فیلد یا query به معنی نبود فینگرپرینت در کل اتصال، تمام مسیرها یا کل دانلود نیست؛ ابزار هنوز semantic blocker نیست.

## تنها تکرار مجاز همین اصلاح
اجرای اول 40284772754 تطابق کامل UA با ثابت مستقل را ثبت کرد، اما پیش از query به علت late_process_image_failed متوقف شد و cleanup موفق بود. این commit فقط یک تکرار روی runner تازه را فعال می‌کند؛ کد مشاهده‌گر، محدودیت زمان و تمام حفاظ‌ها بدون تغییرند. اگر این تکرار هم متوقف شود، اجراهای بیشتر خودکار شروع نمی‌شوند.

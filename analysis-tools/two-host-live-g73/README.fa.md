# G73 — مقایسهٔ دقیق Range با کل شیء عمومی

تنها تغییر معنایی: وقتی مرجع ساختاری قبلی وجود ندارد، Range فقط با شروع صفر و انتهای دقیق اندازهٔ کدشده منهای یک، و توافق DL و EN همان محصول، کل شیء عمومی شناخته می‌شود. داخل محدوده بودن کافی نیست. مسیر دارای query هیچ تطابق مثبتی نمی‌گیرد.

مرجع مستقل و پین‌شدهٔ G69 و انتساب bts مرحلهٔ G72 بدون تغییر حفظ شده‌اند. هیچ داده یا executable تازه‌ای برای حل Range دریافت نمی‌شود. مقصدهای runtime همان دو میزبان، استثنای مدیریت CI بدون تغییر؛ main و Unified Firewall Desktop 0.9.10 دست‌نخورده‌اند. کنترل‌های native و اعتماد گواهی قبل از اجرا الزامی‌اند؛ مشاهده فقط ۱۲۰ ثانیه و یک Continue زبان، نه Install یا ورود. هیچ تطابقی اثبات نبود fingerprint نیست.

# G61 — اصلاح نام‌یابی بدون بازکردن شبکه

G60 در APIهای نام‌یابی نصب‌کننده برای us.version.battle.net خطای 11001 ثبت کرد. علت کامل BLZ هنوز قطعی نیست. در این آزمایش فقط نام‌یابی همان دو نام از طریق فایل hosts ویندوز موقت انجام می‌شود.

پیش از ایزوله‌سازی همان دو نام resolve و IPها در config خصوصی ثبت می‌شوند. فایل hosts اولیه دقیقاً backup می‌شود؛ فقط همان نام‌ها با همان IPها اضافه می‌شوند. هیچ IP یا نام سوم یا استثنای DNS به فایروال افزوده نمی‌شود. پس از blocking، نام‌یابی هر دو نام آزموده می‌شود و همهٔ جواب‌ها باید در snapshot همان نام باشند. Verify هش فایل hosts و سیاست فایروال را کنترل می‌کند. پس از توقف پردازش‌ها، hosts دقیقاً از backup بازگردانده و هش آن تأیید می‌شود؛ سپس فایروال برمی‌گردد.

این اصلاح مخصوص runner است، نه تغییر تنظیم کاربر یا نسخهٔ RC. نتیجهٔ محتوا، کنترل‌ها و لاگ پالایش‌شده مانند G60 ثبت می‌شود. کنترل مثبت HTTPS/TLS هنوز وجود ندارد و نبود محتوای ثبت‌شده به معنی نبود فینگرپرینت نیست.

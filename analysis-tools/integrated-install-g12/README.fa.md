# چارچوب آزمایشی بازیابی یکپارچه G12

این پوشه محصول نهایی یا اجراکننده قابل اعتماد برای نصاب واقعی نیست. سورس جاری شامل دو سناریوی ساختگیِ crash پس از ready و deadline بدون پیشرفت ناظر، در ماشین تازه Windows-2025 است. ورود فقط با approval دقیق workflow، branch پژوهش، push اول و runner موقت مجاز است.

Driver ناظر بیرونیِ آزمایش، Supervisor ناظر نشست، ExternalProbe فرایند/سرویس/وظیفه بی‌خطر، و Recover بازیابی مستقل SYSTEM است. Common قفل lease با ACL صریح SYSTEM/Administrators و ثبت اتمی وضعیت را فراهم می‌کند. FirewallGate درگاه برگرفته از G8 است؛ watchdog قدیمیِ import بی‌قیدوشرط ندارد. Restore نیازمند receipt پایان مؤلفه‌ها و phase=releasing است.

هیچ فایل اجرایی یا پیکربندی خصوصی به artifact راه ندارد. در شکست احراز پایان مؤلفه‌ها، مسیر بازیابی خودکار اجازه import بی‌قیدوشرط ندارد و ممکن است ماشین موقت با محدودیت باقی‌مانده کنار گذاشته شود. برای نصب واقعی باید پوشش مؤلفه‌های جدید/ناشناخته و crash حین startup تکمیل شود؛ صحت فعلی محدود به fixtureهای شناخته‌شده است.

گزارش معتبر در `reports/integrated-install-g12b/RESULT.fa.md` و گزارش‌های ناموفق قبلی جداگانه در `reports/integrated-install-g12` و `reports/integrated-install-g12a` حفظ شده‌اند. بررسی ضرورت تلمتری خارج از این مسیر است و پروژه منجمد ۰.۹.۱۰ تغییر نمی‌کند.

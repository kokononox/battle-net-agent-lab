# G60 — علت‌یابی توقف bootstrap

همان محدودیت دو مقصد و همان نصب‌کنندهٔ پین‌شدهٔ G59؛ بدون مجازکردن DNS یا مقصد تازه. فقط Windows موقت GitHub. نسخهٔ RC کاربر تغییر نمی‌کند.

پس از پایان پردازش و پیش از بازگردانی شبکه، فقط فایل‌های log/txt جدید یا تغییرکرده در مسیرهای محدود vendor و TEMP بررسی می‌شوند: حداکثر 64 فایل، 400 پوشه، 2MiB مجموع، 256KiB انتهای هر فایل، 80 ردیف تشخیصی هر فایل. نام مسیر و متن خام منتشر نمی‌شود؛ فقط دسته‌بندی ثابت واژه‌ها، کد BLZ و عددهایی که صریحاً با error/hresult/status برچسب خورده‌اند. دسته‌بندی واژه اثبات علت نیست. فایل‌های قدیمی بدون تغییر کنار گذاشته می‌شوند. جمع‌آوری محدود و غیرجامع است.

هوک تشخیصی خروجی getaddrinfo/GetAddrInfoW، شروع WinINet/WinHTTP، InternetGetConnectedState و CreateProcess را ثبت می‌کند؛ فقط نام ثابت API و نتیجه/کدخطا، و برای DNS یکی از دو نام مجاز یا other/loopback منتشر می‌شود. هیچ commandline، URL، نام دلخواه DNS، هدر یا بدنه‌ای صادر نمی‌شود. سقف 500 رخداد است. همهٔ داده‌ها مشاهده‌ای هستند و نتیجهٔ API تغییر نمی‌کند.

کنترل‌های مثبت G59 و تأیید رخدادهای موفق API در هر دو معماری پیش از اجرای واقعی لازم‌اند. صفر رخداد یا CI موفق نشانهٔ نبود فینگرپرینت نیست. TLS مثبت هنوز تست نشده است.

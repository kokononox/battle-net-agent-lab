# آزمایش نصب حداقلی Battle.net — مستقل از Unified Firewall

نسخه Unified Firewall 0.9.10 منجمد است. این شاخه ابزار آزمایش روی ویندوز یک‌بارمصرف است، نه نسخه جدید آن برنامه و نه فایل اجرایی نهایی.

## هدف و مرز
نصب واقعی و کامل کلاینت Battle.net باید انجام شود. ورود حساب، نصب بازی، تغییر گواهی TLS و خاموش‌کردن اعتبارسنجی TLS مجاز نیست. هدف نهایی حذف فعالیت‌های غیرضروری با آزمایش مقایسه‌ای است؛ صرف وجود نام telemetry یا Agent دلیل کافی برای مسدودسازی همه آن فرایند نیست.

هر آزمون روی VM تازه GitHub-hosted، با سقف زمان، تأیید امضای Blizzard و SHA256/اندازه نصب‌کننده از پیش بررسی‌شده انجام می‌شود. تغییر نصب‌کننده باعث توقف پیش از اجرا می‌شود. محیط فرایند هدف از اسرار GitHub پاک است. اعتبار نوشتن مخزن فقط در job جداگانه انتشار گزارش وجود دارد. خروجی خام، UUID، فایل اجرایی و ترافیک خام منتشر نمی‌شود. VM پس از پایان job دور انداخته می‌شود؛ cleanup_attempted تضمین خاتمه همه فرایندهای ناشناخته نیست.

## ترتیب آزمون‌ها
1. **C0 خط مبنای نصب:** فعلاً بدون هیچ انسداد؛ ابتدا اثبات کنیم خود نصب و ابزار سنجش کار می‌کنند.
2. **C0R تکرارپذیری:** نصب تازه با هویت همان نصب‌کننده و ثبت تفاوت نسخه کلاینت/CDN. مقایسه نسخه‌های متفاوت به عنوان آزمون هم‌گروه معتبر نیست.
3. **C1 پوشش رصد:** جمع‌آوری شروع/پایان فرایند و انتساب اتصال از قبل از اجرا؛ تعیین صریح شکاف‌های ETW، DNS، UDP، IPv6 و فرایندهای کوتاه‌عمر. C0 چنین پوشش کاملی ندارد.
4. **C2 حذف تک‌متغیره:** یک مقصد یا فعالیت مشخص در هر VM تازه مسدود شود. نتیجه نصب، زمان، خطا و بازگشت به baseline مقایسه شود. level3.blizzard.com و us.version.battle.net فرضیه‌های ضروری بودن بر مبنای مشاهده کاربر هستند، نه فهرست نهایی.
5. **C3 ترکیب و بازآزمایی:** فقط مواردی که غیرضروری بودنشان نشان داده شده ترکیب شوند؛ شکست نصب یا نقص رصد با موفقیت اشتباه نشود. دامنه‌های مشترک CDN و فرایند Agent یک‌جا حذف نشوند.
6. **C4 خروجی اختصاصی:** بعد از نتایج تکرارشده، EXE نصب ایزوله با سیاست حداقل دسترسی، fail-closed، نمایش وضعیت قابل فهم، backup و بازیابی ساخته و روی ویندوز آزمایش شود.

## تعریف محدود موفقیت C0
صرف اجرا شدن Setup، زدن Continue، وجود فایل یا پاسخ DNS کافی نیست. گزارش باید هم‌زمان کلید uninstall معتبر با مسیر و نسخه، فایل launcher و client با امضای معتبر Blizzard، ثبات فایل‌های کلیدی حداقل ۲۰ ثانیه، نبود Setup در نمونه فرایندها و نبود خطای snapshot را تأیید کند. این معیار اثبات ورود موفق، سلامت همه قابلیت‌های برنامه، حذف تلمتری یا پوشش همه ترافیک نیست.

در C0 تنها شش نام شناخته‌شده با نمونه‌برداری محدود رصد می‌شوند؛ فرایندهای کوتاه‌عمر/ناشناخته و برخی اتصال‌ها ممکن است دیده نشوند. بررسی باینری‌ها به پوشه پیش‌فرض، عمق و تعداد محدود شده است. UI ناشناخته، نتیجه نامطمئن کلیک یا نسخه تغییرکرده نباید به کلیک کور یا ادعای نصب موفق منجر شود.

نتیجه `bounded_install_not_verified` یا `stopped` یعنی نصب تأیید نشده است؛ دلیل توقف باید پیش از آزمون حذف مقصد بررسی شود. در این مرحله هیچ ادعای «بدون نشتی/تلمتری» نداریم.
